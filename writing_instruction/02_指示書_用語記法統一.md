# 指示書02：用語・記法統一パス

## 目的

全章の数学記法・専門用語・カタカナ表記を統一し、`task lint:terms` で違反ゼロを維持する。

## 参照

- 規約：`STYLE_GUIDE.md`「用語・数学記法」節
- lintルール：`style/terms.yaml`（`task lint:terms` で自動検証）

## 実施済み（2026-06-14）

`site/series/00.md`〜`15.md`、`appendix.1.md`〜`appendix.6.md` に適用済み。

主な変更：

- `$S^{d-1}$` → `$\mathbb{S}^{d-1}$`（全章）
- `von Mises-Fisher (vMF)` → 全角括弧に統一
- `vmf`（小文字）→ `vMF`
- `\boldsymbol{h}` 等ラテン文字への誤用 → `\mathbf{h}`
- `ソフトマックス` → `Softmax`

## 新規章追加時のチェックリスト

- [ ] `task lint:terms` でエラーがないこと
- [ ] 球面表記：`$\mathbb{S}^{d-1}$` を使っているか
- [ ] ベクトル記法：ラテン文字は `\mathbf{}`、ギリシャ文字は `\boldsymbol{}`
- [ ] vMF 分布：章内初出で「von Mises-Fisher（vMF）分布」と展開しているか
- [ ] 確率単体に言及する場合：章内初出で「確率単体（シンプレックス、probability simplex）」と注記しているか

## 禁止事項

- 文意の変更。用語置換で文が不自然になる場合は執筆者に確認。
- 数式の数学的内容の変更（記法のみ変更すること）。
