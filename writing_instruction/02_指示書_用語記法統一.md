## 実施済み項目（再実施不要）

### A. 数学記法

**A-1. ベクトル記法**

全章で規則通り使用されており、違反なし。

| 対象 | 記法 | 例 |
| --- | --- | --- |
| ラテン文字ベクトル | `\mathbf{}` | $\mathbf{x}, \mathbf{z}, \mathbf{W}$ |
| ギリシャ文字ベクトル | `\boldsymbol{}` | $\boldsymbol{\mu}, \boldsymbol{\theta}$ |
| スカラー | 素のイタリック | $\kappa, d, \tau$ |

検証: `grep -n 'boldsymbol{[a-z]' *.md` でラテン文字への誤用を確認。

**A-2. 球面表記**

`$S^{d-1}$`（`\mathbb` なし）→ `$\mathbb{S}^{d-1}$` に全章統一済み。`$S^1$`、`$S^2$` 等も同様。

検証: `grep -rn 'S\^{' site/series/*.md | grep -v mathbb` でヒットゼロを確認。

**A-3. その他の記法**

- 期待値：`$\mathbb{E}$` で全章統一済み
- KL ダイバージェンス：`$D_{\text{KL}}$` で統一済み
- ノルム：`$\|\mathbf{x}\|$`（$L_2$ 以外が使われないコンテキストでは下付き省略）

**A-4. 計量記号の章間差異**

00.md は $g_{ij}(\theta)$（リーマン計量の一般論）、04.md は $F_{ij}$（Fisher情報行列の慣用）を使用。
各章内では一貫しており、04.md の定義直後に「（第0回で導入したリーマン計量 $g_{ij}(\theta)$ に相当する。）」と接続注記を追記済み。

### B. 用語

**B-1. 球面 / 超球面**

本文では「球面」に統一。以下の例外のみ許可：

- nGPT 論文タイトル ("Normalizing LLM Geometries on the Hypersphere") への言及
- 03.md「球面と超球面の混同」セクション内の用語解説表

検証: `grep -rn '超球面' site/series/*.md` で例外箇所以外のヒットがないこと。

**B-2. 確率単体 / シンプレックス**

- 各章の初出：「確率単体（シンプレックス、probability simplex）」
- 以降：「単体」または「確率単体」

検証: `grep -rn 'シンプレックス' site/series/*.md` で初出注記以外のヒットがないこと。

**B-3. κ の訳語**

- 数学的パラメータとして語るとき：「集中度 $\kappa$」
- 直感・解釈として語るとき：「確信度」

07.md 5行・238行に定義文あり。使い分けは揺れではなく意図的な区別。

**B-4. von Mises-Fisher**

- 各章の初出：「von Mises-Fisher（vMF）分布」（括弧は全角）
- 以降：「vMF 分布」
- `vmf`（小文字）は使用禁止。`vMF` で統一。

検証: `grep -rn 'von Mises-Fisher (' site/series/*.md` で半角括弧を検出。

**B-5. カタカナ・英字語**

全章で統一済み。

| 概念 | 推奨 | 禁止 |
| --- | --- | --- |
| softmax | Softmax | ソフトマックス |
| embedding | 埋め込み | エンベディング |
| attention | Attention | アテンション |
| logit | ロジット（初出のみ "logit" 併記） | — |
| token | トークン | — |

## 新規章追加時のチェックリスト

新しい章（`site/series/` に追加する `.md`）を執筆したら以下を確認する。

- [ ] 球面表記：`$\mathbb{S}^{d-1}$`（`\mathbb` あり）を使っているか
- [ ] ベクトル記法：ラテン文字は `\mathbf{}`、ギリシャ文字は `\boldsymbol{}`
- [ ] vMF 分布：章内初出で「von Mises-Fisher（vMF）分布」と展開しているか
- [ ] 確率単体：章内初出で「確率単体（シンプレックス）」と注記しているか（04.md 以降の章で言及する場合）
- [ ] カタカナ・英字語が `用語表.md` に従っているか
- [ ] `task lint` でエラーがないこと
