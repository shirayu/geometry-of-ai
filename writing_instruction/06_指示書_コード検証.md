# 指示書06：コード検証パス

## 目的

全章の実装ノート（コードフェンス計34前後）を実行可能な環境で検証し、「期待される結果」コメントが実測と一致することを保証する。読者がコピペで動かせない実装ノートは信頼を損なう。

## 実施環境

- Python 3.11+ / numpy, scipy, matplotlib, scikit-learn, torch（CPU可）
- 各章のコードを `code/NN/` に切り出し、独立スクリプトとして保存（これ自体がリポジトリの資産になる）

## 検証項目（コードブロックごと）

1. **実行可能性**：コピペで動くか。import漏れ、未定義変数、前のブロックへの暗黙依存がないか。依存がある場合は本文に「上のコードの続き」と明示するか、自己完結に修正。
2. **期待出力の一致**：コメント内の数値（例：00の「d=10000: std≈0.010」、04の「τ=0.5: [0.88, 0.12, 0.01] に近い」）を実測し、乖離があれば数値を更新。乱数を使うコードは `seed` 固定がされているか確認し、なければ追加。
3. **数値安定性**：本文が数値安定性を主題にしている箇所（03の正規化、04の数値安定Softmax、05の数値安定ArcFace）は、不安定になる入力（大きなロジット、ゼロベクトル）でのエッジケーステストを追加実行。
4. **APIの現行性**：scikit-learn / PyTorch の非推奨API（deprecation warning）が出ないか。出る場合は現行APIに更新。
5. **本文との整合**：コードの変数名・数式記号が本文の記法（指示書02の記号表）と対応しているか。例：温度は `tau`、集中度は `kappa`。
6. **教育的コメントの質**：「なぜこう書くか」のコメントが本文の幾何学的説明と対応しているか。冗長な自明コメントの削除。

## 章別の重点項目

| 章 | 重点 |
| --- | --- |
| 00 | 直交性実験の統計値、Slerp/Lerpの中点ノルム≈0.71 の実測確認 |
| 01 | スイスロール：Isomap/LLEのパラメータ（近傍数）で結果が大きく変わるため、掲載パラメータで本文の主張通りの図になるか |
| 02 | Word2Vec概念実験：「概念的シミュレーション」の免責が十分か。可能なら gensim + 学習済みモデルでの実測版を補足として追加検討（保留リストへ提案） |
| 03 | vMF可視化、球面制約維持コードが学習ループで実際にノルム1を保つか |
| 04 | Gumbel-Softmax の soft/hard、温度3水準の出力一致。自然勾配近似が「教育目的」の免責通り小規模で動くか |
| 05 | ArcFace素朴版が実際に発散・不安定になるケースを示せるか（「数値安定版が必要」という本文の主張の実証） |
| 06 | 標準 vs Cosine Attention の比較が本文の主張（スケール不変性）を示す出力になるか。RoPEの相対位置性（位置シフトで内積不変）の数値確認 |
| 07 | vMFサンプリングの正当性（サンプル平均方向がμに収束）、KL近似と「厳密計算スケルトン」の整合、旧名エイリアスが実際に必要か（不要なら削除提案） |

## 出力

1. `code/` ディレクトリ（章別・実行確認済みスクリプト＋ `requirements.txt`）
2. `検証報告_コード.md`：ブロックごとに「実行可否 / 期待出力との差分 / 修正内容」
3. 修正版 `00.md`〜`07.md`（コードブロックのみ変更）
4. `保留リスト_コード.md`（仕様変更を伴う提案：gensim実測版の追加など）
