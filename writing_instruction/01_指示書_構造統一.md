# 指示書01：構造統一パス

## 目的

全章（`00.md`〜`15.md`、`appendix.1.md`〜`appendix.6.md`）の章構成・見出し・章末セクションを正規形に揃え、シリーズとして一冊の本のように読める状態にする。**本文の内容・表現には手を入れない**（それは指示書04・07の担当）。

## 対象ファイル

- `site/series/` 配下の全 `.md`（本章 `00.md`〜`15.md`、Appendix `appendix.1.md`〜`appendix.6.md`）
- 対象外：`intro.md`、`toc.md`、`references.md`、`keywords.md`、`toc.data.ts`（構成ファイルのため）
- 前提：`STYLE_GUIDE.md`（Phase 0 で確定済みの章末正規形・副題方針）

## 正規形

```md
# 第N回：タイトル ～サブタイトル～
## 注意事項
## 導入：…
（本文セクション群）
## まとめ：…（副題付き）
## 次回予告
## 実装ノート：…（副題付き）
## 参考文献
### （カテゴリ別小見出し）
```

例外：`15.md`（最終回）は実装ノート・次回予告なしを意図的省略として許容。

## チェックリスト（将来の章追加・改訂時に使用）

- [ ] 見出しレベルの飛び（`##` 直下に `####` 等）がない
- [ ] 「注意事項」が箇条書き3〜5項目＋末尾引用句で章冒頭にある
- [ ] 図キャプションが `<img>` 直後の「図: 〜。」形式（全角コロン不可）
- [ ] 本文中に「図1では」等の通し番号参照がない（「下図では」等に統一）
- [ ] コールアウト種別が STYLE_GUIDE の使い分け基準に合致
- [ ] 表の直前に導入文がある（裸の表を置かない）
- [ ] 実装ノート内のコードフェンス見出しが `###` で統一されている
- [ ] 章タイトルの波ダッシュが `～`（U+FF5E）で統一されている

## 禁止事項

- 本文段落の書き換え・削除（移動は可、ただし変更ログに記録）
- 数式・コード・参考文献への変更（他パスの担当）
