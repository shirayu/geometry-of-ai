# 通読レポート

指示書07（通読・読者体験監査パス）の観点別レポート。
重要度：**A**＝読者の理解を妨げる／数学的に誤解を招く（要対応）、**B**＝一貫性・体験上の改善余地（推奨）、**C**＝軽微・好みの範囲。
修正提案は出すが適用しない（最終判断は著者）。


## 観点1：メタファー体系の監査

対象：第0〜15回＋Appendix 1〜6 を一読者として通読。基幹メタファーの初出導入・混線・数学的歪み・限界明示の4点を監査した。
登録済み全メタファーは `style/metaphor.md` を参照。

### 総評

メタファー体系は全体として**質が高い**。とりわけ次の3点は模範的である。

1. **限界明示の徹底**：基幹メタファーの大半に CAUTION/注意事項で「賞味期限」が書かれている（STYLE_GUIDE「メタファーには必ず賞味期限を書く」を遵守）。特に第8〜13回は「これは比喩である」の明示が各章導入に組み込まれ、過剰なほど丁寧。
2. **「霧」の進化**：第0回（確率分布）→第7回（不確実性・κ）→第9回（拡散の中間分布）→Appendix 4（分布全体の代表）と、同一メタファーが対象を変えずに解像度を上げていく。STYLE_GUIDE が求める「同じ説明の繰り返しではなく深化」の好例。
3. **円環構造**：第0回「地図／旅」→第1回「かつての地図」→第15回「地図を閉じる時／プラネタリウムを建てよう」で開幕と終幕が呼応し、通読者に強い完結感を与える。

以下、個別指摘。

### A：要対応

#### A-1. 「望遠鏡/霧」の初出章が STYLE_GUIDE と不一致（第0回・第6回 vs 表記「第7回」）

- **箇所**：STYLE_GUIDE.md メタファー表 L167／第0回 §多様体の機能的階層 TIP（L57「望遠鏡の倍率」）、第0回 §なぜ多様体が重要か（L85「霧」）、第6回 §天体観測メタファー全般。
- **問題**：STYLE_GUIDE は「望遠鏡/霧」の初出を第7回と定義するが、実態は霧が第0回、望遠鏡が第0回TIP〜第6回で既に基幹的に使われている。正規定義（規約）と本文がずれており、台帳が執筆資産として機能しない。
- **提案（推奨）**：STYLE_GUIDE 表の初出列を「霧＝第0回／望遠鏡（天体観測）＝第6回」に修正。第7回は「望遠鏡/霧を不確実性へ適用」と位置づけ直す。
- **代替案（非推奨）**：第0回TIPの「望遠鏡の倍率」を別表現（例「ズームのレベル」）に変えて天体観測系の初出を第6回に一本化する案も考えられるが、**副作用があるため非推奨**。「望遠鏡の倍率」は第0回TIP単発ではなく、第6回 §Softmax（L332「望遠鏡の倍率を調整」＝温度）で再利用され、さらに第7回 導入（L16「望遠鏡の倍率を上げれば新たな構造が見えてくる」）が第0回TIPと響き合う「倍率」系の伏線を形成している。第0回TIPのみを別語に変えると、この伏線の連鎖が切れる。規約側を実態に合わせる推奨案を採るべき。

#### A-2. 第6回：基幹メタファー「測量士」が章内で「天体観測」に乗っ取られている

- **箇所**：第6回（タイトル「Transformerという測量士」）。§Attention機構の直感では測量士（L105-115）だが、以降 §天体観測メタファー（L160〜）・§Multi-head・§RoPE・§Softmax・まとめまで一貫して**望遠鏡/星**で説明される。測量士は導入の数段落のみ。
- **問題**：タイトルと章の主要メタファーが食い違う。読者は「測量士」を期待して読み始め、本文では「天体観測」で理解させられる。さらに同一章内で測量士（基準点測量）と天体観測（望遠鏡で星を観測）という**2つの空間メタファーが併存**し、QKVの直感が二重化している（測量：Q=測量士の意図／天体観測：Q=望遠鏡のフィルター）。
- **提案**：いずれかに寄せる。(a) タイトルを天体観測系に変えるとシリーズの「測量士」基幹メタファー（STYLE_GUIDE登録）が消えるため非推奨。(b) 測量士＝「動的に計量を測る」骨子、天体観測＝「QKVの具体的対応」と役割分担を1文で明示し、§天体観測メタファー冒頭に「測量という営みを、より具体的に天体観測として描き直す」と橋を架けるのが穏当。現状は橋がなく唐突に切り替わる。

### B：推奨

#### B-1. 「星」が6種の対象を指す多義負荷

- **箇所**：第1回（星＝単語）／第3回（星＝データ点）／第6回（星＝トークン）／第7回（星＝概念）／第9回（星＝凝縮先データ）／Appendix 2（星＝事実）。詳細は台帳 §3.2。
- **問題**：STYLE_GUIDE が名指しで警告する混線（「星＝トークン／概念」）が実在し、しかも想定より広い。各章で再宣言はされている（規約は遵守）ため致命的ではないが、通読すると「星」の指示対象が章ごとに滑り、特に第1回（単語）→第3回（データ点）の最初の切り替えで読者が引っかかりやすい。
- **提案**：(a) 第1回 §pLSA/LDAの「離散的な星空」は、後続の球面プラネタリウム（連続）と対照させる意図なら、その対照を1文で明示すると混線が「対比の仕掛け」に転じる（例「後の章では星は連続空間の点になる。ここでの星は離散的なカテゴリだという違いに注意」）。(b) 最低限、台帳を著者手元に置き、第8回以降で「星」を新たな対象に流用しないよう統制。

#### B-2. 光学機器メタファーの分岐（望遠鏡 vs 顕微鏡）

- **箇所**：第0回TIP・第6・7回「望遠鏡」（遠くの星＝大域構造を見る）／第14回「トポロジーという顕微鏡」（穴・ループ＝微細構造を見る）。
- **問題**：同じ「光学機器で見る」系統で、望遠鏡（マクロ）と顕微鏡（ミクロ）が逆向きの含意を持つ。第14回が「顕微鏡」を選んだ理由（トポロジーは局所の穴を拾う）は妥当だが、望遠鏡系との関係が無言。読者は「なぜここだけ顕微鏡？」と感じうる。
- **提案**：第14回導入に1文。「これまで望遠鏡で星の配置（大域的な形）を見てきたが、本回は顕微鏡に持ち替え、形の内側の穴やループを見る」と接続すれば、分岐が意図的な対比になる。Appendix 6 の「最も強力なレンズの一つ」（L147）とも整合する。

#### B-3. 第6回「辞書メタファー」の扱い

- **箇所**：第6回 §なぜ「辞書」ではなく「天体観測」か（L162-168）。
- **所見**：辞書メタファーを明示的に導入→限界提示→天体観測へ乗り換える構成は良い（比喩の安売りを避け、なぜ別比喩が要るかを説明）。**これは A-2 の解決モデルにもなる**——測量士→天体観測も同じ「乗り換えを明示する」型で書けば自然になる。指摘ではなく好例として記録。

### C：軽微

#### C-1. 第0回タイトル「羅針盤」が本文に登場しない

- **箇所**：第0回タイトル「～この講義の羅針盤～」。本文中に「羅針盤／コンパス」の語はなく、地図・地球儀・霧・望遠鏡が実体。
- **所見**：サブタイトルの「羅針盤」は比喩として孤立（=方向を指し示す道具、の含意は伝わるので許容範囲）。気になるなら §本講義の地図 で「五つの道具が羅針盤になる」等の一言で回収可。重要度C。

#### C-2. 第9回「霧から星が凝縮」見出しの星

- **箇所**：第9回導入見出し（L13）。
- **所見**：ここでの「星」はデータ点（生成結果）の意で、第7回の「星＝概念＋霧」を引き継ぐ自然な用法。再宣言は薄いが、霧（拡散の前段）との対で意味は取れる。混線というより継承。記録のみ。

## 修正方針案

観点1の指摘を受け、本文側の修正は「比喩を減らす」よりも、**役割分担を明示し、初出管理を実態に合わせる**方針で進める。既存のメタファー体系は全体として有効なので、全面的な置換は行わない。

### 1. STYLE_GUIDE のメタファー表を実態に合わせて更新する

**対応する指摘**：A-1

`STYLE_GUIDE.md` の「望遠鏡/霧」を一項目にまとめたままだと、初出章と指す対象が本文実態とずれる。次のように分離して登録する。

```txt
| 望遠鏡/天体観測 | 第6回（第0回 TIP に先行的表現あり） | AttentionにおけるQuery/Key/Value、観測視点、Softmax温度 | 観測比喩は計算機構の直感化であり、Attentionが実際に光学観測を行うわけではない |
| 霧 | 第0回 | 確率分布、不確実性、拡散過程、分布全体 | 等方的な広がりの比喩であり、異方的な共分散や多峰性を常に表せるわけではない |
```

第7回は「望遠鏡/霧の初出」ではなく、**霧を不確実性・κへ適用する章**として位置づけ直す。第0回の「望遠鏡の倍率」は局所的な先行表現として許容し、天体観測メタファーの本格導入は第6回とする。

### 2. 第6回に「測量士」と「天体観測」の橋渡しを追加する

**対応する指摘**：A-2、B-3

第6回ではタイトルと章の骨格を「測量士」のまま維持する。天体観測は、測量士メタファーを置き換えるものではなく、QKVをより具体的に説明するための下位メタファーとして位置づける。

挿入候補は、`## 天体観測メタファー：QKVの再解釈` の直後。

```md
ここで、測量士の比喩を一段具体化する。測量士が未知の地形を測るように、Attentionは入力ごとに「どの基準点を見るか」を決める。ただし、QKVの対応を説明するには、測量よりも「どの波長を通す望遠鏡で、どの星を見るか」という天体観測の方が直感的である。

以降では、測量士を「入力ごとに計量を作る」という章全体の比喩として保ちつつ、QKVの細部は天体観測として描き直す。
```

これにより、測量士＝章全体の機能、天体観測＝QKVの具体的対応、という分担が明確になる。

### 3. 第6回のまとめで測量士メタファーへ戻す

**対応する指摘**：A-2

章末のまとめが天体観測寄りに閉じると、タイトルの「測量士」が回収されにくい。まとめに次のような一文を加える。

```md
天体観測の比喩で見た望遠鏡・星・フィルターは、章全体の言葉で言えば、測量士が入力ごとに基準点を選び、距離の測り方を組み替えている姿である。
```

この一文で、章タイトルと本文後半の比喩を再接続する。

### 4. 「星」の多義は置換せず、章内初出で再宣言する

**対応する指摘**：B-1

「星」はシリーズ全体の雰囲気を作る基幹語なので、全面置換はしない。ただし、章ごとに指す対象が変わるため、初出時に必ず対象を宣言する。

優先して補う箇所は第1回と第9回。

第1回の `pLSA/LDA` 付近には、後続章との差を明示する。

```md
ここでの「星」は、後の球面プラネタリウムで扱う連続的な埋め込み点ではなく、語彙という離散的な記号を指す。
```

第9回の導入見出し「霧から星が凝縮する」の直後には、星の意味を明示する。

```md
ここでいう「星」は、生成過程の終点として現れるデータ点であり、第7回の「概念を表す星」とは少し役割が異なる。
```

第8回以降で新たに「星」を別対象へ流用する場合は、同じ形式で初出宣言を入れる。

### 5. 第14回に「望遠鏡から顕微鏡へ」の接続文を追加する

**対応する指摘**：B-2

第14回の「トポロジーという顕微鏡」は有効だが、望遠鏡系メタファーからの持ち替えが無言になっている。導入末尾、または `## 幾何学とトポロジー：二つの視点` の冒頭に次を加える。

```md
これまで私たちは、望遠鏡で星の配置を見るように、表現空間の距離・角度・曲率を眺めてきた。本回では顕微鏡に持ち替え、空間の内側にある穴やループという、より位相的な構造を見る。
```

これにより、望遠鏡＝配置や大域的な見え方、顕微鏡＝穴やループの検出、という対比が意図的なものとして読める。

### 6. 第0回「羅針盤」は任意対応に留める

**対応する指摘**：C-1

第0回タイトルの「羅針盤」は孤立しているが、読解を妨げるほどではない。修正する場合のみ、`## 本講義の地図` 付近に次の一文を足す。

```md
この地図は、以降の講義で迷わないための羅針盤でもある。
```

ただし、地図・旅・羅針盤の比喩が過密になる場合は、現状維持でよい。

### 7. 修正優先度

実作業では、次の順に対応する。

1. **第6回の橋渡し追加**：読者体験への影響が最も大きい。
2. **STYLE_GUIDE の表更新**：今後の執筆・レビュー基準を安定させる。
3. **第14回の接続文追加**：低コストで通読時の連続性が上がる。
4. **第1回・第9回の「星」再宣言**：混線リスクを下げる。
5. **第0回「羅針盤」の回収**：任意。違和感が残る場合のみ対応。

この修正で、メタファー体系の強みである「地図・星・霧・観測」の連続性を残しつつ、読者が章ごとの比喩の切り替わりで迷う箇所を減らせる。
