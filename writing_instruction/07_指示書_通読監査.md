# 指示書07：通読・読者体験監査パス（最終パス）

## 目的

Phase 1〜2 の修正完了後、シリーズ全体を第0回から第15回まで（＋Appendix）**一人の読者として通読**し、章間の接続・メタファーの進化・難易度勾配・冗長性を監査する。本パスは個別章では発見できない問題（シリーズ全体の体験）を対象とする。

## 実施方法

- **実施タイミング**：草稿層（08〜15・Appendix）の書き直しが完了し、全章が確定層に揃ってから実施する（`00_洗練計画.md` §1.5 参照）。
- 対象ファイル：`00.md`〜`15.md`（本章）＋ `appendix.1.md`〜`appendix.6.md`（補足として参照）
- 全16章を順番に読む。1回の通読で以下の4観点すべてをメモし、観点別レポートにまとめる。
- 修正提案は出すが適用しない（最終判断は著者）。ただし誤字脱字・てにをはレベルは直接修正リストとして列挙してよい。

## 観点1：メタファー体系の監査

本シリーズの基幹メタファーは段階的に進化する（`STYLE_GUIDE.md` のメタファー表が正規定義）：

```txt
地図（第0回）→ 地球儀/プラネタリウム（第3回）→ 測量士（第6回）→ 望遠鏡/霧（第7回）→ 第8回以降の展開（通読時に確認）
```

第8回以降のメタファーは事前に確定せず、通読時に実態を把握してメタファー台帳に記録する。

- [ ] 各メタファーの**初出時に十分な導入**があるか。前の章を読んでいない読者にも独立に成立するか（Web連載は途中から読まれる）。
- [ ] メタファーの**混線**がないか（例：「星」が第6回ではトークン、第7回では概念の分布。同じ語が別の対象を指す箇所で読者が迷わないか）。
- [ ] メタファーが**数学的内容を歪めていないか**（指示書04と連携。比喩が比喩であることが明示されているか）。
- [ ] メタファー対応表を作成：`メタファー台帳.md`（メタファー / 初出章 / 指す数学的対象 / 限界の明示箇所）。第8回以降の執筆資産になる。

## 観点2：章間接続・伏線の検証

- [ ] 各章の「次回予告」が次章の実際の内容と一致するか（執筆中に内容がずれた可能性。特に04→05、06→07）。
- [ ] 「第N回で見たように」という後方参照がすべて正しい章・正しい内容を指すか（grep「第[0-9]回」で全参照を抽出し突合）。
- [ ] 前方参照（「第6回で整理する」等）がすべて回収されているか。03の TIP「Transformerの全体像は第6回冒頭で」→ 06冒頭に実在することは確認済み。他の前方参照も同様に。
- [ ] 00の「本講義の地図：三つの世界」「続編への接続」が、完成した1〜7回の実態および第8回予告（時間の発見：拡散モデル・CoT）と整合するか。**00は最初に書かれたはずなので、7章分の執筆を経て陳腐化した記述がないか重点確認**。
- [ ] 第8回への伏線：07の次回予告と00の続編記述の整合。

## 観点3：難易度勾配と読者体験

- [ ] 前提知識の段差：章の途中で突然要求水準が上がる箇所（例：04の情報幾何学セクション、07の正規化定数）に、適切な迂回路（「初読では飛ばしてよい」等の案内）があるか。
- [ ] 各章の長さバランス：04（55KB）と07（63KB）、10（CoT）と09（拡散）は他章より大幅に長い。分割または「発展的トピック」の独立ページ化を検討すべきか提案。
- [ ] 「注意事項」（章冒頭）が、初読者には文脈不明で威圧的になっていないか。読了後に戻ると分かる書き方なら「読了後に再読を推奨」の一文を検討。
- [ ] 各章が単独で読めるか：途中の章から読み始めた読者向けに、冒頭で必要な前章リンクが張られているか。

## 観点4：冗長性と文体

- [ ] 章をまたぐ重複説明の監査：vMF分布は03と07で二度導入される（連載として意図的な再導入は可。ただし**同じ説明の繰り返し**ではなく**深化**になっているか）。「点埋め込み=κ→∞」は07内で4回以上繰り返されている可能性——強調と冗長の線引きを判定。
- [ ] 「である」調の統一、一文の長さ（80字超の文の洗い出し）、接続詞の癖（「しかし」「つまり」の頻度）。
- [ ] 各章の導入が同じ型（「第N回で〜した。しかし〜」）に固定化していないか。型は良いが単調なら変奏を提案。

## 出力

1. `通読レポート.md`（観点別。指摘には章・見出し・重要度A/B/Cを付す）
2. `メタファー台帳.md`（第0〜15回＋Appendix のメタファー全登録）
3. `誤字脱字リスト.md`（直接修正可能な機械的修正）
4. `申し送り.md`：通読で見えた「シリーズ全体で未消化の約束」「続編（第16回以降）が回収すべき伏線」の一覧
