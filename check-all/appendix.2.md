## 総評

「幾何学は形を測れるが、正しさは測れない」という本連載の通底テーマを、データ品質という実務的な問題に接続する野心的なAppendixである。特に第7回の「無知の捏造」と対比させた「誤信念の表出（確信した嘘）」の2類型は、ハルシネーション問題を幾何学的に整理する独自貢献であり、読みごたえがある。「原理的な識別不能性」を正面から認める誠実さも、本連載の姿勢と整合する。

しかし、STYLE_GUIDEのAppendix正規形が定める「本Appendixの位置づけ」という見出し名が使われておらず、「問題の所在」という独自の見出しに置き換わっている。まとめセクションの本編接続も不十分で、第8回への接続が1行に書かれるのみである。また、「動態論への伏線」と「動態論への接続」が実質的に同一の内容を繰り返しており、冗長さが目立つ。

## 指摘詳細

### 1. [A] 「本Appendixの位置づけ」の見出し名と前提章の欠如

- **箇所**: `## 問題の所在`（L8）および `## 本Appendixの射程`（L28）
- **現状**: 冒頭のセクション見出しが「問題の所在」であり、STYLE_GUIDEのAppendix正規形が定める「本Appendixの位置づけ」ではない。「本Appendixの射程」セクションが後に続き、扱うこと・扱わないことを列挙している。
- **問題**: STYLE_GUIDEは「本Appendixの位置づけ（本編のどの章・概念を深掘りするか。1〜3段落）」をAppendixの最初のセクションとして定めている。現在の内容は問題提起と射程の宣言に終始しており、どの章を先に読むべきか（前提知識）が読者に伝わらない。本文では第3回（正規化）、第7回（不確実性）、第8回（動態論）、第13回（高次元・距離の集中）、第14回（TDA）が参照されるが、これらを先に読む前提であることが明示されていない。
- **改善案**: 「問題の所在」と「本Appendixの射程」を統合し、見出しを「本Appendixの位置づけ」に変更する。構成は以下の通り：
  1. 本Appendixが深掘りする本編の章・概念（第3回、第7回）
  2. 前提として読んでおくべき章のリスト
  3. 扱うこと・扱わないこと（現在の「射程」の内容）
  
  例：

  ```text
  ## 本Appendixの位置づけ
  
  本Appendixは、第3回「球面と正規化」と第7回「不確実性の復権」を前提として、
  幾何学的安定化がデータ品質の保証にはつながらない理由を掘り下げる。
  第8回「情報幾何学とAIの動態論」への伏線も含む。
  
  前提として以下の章に目を通しておくことを推奨する：
  - 第3回（正規化と球面設計）
  - 第7回（集中度 κ とハルシネーション）
  ```

### 2. [A] まとめに本編接続の表がない

- **箇所**: `## まとめ：データ品質の幾何学的限界`（L354-L366）
- **現状**: まとめには4行の要約表（主題・要点・現状）があるが、「本編との接続まとめ」が含まれていない。最後の行で「第8回『CoTのエネルギー地形』へ」と書かれているのみ。
- **問題**: STYLE_GUIDEは「まとめには『本編との接続まとめ』を含める（表形式可）」と定めている。Appendix 1のまとめは5章分の接続表を持つが、Appendix 2では第8回への1行言及にとどまる。本文では第3回、第7回、第13回、第14回も参照しているため、これらの接続がまとめに反映されるべき。
- **改善案**: まとめ表の後に、本編接続表を追加する。例：

  ```text
  | 講義回 | 接続点 |
  | --- | --- |
  | 第3回（球面と正規化） | 正規化が形式の安定を与えるが内容の真偽には中立 |
  | 第7回（不確実性） | 無知の捏造（低κ）と誤信念の表出（高κ・誤方向）の対比 |
  | 第13回（高次元） | 距離の集中が密度ベース選別を困難にする |
  | 第14回（TDA） | Betti数と論理矛盾の対応（仮説段階） |
  | 第8回（動態論） | 静的な純度問題が推論時に偽の極小値として顕在化 |
  ```

### 4. [B] vMF分布の平均方向の記号違反

### 6. [B] 「論理と幾何の断絶」の直感説明不足

- **箇所**: `### 論理と幾何の断絶`（L162-L174）
- **現状**: 三角不等式 $d(\mathbf{v}_A, \mathbf{v}_B) + d(\mathbf{v}_B, \mathbf{v}_C) \geq d(\mathbf{v}_A, \mathbf{v}_C)$ を示した上で、「含意の向き（A→BとB→Aは別物）や反例の存在は表現距離だけでは表現できない」と述べている。
- **問題**: 三角不等式は距離の公理であり常に成り立つが、問題は「距離が対称であること（$d(A,B) = d(B,A)$）」にある。含意の向き（A→B）は非対称な関係だが、距離は対称なので方向を表現できない、という直感的な説明が抜けている。想定読者は「なぜ三角不等式を持ち出したのに含意の話になるのか」という論理の飛躍に直面する。
- **改善案**: 三角不等式の後に、距離の対称性に触れる1文を追加する。例：

  ```text
  距離は対称（$d(A,B) = d(B,A)$）であるため、「AならばB」と「BならばA」を区別できない。
  含意には向きがあるが、距離には向きがない。この非対称性の欠如が、論理を距離だけで表現できない一因である。
  ```

### 7. [C] 「問題の所在」と「本Appendixの射程」の分割

- **箇所**: `## 問題の所在`（L8-L26）と `## 本Appendixの射程`（L28-L52）
- **現状**: 冒頭が二つの ## 見出しに分割されている。「問題の所在」は問題提起と純度の定義、「本Appendixの射程」は扱うこと・扱わないこと・正しさの3類型を含む。
- **問題**: Appendix正規形は「本Appendixの位置づけ（1〜3段落）」を1セクションとして定めている。2つの ## 見出しに分けると、読者が「どこまでが位置づけの説明か」を把握しにくい。また、「正しさの3類型」表は本文の基盤定義であり、位置づけセクションではなく本文セクション内に置く方が自然。
- **改善案**: 「問題の所在」と「本Appendixの射程」を「本Appendixの位置づけ」に統合し、「正しさの3類型」表は本文の最初のセクション（例えば「正規化が解決したこと、しなかったこと」の前）に独立した小見出しで配置する。

### 8. [C] 表中のメタファーが説明なし

- **箇所**: `### 既存の道具を多様体の言葉で読み直す`（L86-L94）
- **現状**: 表中で「外部の神託」（人手ラベリング）、「多様体の『設計'」（合成データ）という表現が使われている。
- **問題**: 「神託」はoracleの訳語として機械学習で使われるが、想定読者（深層学習の実装経験はあるが微分幾何は未習）に自明ではない。「多様体の設計」も、合成データ生成を幾何学的に言い換えたメタファーだが、なぜ「設計」なのかの説明がない。
- **改善案**: 「外部の神託」を「外部の正解ラベル（人手判定）」のように具体的な表現に改めるか、NOTEで補足する。「多様体の設計」は「正しい多様体を先に構築する（合成データで）」のように括弧で言い換える。

### 9. [C] 「全員」の擬人化

- **箇所**: `### 解決しなかったこと（原理的な限界）`、L76付近
- **現状**: 「球面上に綺麗に配置されたデータが、全員『間違った方向』を指していても」
- **問題**: 「全員」は人間に対する語であり、データ点に対する擬人化は曖昧さを生む。技術文書では「すべて」または「全てのデータ点が」が適切。
- **改善案**: 「球面上に綺麗に配置されたデータ点が、すべて『間違った方向』を指していても」

### 10. [C] ASCII図のキャプション不足

- **箇所**: `### 球面上での可視化`、L225-L233
- **現状**:

  ```text
  ★ ✗ ★      ← ✗ = 誤った答え
  ```

  というASCII図があるが、★が何を表すか、✗がどこにあるかの説明が図内のコメント（← ✗ = 誤った答え）のみ。
- **問題**: 「★ ✗ ★」の行は「集中度κは高いが方向が誤っている」状態を図示しているが、★がサンプル点、✗が誤った予測中心であることを明示するキャプションがない。直前の「無知の捏造」の図（L218-L223）も同様にキャプションが薄い。
- **改善案**: 各図の直後に1行のキャプションを追加する。例：

  ```text
  図: 誤信念の表出。★は高い集中度を持つサンプル点、✗は誤った予測中心。
  球面上の一点にサンプルが集中しているが、その方向が真の答えとずれている。
  ```

## 維持すべき良い点

1. **「無知の捏造」と「誤信念の表出」の2類型対比表**（L204-L211）：メカニズム、幾何学的状態、サンプリング温度の効果、対策の可否までを網羅的に比較しており、ハルシネーション研究の整理として独自性が高い。
2. **「原理的な識別不能性」の明示**（L125-L134）：幾何学が内在的性質しか測れないことを正面から認め、「逃げではなく必然」と位置づける誠実さ。本連載の「仮説と事実の書き分け」方針とも整合する。
3. **「正しさ」の3類型表**（L42-L51）：論理整合性・事実整合性・規範整合性を分け、規範整合性を「幾何学の射程外」と明示することで、議論のスコープを読者に伝えている。
4. **CAUTIONの適切な配置**（L109, L147）：EL2Nと表現距離の混同防止、高次元の呪いの過剰一般化への警告を、該当箇所の直後に配置しており、読者の誤読を先回りして防いでいる。
5. **第7回との対比構造**: 全Appendixを通じて第7回の一貫した参照があり、「不確実性の復権」の議論をデータ品質の問題へと自然に接続している。特にL186-L195の導入は効果的。
