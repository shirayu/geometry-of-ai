# Appendix 6 理解度チェック：特異点の幾何学

## 正則と特異

### Q1. 正則モデルと特異モデル

正則モデルと特異モデルの違いとして、正しいものはどれか。

```quiz
- [x]正則モデルでは局所的にパラメータが識別しやすいが、特異モデルでは冗長性や退化により識別できない方向が生じる
- 特異モデルでは学習が必ず不可能になる
- 正則モデルには確率分布がない
- 両者の違いはデータ数だけで決まる
S: /series/appendix.6#正則と特異の違い
A: 特異モデルでは、異なるパラメータが同じ分布を表すなど、局所的な識別性が壊れる。ニューラルネットワークの対称性や冗長性が典型的な要因になる。
```

### Q2. 深層学習の特異性

深層学習が特異になりうる理由はどれか。

```quiz
- パラメータが少なすぎるから
- [x]ニューロンの置換対称性や過剰パラメータ化などにより、同じ関数を複数のパラメータで表せるから
- 活性化関数が必ず線形だから
- データが必ず低次元だから
S: /series/appendix.6#なぜ深層学習は「特異」なのか
A: ニューラルネットワークでは、ユニットの入れ替えや不要な経路などによって、同じ関数を表すパラメータが複数存在しうる。これが正則な局所構造を壊す。
```

### Q3. 谷の幾何学

特異モデルの損失地形を「谷の広さ」で見る意義はどれか。

```quiz
- [x]単一の点やパラメータ数だけでなく、同じ性能を持つ解の広がりや退化を考慮できる
- 広い谷は必ず訓練誤差が大きい
- 谷の形は汎化と無関係である
- 特異点の近くでは損失を定義できない
S: /series/appendix.6#自由エネルギーと汎化誤差
A: 特異モデルでは解が単一点ではなく、広い集合や退化した谷を形成することがある。自由エネルギーや汎化誤差を、パラメータ数だけでなく幾何学的な広がりから考える動機になる。
```

### Q4. RLCT

RLCTを「空間の実質的な次元」として読む説明はどれか。

```quiz
- パラメータの個数をそのまま数える指標
- [x]特異な損失地形で、汎化やベイズ積分の漸近的な複雑さを特徴づける量
- 学習率を決めるハイパーパラメータ
- データのクラス数を表す量
S: /series/appendix.6#rlct-空間の「実質的な次元」
A: RLCTは、特異点を持つモデルの複雑さを、単純なパラメータ数とは異なる形で表す。ベイズ自由エネルギーや汎化誤差の漸近評価に関係する。
```

## 相転移と汎化

### Q5. 学習の相転移

学習の相転移を幾何学的に見ると、何が急に変化しうるか。

```quiz
- [x]損失地形や解の領域、表現の性質が、制御パラメータの変化に対して急に変わる
- 学習率だけが必ず一定になる
- 相転移は物理学にしか存在しない
- 汎化性能は相転移と無関係である
S: /series/appendix.6#学習の相転移
A: モデル規模、正則化、データ量などの変化により、学習の状態や汎化の振る舞いが急に変わることがある。これは比喩ではなく、条件に応じた現象として検討される。
```

### Q6. 特異点解消

特異点解消の数学的な役割として、正しいものはどれか。

```quiz
- 特異点を無視して、常に正則モデルとして近似する
- [x]適切な変換で特異な構造を調べやすい局所的な空間へ展開し、解析の手がかりを与える
- 学習データをすべて削除する
- 曲率を必ず0にする
S: /series/appendix.6#特異点解消-裂け目を修復する数学
A: 特異点解消は、特異な空間を解析しやすいチャートへ展開する数学的枠組みである。学習問題へ適用するには、モデルと損失の構造を具体化する必要がある。
```

### Q7. 情報幾何学との統合

特異学習理論と情報幾何学の関係について、適切な説明はどれか。

```quiz
- [x]正則モデルで有効な計量の見方を、退化や特異性を含む学習の幾何へ拡張して考える接点がある
- 特異学習理論は確率分布を扱わない
- 情報幾何学を使えば特異点は必ず消える
- 正則モデルと特異モデルは同じ近似だけで十分に扱える
S: /series/appendix.6#情報幾何学と特異学習理論の統合
A: 情報幾何学は正則な確率モデルの計量を与えるが、深層学習では退化や特異点が現れる。両者を接続するには、正則性の破れを考慮した理論が必要になる。
```

### Q8. 汎化の読み方

特異学習理論から汎化を考えるとき、最も慎重な説明はどれか。

```quiz
- パラメータ数だけで汎化性能が完全に決まる
- [x]解の谷や特異性、データとの関係を含む実効的な複雑さが汎化の理解に関わる
- 特異点があれば必ず汎化する
- RLCTを測ればタスクの真偽が直接わかる
S: /series/appendix.6#まとめ-特異点と汎化の接続
A: 特異性は、パラメータ数だけでは表せないモデルの複雑さや解の広がりを考える視点を与える。ただし、汎化はデータ、損失、学習過程にも依存する。
```
