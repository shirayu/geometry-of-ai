# Appendix 6 理解度チェック：特異点の幾何学

## 正則と特異

### Q1. 正則モデルと特異モデル

正則モデルと特異モデルの違いとして、正しいものはどれか。

```quiz
- 両者の違いはパラメータ数の多さで決まり、層を増やすほど正則モデルに近づく
  R: 正則・特異の区別はパラメータ対分布の対応関係（単射か多対1か）で決まるものであり、層を増やして単にパラメータ数を増やしても正則性が回復するわけではない。
- 特異モデルは損失地形が退化しているため、勾配法による学習そのものが原理的に不可能である
  R: Fisher情報行列がランク落ちすることは局所的な識別性が壊れることを意味するが、多層パーセプトロンやTransformerのような特異モデルは勾配法で現に学習が進んでおり、学習そのものが不可能になるわけではない。
- 正則・特異の区別はモデルが確率分布を定義できるかどうかの違いを指す
  R: 正則モデルも特異モデルもどちらも確率分布を定義できる点は共通しており、両者の違いはパラメータと分布の対応が1対1か多対1かという識別性の違いにある。
- [x]正則モデルは局所識別、特異モデルは冗長性を持つ
  R: 正則モデルはパラメータと分布が1対1に対応し局所的に識別できるのに対し、特異モデルは異なるパラメータが同じ分布を表す冗長性を持ち、Fisher情報行列がランク落ちする。
S: /series/appendix.6#正則と特異の違い
A: 特異モデルでは、異なるパラメータが同じ分布を表すなど、局所的な識別性が壊れる。ニューラルネットワークの対称性や冗長性が典型的な要因になる。
```

### Q2. 深層学習の特異性

深層学習が特異になりうる理由はどれか。

```quiz
- [x]同じ関数を複数のパラメータで表せるから
  R: 隠れ層のニューロンの入れ替えや、重みが0になったニューロンへの入力側の不定性など、同じ関数を複数のパラメータ設定で表せる冗長性が特異性の直接の原因になる。
- データが低次元で、表現の自由度が少ないから
  R: 特異性はデータの次元とは別の話であり、パラメータ空間内でニューロンの交換や消滅によって同じ関数が複数のパラメータで表されることに由来する。
- パラメータが少なく、同じ関数を表せないから
  R: 特異性が生じるのはパラメータが少なく同じ関数を表せないからではなく、むしろパラメータが冗長で複数の設定が同じ関数を表せてしまうことによる。
- 活性化関数が線形で、対称性が生じないから
  R: 特異性の典型的な発生源であるニューロンの交換対称性は、線形・非線形を問わず任意の多層パーセプトロンに現れる構造であり、線形活性化に限った現象ではない。
S: /series/appendix.6#なぜ深層学習は「特異」なのか
A: ニューラルネットワークでは、ユニットの入れ替えや不要な経路などによって、同じ関数を表すパラメータが複数存在しうる。これが正則な局所構造を壊す。
```

### Q3. 谷の幾何学

特異モデルの損失地形を「谷の広さ」で見る意義はどれか。

```quiz
- 谷の広さは訓練誤差の値そのものを表す量なので、汎化誤差の議論には使えない
  R: 谷の広さは訓練誤差そのものではなく、事後分布の広がりを通じてベイズ自由エネルギーの漸近形（RLCT）に関わる量であり、汎化誤差の議論に直結する。
- 谷が広いか狭いかは、モデルのパラメータ総数だけで一意に決まる
  R: 谷の広さを表すRLCTはパラメータ総数とは一致せず、損失関数の谷の幾何学的構造から決まる量である。
- 広い谷を持つ解は、狭い谷を持つ解より訓練誤差が大きくなる
  R: 谷の広さは事後分布の体積に関わる幾何学的な性質であり、訓練誤差の大小そのものを直接決めるものではない。
- [x]汎化をパラメータ数だけでなく、解の幾何学的な広がりから考えられる
  R: 特異モデルでは解が単一点ではなく広い集合や退化した谷を形成しうるため、複雑さのペナルティをパラメータ数ではなく谷の幾何学的な広がり（RLCT）から考える動機になる。
S: /series/appendix.6#自由エネルギーと汎化誤差
A: 特異モデルでは解が単一点ではなく、広い集合や退化した谷を形成することがある。自由エネルギーや汎化誤差を、パラメータ数だけでなく幾何学的な広がりから考える動機になる。
```

### Q4. RLCT（Real Log Canonical Threshold、実対数標準閾値）

RLCT（Real Log Canonical Threshold、実対数標準閾値）を「空間の実質的な次元」として読む説明はどれか。

```quiz
- 学習率を決めるハイパーパラメータ
  R: RLCTは学習の最適化アルゴリズムが使うハイパーパラメータではなく、ベイズ自由エネルギーの漸近展開に現れる、モデルの複雑さを表す量である。
- データのクラス数を表す量
  R: RLCTはデータのクラス数のようなタスク設定の量ではなく、損失関数の谷の幾何学的な広さから決まる、特異モデルの漸近的な複雑さを表す量である。
- [x]特異モデルの漸近的な複雑さを表す
  R: RLCTはベイズ自由エネルギーの対数項の係数として現れ、損失関数の谷の幾何学的な広さを反映した、特異モデルの実質的な複雑さを表す。
- パラメータの個数をそのまま数える指標
  R: RLCTはパラメータ数と一致するとは限らず、谷が広ければパラメータ数が多くても小さい値を取りうる、パラメータ数とは異なる複雑さの指標である。
S: /series/appendix.6#rlct-空間の「実質的な次元」
A: RLCTは、特異点を持つモデルの複雑さを、単純なパラメータ数とは異なる形で表す。ベイズ自由エネルギーや汎化誤差の漸近評価に関係する。
```

## 相転移と汎化

### Q5. 学習の相転移

学習の相転移を幾何学的に見ると、何が急に変化しうるか。

```quiz
- 相転移的な変化は訓練損失の値には現れるが、汎化誤差には反映されない
  R: 学習の相転移は学習曲線に現れる階段状の変化であり、ロスだけでなく汎化誤差の推移にも現れる現象として扱われる。
- 学習の相転移は物理学の相転移の比喩にすぎず、対応する数理的な機構は存在しない
  R: 学習の相転移は物理学の相転移との類似が指摘されるだけでなく、特異点付近のプラトーからの脱出という数理的な機構として特異学習理論の枠組みで解析される。
- 相転移が起きる条件はモデル規模のみで決まり、データ量や正則化には依存しない
  R: 学習の相転移は、モデル規模だけでなく正則化やデータ量などの条件の変化によっても学習状態や汎化の振る舞いが急変する現象として扱われる。
- [x]制御パラメータで学習状態が急変する
  R: モデル規模、正則化、データ量などの制御パラメータの変化に応じて、特異点付近のプラトーから脱出し学習状態が急激に変わることがある。
S: /series/appendix.6#学習の相転移
A: モデル規模、正則化、データ量などの変化により、学習の状態や汎化の振る舞いが急に変わることがある。これは比喩ではなく、条件に応じた現象として検討される。
```

### Q6. 特異点解消

特異点解消の数学的な役割として、正しいものはどれか。

```quiz
- 特異点を無視して、正則モデルとして近似する
  R: 特異点解消は特異点を無視して正則モデルで近似する操作ではなく、座標変換によって特異な構造そのものを解析可能な形に展開する操作である。
- 学習データを削除する
  R: 特異点解消はパラメータ空間の座標変換に関する数学的な操作であり、学習データを削除する操作とは無関係である。
- 曲率を0にする
  R: 特異点解消は空間の曲率を一律に0にする操作ではなく、適切な座標変換によって特異点のない滑らかな空間へ展開し、谷の構造を解析可能にする操作である。
- [x]特異な構造を解析しやすい空間へ展開する
  R: 特異点解消はブローアップと呼ばれる座標変換によって、特異点を持つ空間を特異点のない滑らかな空間へ引き伸ばし、RLCTなどの解析を可能にする。
S: /series/appendix.6#特異点解消-裂け目を修復する数学
A: 特異点解消は、特異な空間を解析しやすいチャートへ展開する数学的枠組みである。学習問題へ適用するには、モデルと損失の構造を具体化する必要がある。
```

### Q7. 情報幾何学との統合

特異学習理論と情報幾何学の関係について、適切な説明はどれか。

```quiz
- 情報幾何学のフィッシャー計量は特異点でも正則点と同じ値を取るため、拡張は不要である
  R: フィッシャー情報行列は特異点付近でランク落ちし正則点とは異なる振る舞いをするため、正則性の破れを考慮した理論への拡張が必要になる。
- [x]特異性を含む学習の幾何へ計量を拡張する
  R: 情報幾何学は正則な確率モデルの計量を与えるが、深層学習では退化や特異点が現れるため、両者を接続するには正則性の破れを含む形へ計量の考え方を拡張する必要がある。
- 特異学習理論はベイズ自由エネルギーの漸近展開を扱うが、確率分布そのものは扱わない
  R: 特異学習理論はベイズ推論の枠組みに基づいており、モデルが表す確率分布とデータの尤度を前提として自由エネルギーの漸近展開を論じるため、確率分布と無関係ではない。
- 特異点解消の座標変換を経ると、元のモデルの特異性は解消され正則モデルとして扱える
  R: 特異点解消は解析のために座標変換で滑らかな空間へ展開する操作であり、これによって元のモデルが持つ特異性そのもの（冗長性や識別不能性）が消えて正則モデルになるわけではない。
S: /series/appendix.6#情報幾何学と特異学習理論の統合
A: 情報幾何学は正則な確率モデルの計量を与えるが、深層学習では退化や特異点が現れる。両者を接続するには、正則性の破れを考慮した理論が必要になる。
```

### Q8. 汎化の読み方

同じ関数を表す二つのパラメータ設定で、損失地形の見え方と学習後の汎化が異なった。この結果の読み方として、最も適切なものはどれか。

```quiz
- RLCTの値だけで、タスクの真偽や学習の原因まで決める
  R: RLCTは損失関数の谷の幾何学的な広さを表す量であり、それだけでタスクの真偽や学習結果の原因のすべてを決めるものではない。
- 特異な方向がある設定を選べば、汎化の差を説明できるとみなす
  R: 特異な方向の有無だけに注目すると、データや学習過程など汎化の差に関わる他の要因を見落とすことになる。
- パラメータ数が同じなら、汎化の差は測定誤差とみなす
  R: 特異モデルではパラメータ数が同じでも損失地形の冗長性や谷の広さが異なりうるため、汎化の差を単なる測定誤差として片付けるのは早計である。
- [x]冗長性・解の谷・データ・学習過程を分け、複雑さと汎化を比較する
  R: 同じ関数でもパラメータ空間の冗長性や損失地形の谷の広さは異なりうるため、冗長性、データ、学習過程を分けて実効的な複雑さを調べ、汎化との関係を比較するのが妥当である。
S: /series/appendix.6#まとめ-特異点と汎化の接続
A: 同じ関数でもパラメータ空間の冗長性や損失地形は異なりうる。特異性、データ、学習過程を含む実効的な複雑さを調べ、汎化との関係を比較する必要がある。
```
