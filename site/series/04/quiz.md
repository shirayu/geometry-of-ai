# 第4回 理解度チェック：分類の再統一 I

## 確率空間への写像

### Q1. 確率単体

K個のクラスの確率分布が存在する空間として、確率単体の説明はどれか。

```quiz
- K個の座標が各独立に無限の値を取る空間である
- クラス数によらず1次元の空間である
- [x]各成分が非負で総和が1になる確率ベクトルの集合で、自由度はK-1である
- 各確率が負になることを許す空間である
S: /series/04#確率単体-確率分布の空間
A: 確率ベクトルは各成分が非負で、総和が1という制約を持つ。そのためK個の成分があっても自由に選べるのはK-1個である。
```

### Q2. Softmaxの性質

Softmaxの定義と性質について、正しい説明はどれか。

```quiz
- ロジットの順序を入れ替えても、クラスごとの確率は変わらない
- 一つのクラスの確率だけを1にする
- ロジットの総和を1にするだけで、指数関数は使わない
- [x]ロジットを確率単体上の正の確率へ写し、ロジット全体への同じ定数の加算では出力が変わらない
S: /series/04#softmaxの定義と性質
A: Softmaxは指数関数でロジットの差を確率へ変換し、出力を確率単体に置く。また、すべてのロジットへ同じ値を加えても比が変わらないため、出力は不変である。
```

### Q3. 最大エントロピー原理

制約付き最大エントロピー原理がSoftmaxの理解に与える見方はどれか。

```quiz
- 各クラスを同じ確率に固定する
- [x]与えられた制約のもとで余計な仮定を加えず、最もエントロピーの大きい分布を選ぶと指数型の分布が現れる
- 確率分布ではなく距離関数を直接最適化する
- エントロピーを0にする分布を選ぶ
S: /series/04#制約付きエントロピー最大化
A: 期待値などの制約だけを満たす分布の中でエントロピーを最大化すると、指数型分布が得られる。Softmaxはこの原理と結びつけて解釈できる。
```

## 計量と温度

### Q4. Log-Sum-Exp

Log-Sum-Expが最適化や数値計算で重要な理由はどれか。

```quiz
- 最大のロジット以外をそのまま削除する
- 確率の総和を0にする
- [x]凸性を持つ滑らかな最大値の近似として働き、安定化した計算ではオーバーフローを抑えられる
- どの入力でも線形関数になる
S: /series/04#log-sum-expの凸性-最適化しやすさの源泉
A: Log-Sum-Expは最大値を滑らかに近似する凸関数であり、Softmaxの分母に現れる。最大値を引いてから指数を計算することで数値的な発散も抑えられる。
```

### Q5. 温度パラメータ

Softmaxの温度を下げると、一般に出力分布はどうなるか。

```quiz
- 温度はSoftmaxの出力に影響しない
- 各クラスが一様になる
- [x]最大のロジット付近に確率が集中し、分布が尖る
- クラス間の順位が逆転する
S: /series/04#情報量-確実性からの遠さ
A: 温度はロジットのスケールを調整する。温度を下げると差が強調され、出力は尖るが、尖りがそのまま正しさや情報量の増加を意味するわけではない。
```

### Q6. フィッシャー情報と自然勾配

自然勾配が確率分布の学習に適しているとされる理由はどれか。

```quiz
- 勾配を確率に変換して更新を止める
- 各パラメータ方向を同じ長さで更新する
- ユークリッド空間の座標だけを見て更新する
- [x]フィッシャー情報が定める確率分布空間の計量を使い、分布の変化を考慮して更新する
S: /series/04#自然勾配-幾何学に従った降下
A: フィッシャー情報行列は、パラメータの変化が確率分布をどれだけ変えるかを表す計量になる。自然勾配はその計量に合わせて勾配を調整する。
```

### Q7. Gumbel-Softmax

Gumbel-Softmaxの位置づけとして正しいものはどれか。

```quiz
- [x]離散的な選択を、温度で硬さを調整できる連続的な近似として扱う
- どの温度でも一つのクラスだけを厳密に選ぶ
- 勾配を使わずに離散サンプリングを学習する
- 確率単体をユークリッド空間の外へ写す
S: /series/04#softmaxの定義と性質
A: Gumbel-Softmaxは離散サンプリングを連続的に近似し、温度を下げるほど一つの選択に近づける。近似であるため、温度と勾配の扱いに注意が必要である。
```

### Q8. 構造化予測

系列ラベルの単独精度は高いが、隣接ラベルの組み合わせに不自然な出力が多い。次の改善として、最も適切なものはどれか。

```quiz
- Softmaxの温度だけを調整し、出力構造は評価しない
- 各ラベルの最大確率だけをさらに尖らせる
- ラベル間の依存を無視してクラス数を増やす
- [x]ラベル間の遷移や系列全体の制約を損失・推論へ組み込み、独立予測と比較する
S: /series/04#構造化予測-点から線へ
A: 単独の確率が高くても、系列全体の整合性は別問題である。遷移や構造の制約を含めて評価すると、点ごとの予測と構造化予測の違いを検証できる。
```
