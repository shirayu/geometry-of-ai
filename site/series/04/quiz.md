# 第4回: 分類を確率で読む: Softmaxと情報幾何学（理解度チェック）

## 確率分布の空間への写像

### Q1. 確率単体

K個のクラスの確率分布が存在する空間として、確率単体の説明はどれか。

```quiz
- K個の座標が各独立に無限の値を取る空間である
  R: 確率の各成分は非負かつ総和が1という制約を持つため、各座標が独立に無限の値を取ることはできない。
- クラス数によらず1次元の空間である
  R: 確率単体の次元は総和1の制約によりK-1で、クラス数Kに応じて変わる。1次元に固定されるわけではない。
- [x]非負で総和が1のK次元ベクトルの集合
  R: 確率ベクトルは各成分が非負で総和が1という制約を満たすK次元ベクトルの集合であり、これが確率単体の定義そのものである。
- 各確率が負になることを許す空間である
  R: 確率は非負であることが定義上の制約であり、負の値を許す空間は確率単体ではない。
S: /series/04#確率単体-確率分布の空間
A: 確率ベクトルは各成分が非負で、総和が1という制約を持つ。そのためK個の成分があっても自由に選べるのはK-1個である。
```

### Q2. Softmaxの性質

Softmaxの定義と性質について、正しい説明はどれか。

```quiz
- ロジットの順序を入れ替えても、クラスごとの確率は変わらない
  R: Softmaxはロジットの大小関係に応じて各クラスの確率を割り当てるため、ロジットの並び順を入れ替えれば対応する確率も入れ替わる。
- 一つのクラスの確率を1にする
  R: Softmaxの出力は指数関数の性質上どの成分も0や1にはならず、常に単体の内部にとどまる。
- ロジットの総和を1に正規化し、指数関数は使わない
  R: Softmaxは指数関数でロジットを変換してから総和が1になるよう正規化する関数であり、指数関数を使わずに総和を1にする操作ではない。
- [x]ロジットを確率へ写し、共通の定数加算では出力が変わらない
  R: Softmaxは指数関数によりロジットを確率単体上の点に変換し、すべてのロジットへ同じ定数を加えても比が変わらないため出力は不変である。
S: /series/04#softmaxの定義と性質
A: Softmaxは指数関数でロジットの差を確率へ変換し、出力を確率単体に置く。また、すべてのロジットへ同じ値を加えても比が変わらないため、出力は不変である。
```

### Q3. 最大エントロピー原理

制約付き最大エントロピー原理がSoftmaxの理解に与える見方はどれか。

```quiz
- 各クラスを同じ確率に固定する
  R: 各クラスを同じ確率に固定する一様分布は、制約がない特殊な場合の解であり、一般に期待値などの制約が課された下での最大エントロピー解とは限らない。
- [x]制約下で最もエントロピーの大きい分布を選ぶ
  R: 期待値などの制約だけを満たす分布の中でエントロピーを最大化すると指数型分布族が得られ、これがSoftmaxの形式そのものになる。
- 確率分布ではなく距離関数を直接最適化する
  R: 最大エントロピー原理はエントロピーという確率分布の量を制約下で最大化する枠組みであり、距離関数を最適化する話ではない。
- エントロピーを0にする分布を選ぶ
  R: エントロピーが0になるのは一点に確率が集中する分布であり、これは最も偏った選択であって、制約下でエントロピーを最大化する原理とは逆の方向である。
S: /series/04#制約付きエントロピー最大化
A: 期待値などの制約だけを満たす分布の中でエントロピーを最大化すると、指数型分布が得られる。Softmaxはこの原理と結びつけて解釈できる。
```

## 計量と温度

### Q4. Log-Sum-Exp

Log-Sum-Expが最適化や数値計算で重要な理由はどれか。

```quiz
- 最大値を選ぶ非滑らかな関数で、他のロジットを捨てる
  R: Log-Sum-Expは最大値を滑らかに近似する関数であり、他のロジットの情報も指数和の中に残したまま計算する。最大値だけを選ぶ非滑らかな操作ではない。
- 確率の総和を0にする正規化で、凸性は扱わない
  R: Log-Sum-Expは確率の総和を0にする正規化ではなく、その凸性がクロスエントロピー損失の最適化しやすさを支える中心的な性質である。
- [x]滑らかな最大値の近似で、計算を安定化する
  R: Log-Sum-Expは最大値を滑らかに近似する凸関数であり、最大値を引いてから指数を計算することで数値的な発散を抑え計算を安定化する。
- 入力をそのまま線形変換し、最大値近似は行わない
  R: Log-Sum-Expは指数関数と対数を組み合わせた非線形な演算であり、入力をそのまま線形変換するものではない。
S: /series/04#log-sum-expの凸性-最適化しやすさの源泉
A: Log-Sum-Expは最大値を滑らかに近似する凸関数であり、Softmaxの分母に現れる。最大値を引いてから指数を計算することで数値的な発散も抑えられる。
```

### Q5. 温度調整の条件

Softmaxの温度調整について、最も適切な判断はどれか。

```quiz
- 低温にすると分布が尖り最大クラスの確率が上がるため、予測の正しさも向上する
  R: 低温で分布が尖り最大クラスの確率が上がるのは事実だが、ロジットの順位は変わらないため、もともと誤った予測が正しくなるわけではない。尖りと正しさは別の性質である。
- 高温は学習時に有効だが、推論時には使えない
  R: 温度パラメータは知識蒸留のソフトラベル作成や推論時の多様性確保など、学習と推論のどちらの場面でも目的に応じて調整される。
- [x]温度は分布の鋭さを変えるがロジットの順位は変えないため、蒸留や多様性など目的に応じて選ぶ
<!-- quiz-lint-ignore: length - 「順位不変」と「用途に応じた選択」という2つの正確な性質を両方含むため正解が長くなるのが必然 -->
  R: 温度はロジットのスケールを調整して分布の鋭さを変えるが、ロジットの大小関係そのものは変えないため、蒸留や多様性確保など目的に応じて設定を選ぶ余地がある。
- 温度はロジットの順位を逆転させるので、誤分類の訂正に使える
  R: 温度はロジットのスケールを一様に変える操作であり、大小関係の順位そのものを逆転させることはない。誤分類の訂正に使える根拠にはならない。
S: /series/04#温度パラメータ-分布の鋭さの制御
A: 温度はロジットのスケールを調整し、分布の鋭さを変えるが、尖りがそのまま正しさや情報量の増加を意味するわけではない。知識蒸留のソフトラベルや推論時の多様性など、目的に応じて設定を選ぶ。
```

### Q6. フィッシャー情報と自然勾配

自然勾配が確率分布の学習に適しているとされる理由はどれか。

```quiz
- 勾配を確率に変換して更新を止める
  R: 自然勾配は勾配の向きと大きさをフィッシャー情報行列で補正して更新を続ける手法であり、勾配を確率に変換して更新を止めるものではない。
- 各パラメータ方向を同じ長さで更新する
  R: 自然勾配はフィッシャー情報行列によって方向ごとに異なる補正をかける手法であり、各パラメータ方向を同じ長さで一律に更新するわけではない。
- ユークリッド空間の座標上の距離を基準に更新する
  R: ユークリッド空間の座標だけを見るのは通常の勾配降下法の立場であり、自然勾配はそれと対比される形で確率分布の空間の計量を考慮する。
- [x]分布の変化を測る計量で勾配を調整する
  R: フィッシャー情報行列はパラメータの変化が確率分布をどれだけ変えるかを表す計量であり、自然勾配はこの計量に合わせて勾配を調整する。
S: /series/04#自然勾配-幾何学に従った降下
A: フィッシャー情報行列は、パラメータの変化が確率分布をどれだけ変えるかを表す計量になる。自然勾配はその計量に合わせて勾配を調整する。
```

### Q7. 確率分布の空間の物差し

確率分布の空間で「分布がどれだけ変化したか」を測りたい。パラメータのユークリッド距離ではなく、フィッシャー情報行列をリーマン計量として採用する理由の説明として、最も適切なものはどれか。

```quiz
- ユークリッド距離は分布の変化量を正しく読むので、フィッシャー計量はそれを計算上簡略化した近似である
  R: 順序が逆である。ユークリッド物差しは位置やパラメータの表記の仕方で目盛りが変わり、分布の変化量を正しく読めない。フィッシャー計量は分布の変化量を測るための計量であり、ユークリッド距離の近似ではない。
- KLダイバージェンスは2分布間のユークリッド距離と一致するので、どちらも同じ目的に使える
  R: KLダイバージェンスは一般にユークリッド距離と一致せず、非対称で数学的な意味での距離でもない。フィッシャー計量は、KLダイバージェンスの局所的な2次近似として現れる。
- [x]パラメータの表記の仕方に依存しない形で分布の変化量を測り、この選択は自然な条件の下で実質的に一意である
<!-- quiz-lint-ignore: length - 「座標不変性」と「一意性」という2つの根拠を両方含むため正解が長くなるのが必然 -->
  R: フィッシャー計量は、微小なパラメータ変化が分布をどれだけ変えるかを、座標の選び方に依存せずに定量化する。さらに、統計的な粗視化で距離が増えないという条件を満たす計量は、定数倍を除いてフィッシャー計量に限ることが知られている。
- 対称で三角不等式を満たすことに加え、確率単体の上には他の隔たり尺度を定義できないからである
  R: フィッシャー計量が誘導する距離が距離の公理を満たすのは事実だが、それは選択の理由ではない。確率単体の上にはKLダイバージェンスなど他の隔たり尺度も定義できる。
S: /series/04#fisher情報行列-確率分布の空間の計量
A: ユークリッド物差しは、目盛りが位置やパラメータの表記に依存するため、分布の変化量を読めない。フィッシャー計量は座標の選び方に依存せず分布の変化量を測り、統計的な粗視化で距離が増えないという条件の下では実質的に一意な選択であることが知られている。
```

### Q8. Gumbel-Softmax（微分可能な離散サンプリング手法）

Gumbel-Softmax（微分可能な離散サンプリング手法）の位置づけとして正しいものはどれか。

```quiz
- [x]離散選択を温度で調整できる連続近似として扱う
  R: Gumbel-Softmaxは離散サンプリングを連続的に近似する手法であり、温度を下げるほど一つの選択に近づく調整可能な近似として位置づけられる。
- 温度によらず一つのクラスを厳密に選ぶ
  R: Gumbel-Softmaxが厳密に一つのクラスへ収束するのは温度を0に近づける極限の場合であり、通常の温度では単体内部に分布が広がる連続近似にとどまる。
- 勾配を使わずに離散サンプリングを学習する
  R: Gumbel-Softmaxは離散的なargmaxが微分不可能であるという問題を、連続緩和によって勾配が流れるようにする手法であり、勾配を使わない学習ではない。
- 確率単体をユークリッド空間の外へ写す
  R: Gumbel-Softmaxはノイズを加えたロジットをSoftmaxで確率単体上に写す操作であり、Softmax自体が単体の内部に値をとる写像である点は変わらない。
S: /series/04#離散への着地-gumbel-softmaxとサンプリング
A: Gumbel-Softmaxは離散サンプリングを連続的に近似し、温度を下げるほど一つの選択に近づける。近似であるため、温度と勾配の扱いに注意が必要である。
```

### Q9. 構造化予測

系列ラベルの単独精度は高いが、隣接ラベルの組み合わせに不自然な出力が多い。次の改善として、最も適切なものはどれか。

```quiz
- Softmaxの温度を調整し、出力構造は評価しない
  R: 温度調整は各時刻の分布の鋭さを変えるだけで、隣接ラベル間の整合性という系列全体の構造には作用しないため、指摘された問題の解決にはならない。
- 各ラベルの最大確率をさらに尖らせ、それを構造化予測の代わりとする
  R: 各時刻で独立に確率を尖らせても、時刻をまたいだラベルの組み合わせの整合性は評価されないため、隣接ラベルの矛盾は解消されない。
- ラベル間の依存を無視してクラス数を増やす
  R: クラス数を増やすことはラベル間の依存関係を扱う仕組みを追加するものではなく、隣接ラベルの不自然な組み合わせという問題の原因に対処していない。

  R: 遷移ポテンシャルのような形でラベル間の制約を損失や推論に組み込むと、系列全体の整合性を評価でき、点ごとの独立な予測では捉えられない矛盾を防げる。
S: /series/04#構造化予測-点から線へ
A: 単独の確率が高くても、系列全体の整合性は別問題である。遷移や構造の制約を含めて評価すると、点ごとの予測と構造化予測の違いを検証できる。
```
