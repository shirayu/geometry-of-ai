# 第1回 理解度チェック：かつての地図

## 平らな空間の道具

### Q1. PCAの基本原理

PCAが最初に選ぶ方向として正しいものはどれか。

```quiz
- クラス間距離が最小になる方向
- 元の座標軸のうち最初に現れる方向
- 各データ点を同じ確率で通る方向
- [x]中心化したデータの分散が最大になる方向
S: /series/01#pcaの幾何学的解釈
A: PCAは中心化したデータの分散が最大になる方向を主成分として選ぶ。複数の主成分は互いに直交し、射影による情報損失を抑えながら次元を下げる。
```

### Q2. PCAの影絵

PCAを「影絵」と呼ぶことの意味として、最も適切なのはどれか。

```quiz
- 射影方向を変えても、見える構造は同じである
- PCAは非線形な曲がりを正確に展開する
- PCAは元のデータをそのまま保存したまま表示する
- [x]高次元の構造を低次元へ線形射影するため、見やすくなる一方で情報の一部が失われる
S: /series/01#pcaの幾何学的解釈
A: PCAは分散の大きい方向を残す線形射影である。低分散方向の情報や非線形な構造が失われる可能性があり、得られた影を元の形そのものと見なしてはいけない。
```

### Q3. PCAの前提

PCAが捉えやすい構造と、捉えにくい構造の組み合わせはどれか。

```quiz
- どのような非線形構造でも、主成分だけでそのまま表現できる
- 分散が小さい方向ほど、意味がない
- データの中心化はPCAの結果に影響しない
- [x]線形な広がりは捉えやすいが、曲がった多様体や分散の小さい重要な構造は捉えにくい
S: /series/01#pcaの暗黙の前提
A: PCAは線形射影と分散を中心に構造を捉える。非線形な構造や、分散は小さくてもタスクに重要な方向を落とす可能性がある。
```

## 曲がった構造と境界

### Q4. IsomapとLLE

IsomapとLLEがPCAと異なる点として、適切な説明はどれか。

```quiz
- どちらもデータを球面上へ正規化する
- どちらも全データの分散最大方向だけを使う
- [x]近傍関係や局所構造を使い、曲がったデータ構造を低次元で表そうとする
- どちらもクラスラベルが必須である
S: /series/01#isomap-と-lle-によるスイスロールの展開
A: Isomapは近傍グラフから測地線距離を近似し、LLEは局所的な線形再構成を保つ。どちらも、全体を一つの平面へ射影するPCAの限界を補おうとする。
```

### Q5. SVMのマージン

SVMが分類境界を選ぶ原理として、正しいものはどれか。

```quiz
- クラスごとの平均だけを一致させる
- [x]最も近いデータ点までの距離であるマージンを最大化する
- 確率分布のエントロピーを最大化する
- 訓練データから最も遠い点を境界上に置く
S: /series/01#svmの幾何学-マージン最大化
A: SVMは境界と各クラスの最近傍点との距離を広くする。境界を直接当てはめるだけでなく、分類のゆとりを最大化する幾何学的設計である。
```

### Q6. カーネルトリック

カーネルトリックの幾何学的な意味はどれか。

```quiz
- [x]高次元の特徴空間での内積を、特徴を明示的に構成せずに計算する
- 元の入力空間を低次元へ圧縮する
- 距離や内積を使わずに分類する
- データを線形分離可能にする手法である
S: /series/01#カーネルトリック-暗黙の高次元空間
A: カーネル関数は、明示的な特徴写像を作らずに高次元特徴空間の内積を計算する。非線形な境界を扱えるが、適切なカーネルと計算量の制約がある。
```

## 離散的な地図の限界

### Q7. Bag-of-Words

Bag-of-Wordsの表現が失う情報はどれか。

```quiz
- 文書をベクトルとして扱うこと
- 語彙に含まれる単語の種類
- 単語の出現頻度
- [x]単語の出現順序や文脈の構造
S: /series/01#言語を数にする
A: Bag-of-Wordsは単語の頻度を数える一方、並び順や文脈を捨てる。「犬が人を追う」と「人が犬を追う」の違いを表しにくいのが典型的な限界である。
```

### Q8. 古典手法から得られる教訓

PCAの二次元表示ではクラスが混ざるが、近傍関係は保たれているように見える。この結果への対応として、最も適切なものはどれか。

```quiz
- 近傍関係を捨て、分散の大きい方向だけを残す
- 非線形手法へ移れば、どの構造も同じ基準で比較できるとみなす
- PCAの表示だけでクラス分離がないと結論づける
- [x]線形射影と分散基準の限界を確認し、近傍構造を保つ方法や元空間の評価と比較する
S: /series/01#まとめ-平らな世界の限界
A: PCAの表示は分散を保つ線形射影であり、近傍やクラス構造を直接保証しない。目的に応じて、射影の前提と別の構造保存基準を比較する必要がある。
```
