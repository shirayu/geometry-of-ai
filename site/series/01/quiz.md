# 第1回 理解度チェック：かつての地図

## 平らな空間の道具

### Q1. 主成分分析（PCA: Principal Component Analysis）の基本原理

主成分分析（PCA: Principal Component Analysis）が最初に選ぶ方向として正しいものはどれか。

```quiz
- クラス間距離が最小になる方向
  R: PCAはクラスラベルを一切使わない教師なし手法であり、クラス間距離という概念そのものを目的関数に含まない。
- 元の座標軸のうち最初に現れる方向
  R: PCAはデータから新しい方向を計算して選ぶ手法であり、元の座標軸の並び順とは無関係である。
- 各データ点を同じ確率で通る方向
  R: PCAは分散という統計量に基づいて方向を選ぶのであり、各点を通る確率という基準は用いていない。
- [x]中心化したデータの分散が最大になる方向
  R: PCAは中心化したデータの共分散行列を固有値分解し、分散が最大になる方向を第1主成分として選ぶ。
S: /series/01#pcaの幾何学的解釈
A: PCAは中心化したデータの分散が最大になる方向を主成分として選ぶ。複数の主成分は互いに直交し、射影による情報損失を抑えながら次元を下げる。
```

### Q2. PCAの影絵

PCAを「影絵」と呼ぶことの意味として、最も適切なのはどれか。

```quiz
- 分散が最大の方向を選んでいるため、影の中でも元の距離関係は保たれやすい
  R: PCAは線形射影であり、低分散方向の距離情報を落とすため、影の中で元の距離関係が保たれるとは限らない。
- 主成分の数を増やしていけば、影は元の形に近づき、非線形な曲がりも展開できる
  R: 主成分を増やせば再構成誤差は減っていくが、PCAはあくまで線形射影であり、非線形な曲がりを展開する仕組みは持たない。
- 分散が最大の方向を選ぶ射影なので、失われる情報は低分散方向に限られ、実害はない
  R: PCAで失われる情報が低分散方向に集中するのは事実だが、分散が小さくてもタスクにとって重要な構造が含まれる場合があり、低分散方向だからといって実害がないとは言えない。
- [x]高次元の構造を低次元へ線形射影するため、見やすくなる一方で情報の一部が失われる
  R: 影絵が3次元の物体を2次元の壁に投影して一部の情報を失うのと同様に、PCAも高次元構造を低次元へ線形射影することで見やすくなる一方、情報の一部を失う。
S: /series/01#pcaの幾何学的解釈
A: PCAは分散の大きい方向を残す線形射影である。低分散方向の情報や非線形な構造が失われる可能性があり、得られた影を元の形そのものと見なしてはいけない。
```

### Q3. PCAの前提

PCAが捉えやすい構造と、捉えにくい構造の組み合わせはどれか。

```quiz
- 線形な広がりは捉えにくいが、曲がった多様体や分散の小さい重要な構造は捉えやすい
  R: PCAが捉えやすいものと捉えにくいものの関係が逆になっている。PCAは線形な広がりを捉えやすく、非線形な多様体や低分散の構造はむしろ捉えにくい。
- 分散が小さい方向ほど、意味がない
  R: 分散が小さい方向にも、分類などのタスクに重要な情報が隠れていることがあり、分散の大小だけで意味の有無を判断することはできない。
- データの中心化はPCAの結果に影響しない
  R: PCAは中心化したデータの共分散行列を用いる手続きであり、中心化を行わなければ主成分の方向は正しく求まらない。
- [x]線形な広がりは捉えやすく、非線形や低分散の構造は捉えにくい
  R: PCAは線形射影しか行えないため、データが非線形な多様体上に分布している場合や、分散は小さくてもタスクに重要な方向がある場合には構造を捉えにくい。
S: /series/01#pcaの暗黙の前提
A: PCAは線形射影と分散を中心に構造を捉える。非線形な構造や、分散は小さくてもタスクに重要な方向を落とす可能性がある。
```

## 曲がった構造と境界

### Q4. Isomapの近傍数kの選択

Isomapをスイスロールのような多様体データへ適用するとき、近傍数kの選択について最も適切な判断はどれか。

```quiz
- [x]kが小さすぎるとグラフが疎になり、大きすぎるとショートカットが生まれるため、データの構造に合わせて確認する
<!-- quiz-lint-ignore: length - kの過小・過大という両側の失敗モードを正確に述べるため正解が長くなるのが必然 -->
  R: Isomapはk近傍グラフで測地線距離を近似するため、kが小さいとグラフが疎になり測地距離を推定しにくくなり、大きいと多様体上では遠い点同士を結ぶショートカットが生じるため、データごとに適切なkを確認する必要がある。
- kは計算量には影響するが、展開結果の形には影響しない
  R: kは近傍グラフの構造そのものを決めるため、計算量だけでなく測地距離の近似精度や展開結果の形にも直接影響する。
- kは大きいほど大域的な構造を捉えるので、できるだけ大きく選ぶ
  R: kを大きくしすぎると空間的には近いが多様体上では遠い点同士を結ぶショートカットが生まれ、かえって大域的な構造を歪めてしまう。
- 適切なkはデータ点の数から事前に計算でき、データの形には依存しない
  R: 適切なkはデータの密度や多様体の曲がり方といった構造に依存するため、データ点数だけから一律に計算できるものではない。
S: /series/01#isomap-と-lle-によるスイスロールの展開
A: Isomapはk近傍グラフで測地線距離を近似する。kが小さすぎるとグラフが疎になり、大きすぎると空間的には近く多様体上では遠い点同士を結ぶ「ショートカット」が生まれる。万能な選び方はなく、データの構造に合わせて確認が必要である。
```

### Q5. サポートベクターマシン（SVM: Support Vector Machine）のマージン

サポートベクターマシン（SVM: Support Vector Machine）が分類境界を選ぶ原理として、正しいものはどれか。

```quiz
- クラスごとの平均を一致させる
  R: SVMは境界と最近傍点との距離を扱うマージン最大化の手続きであり、クラスの平均を一致させることを目的としているわけではない。
- [x]最近傍点までの最小距離を最大化する
  R: SVMは境界から両クラスの最近傍点（サポートベクター）までの距離であるマージンを最大化するように超平面を選ぶ。
- 確率分布のエントロピーを最大化する
  R: エントロピー最大化は確率分布を扱う別の枠組みの発想であり、SVMの目的関数はマージンという幾何学的な距離に基づく。
- 訓練データから最も遠い点を境界上に置く
  R: SVMの境界を支えるのは最も遠い点ではなく、境界に最も近いサポートベクターであり、この説明は逆になっている。
S: /series/01#svmの幾何学-マージン最大化
A: SVMは境界と各クラスの最近傍点との距離を広くする。境界を直接当てはめるだけでなく、分類のゆとりを最大化する幾何学的設計である。
```

### Q6. カーネルトリック

カーネルトリックの幾何学的な意味はどれか。

```quiz
- [x]特徴空間の内積を使い、非線形な分離を扱う
  R: カーネル関数は明示的な特徴写像を作らずに特徴空間での内積を計算し、その類似度を使って元の入力空間では非線形な関係を分離しやすくする。
- 元の入力空間を低次元へ圧縮する
  R: カーネルトリックはむしろ元の空間をより高次元、場合によっては無限次元の特徴空間へ写像する発想であり、低次元への圧縮とは逆の方向である。
- 距離や内積を使わずに分類する
  R: カーネル関数はまさに特徴空間での内積を計算する仕組みであり、内積を使わずに分類するという説明は成り立たない。
- 元の入力空間で直接、線形分離を行う
  R: カーネルトリックが必要になるのは元の入力空間で直接線形分離ができない場合であり、暗黙の高次元特徴空間での分離を可能にする点が要点である。
S: /series/01#カーネルトリック-暗黙の高次元空間
A: カーネル関数は、明示的な特徴写像を作らずに特徴空間の内積を計算する。幾何学的には、その類似度を使って元の入力では非線形な関係を分離しやすくする。適切なカーネルと計算量の制約もある。
```

## 離散的な地図の限界

### Q7. Bag-of-Words

Bag-of-Wordsの表現が失う情報はどれか。

```quiz
- 文書をベクトルとして扱うこと
  R: 文書をベクトルとして扱うこと自体はBag-of-Wordsの表現方法そのものであり、失われる情報ではない。
- 語彙に含まれる単語の種類
  R: Bag-of-Wordsは各単語の出現有無や頻度を数える表現であり、語彙に含まれる単語の種類そのものは保持している。
- 単語の出現頻度
  R: 単語の出現頻度こそがBag-of-Wordsが数え上げて保持する情報であり、失われる情報ではない。
- [x]単語の出現順序や文脈の構造
  R: Bag-of-Wordsは単語の頻度を数える一方で並び順を無視するため、「犬が人を追う」と「人が犬を追う」のような順序による意味の違いを表現できない。
S: /series/01#言語を数にする
A: Bag-of-Wordsは単語の頻度を数える一方、並び順や文脈を捨てる。「犬が人を追う」と「人が犬を追う」の違いを表しにくいのが典型的な限界である。
```

### Q8. 古典手法から得られる教訓

PCAの二次元表示ではクラスが混ざるが、近傍関係は保たれているように見える。この結果への対応として、最も適切なものはどれか。

```quiz
- 近傍関係を捨て、分散の大きい方向を残す
  R: 近傍関係が保たれているように見えるという観察結果を活かさずに切り捨ててしまうと、分散以外の構造的な手がかりを失うことになる。
- 非線形手法へ移れば、どの構造も同じ基準で比較できるとみなす
  R: 非線形手法もそれぞれ異なる基準（測地距離や局所線形関係など）で構造を保存するのであり、手法を変えただけで全ての構造が同じ基準で比較できるようになるわけではない。
- PCAの表示からクラス分離がないと結論づける
  R: PCAは分散を保つ線形射影に過ぎず、クラスが混ざって見えても近傍関係は保たれている場合があるため、この表示だけでクラス分離の有無を断定するのは早計である。
- [x]分散と近傍構造を別々に評価し、元空間とも比較する
  R: PCAの表示は分散を保つ射影であり近傍やクラス構造を直接保証しないため、分散の保持と近傍構造の保持を別々に評価し、必要なら元の空間での構造とも比較するのが適切である。
S: /series/01#まとめ-平らな世界の限界
A: PCAの表示は分散を保つ線形射影であり、近傍やクラス構造を直接保証しない。目的に応じて、射影の前提と別の構造保存基準を比較する必要がある。
```
