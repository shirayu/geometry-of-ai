# 第5回 理解度チェック：分類の再統一 II

## マージンの幾何学

### Q1. SVMのマージン

SVMの最大マージン原理が選ぶ境界として、正しいものはどれか。

```quiz
- 訓練例を各境界上に置く境界
- クラスの重心から最も遠い境界
- [x]最も近い訓練例までの距離をできるだけ大きくする境界
- 確率が一様になる境界
S: /series/05#マージンとは何か-最も「ゆとり」のある境界線
A: SVMは境界の近くにあるサポートベクターまでの距離をマージンとして最大化する。境界からのゆとりを確保することで、未知データへの頑健性を狙う。
```

### Q2. サポートベクター

サポートベクターの役割として、適切な説明はどれか。

```quiz
- 各クラスの重心にある訓練例
- 学習から除外される外れ値だけを指す
- 推論時に新しく生成されるデータ点
- [x]決定境界に最も近く、最大マージンの位置を決める訓練例
S: /series/05#幾何学的解釈
A: 最大マージンの境界は、境界に近い例の位置に強く制約される。そのため、すべての訓練例ではなく、支柱となる例が境界を決める。
```

### Q3. 球面上のマージン

表現と分類重みを正規化して球面上で分類する場合、マージンは主に何を調整するか。

```quiz
- [x]ベクトル間の角度に基づくクラス間の余裕
- 各ベクトルのノルムを無制限に大きくする量
- 入力データの個数
- クラス確率の総和
S: /series/05#空間を変えると何が変わるか
A: ノルムを揃えると内積のスケール差が抑えられ、分類境界を角度として解釈しやすくなる。マージンは角度方向の分離を強める役割を持つ。
```

### Q4. ArcFaceのアイデア

ArcFaceが導入するマージンの特徴はどれか。

```quiz
- 各クラスのノルムを異なる値に学習させる
- [x]正解クラスの角度に加法的な余裕を課し、球面上でクラスをより離す
- 正解クラスの確率を学習前に1へ固定する
- ユークリッド距離を使って角度を無視する
S: /series/05#従来のsoftmax分類器の限界
A: ArcFaceは正解クラスの角度にマージンを加えることで、正解方向をより厳しい条件で近づける。球面上のクラス間分離を明示的に強化する設計である。
```

## 手法を比較する

### Q5. 角度マージン手法の違い

ArcFace、CosFace、SphereFaceの説明として、最も妥当なものはどれか。

```quiz
- 式は同じで、名前だけが異なる
- いずれもSVMとは無関係な確率モデルである
- [x]いずれも角度やコサインに基づく分離を強めるが、マージンの入れ方が異なる
- いずれもノルムを学習してクラスを分ける手法である
S: /series/05#幾何学的解釈
A: これらの手法は角度中心の分類という共通した考えを持つ。一方、角度への加法やコサインへの加法など、マージンの実装方法は異なる。
```

### Q6. SVMとArcFace

SVMとArcFaceの関係について、適切な説明はどれか。

```quiz
- ArcFaceはSVMの双対問題をそのまま解いている
- SVMは角度を扱えず、ArcFaceは距離を扱えない
- 両者は同じ損失関数を使うため区別できない
- [x]最大の余裕を求める精神は共通するが、最適化問題と分類器の構造は異なる
S: /series/05#共通する精神
A: 両者はクラス間の境界に余裕を持たせる発想を共有する。しかし、SVMは古典的なマージン最適化、ArcFaceはニューラル分類器に組み込む角度マージンであり、問題の構造は同じではない。
```

### Q7. 確率と幾何

ArcFaceを確率モデルか幾何モデルかのどちらか一方に限定しない説明はどれか。

```quiz
- [x]Softmaxによる確率的な出力に、球面上の角度マージンという幾何的制約を組み合わせる
- 確率を使わず、境界だけを決める手法である
- 幾何を使わず、クラス頻度だけで確率を決める
- 角度マージンを入れると確率解釈は失われる
S: /series/05#arcfaceによる統計-確率-と幾何-マージン-の統合
A: ArcFaceは分類確率を出力する枠組みに、正規化された特徴と角度マージンを組み込む。統計的な出力と幾何的な分離を接続する設計と見なせる。
```

### Q8. 数値安定性

ArcFaceの学習で、正規化後の内積がごくまれに1.0000001になり、損失がNaNになった。最初に確認・修正すべきことはどれか。

```quiz
- 正規化を外してノルムの差を角度へ含める
- [x]内積を定義域へクリップし、角度計算とSoftmaxの数値安定性を確認する
- NaNが出たバッチを除外し、学習率や入力分布は調べない
- マージンを大きくして、丸め誤差を損失へ吸収させる
S: /series/05#数値安定なarcface
A: 正規化ベクトルの内積は理論上の範囲を丸め誤差で外れることがある。定義域へのクリップと安定した指数計算を確認し、原因を隠す変更は避ける。
```
