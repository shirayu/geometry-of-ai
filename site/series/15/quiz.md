## 旅を振り返る

### Q1. 空間の形を問う

表現空間を設計するときの問いとして、最も適切なものはどれか。

```quiz
- 各タスクをユークリッド距離で評価する
- 空間の選択は学習結果と無関係だと仮定する
- [x]表現の空間と、使う距離・測地線・曲率を問う
- 最新モデルのアーキテクチャ名を空間設計の指標にする
S: /series/15#まとめ-3つの原則
A: 手法は変わっても、表現を置く空間と測り方は設計の中心にある。空間の形を問うことが、手法に依存しない見方になる。
```

### Q2. 連続と離散の界面

深層学習における連続と離散の界面が未解決問題になる理由はどれか。

```quiz
- 離散化は出力の選び方だけの問題であり、勾配の扱いには影響しないから
- Gumbel-Softmaxのような連続緩和を使えば、離散化の曖昧さは解消されるから
- [x]離散化で曖昧さや勾配の扱いが変わる
- 離散化のタイミングを変えても、曖昧さや勾配の扱いへの影響は同程度だから
S: /series/15#問い2-離散と連続の最適な界面は
A: 離散化は出力を選びやすくする一方、候補間の曖昧さや勾配の切断を伴う。どの時点で離散化するかは今後の設計課題である。
```

### Q3. 統一多様体

異なるモダリティを統合する設計について、最も慎重な説明はどれか。

```quiz
- 共有空間があれば統合の質も同じ基準で評価できる
- [x]共有空間だけでなく、固有空間を橋渡しする設計も検討する
- 共有空間の次元を増やせば、固有空間の橋渡しと同じ効果が得られる
- 統合の目的が検索であれば、固有構造の扱いはタスクによらず同じでよい
S: /series/15#問い1-統一多様体は存在するのか
A: 共有空間は比較を容易にするが、固有構造を圧縮する可能性がある。各空間を保った翻訳やブリッジの方が適切な場合もある。
```

### Q4. 曲率の学習

曲率を学習する設計が難しい理由はどれか。

```quiz
- [x]曲率が距離と最適化の幾何を変える
- 曲率を学習するとユークリッド空間になるから
- 曲率は表現に影響しないから
- 曲率はデータ構造と無関係だから
S: /series/15#問い4-曲率は学習可能か
A: 曲率は単なる表示上のパラメータではなく、距離や測地線を変える。学習可能にする場合、表現と計量が同時に変わることへの対処が必要である。
```

### Q5. MoE（Mixture of Experts、専門家混合）の先

MoE（Mixture of Experts、専門家混合）の次にある設計課題として、適切な問いはどれか。

```quiz
- 各Expertを同じ役割にするか
- Expertを増やせば学習が不要になるか
- スパース性をそのまま排除するか
- [x]Expert選択と連続表現を接続する方法
S: /series/15#問い5-moeの先にあるものは
```

### Q6. 幾何学の限界

幾何学的な分析だけでは保証できないものはどれか。

```quiz
- 表現間の距離や角度
- 空間の曲率やトポロジー
- [x]現実に対する予測の正しさ
- 分布の広がりや集中度
S: /series/15#_2-数式を恐れるな、しかし数式に溺れるな
A: 幾何学は表現の形や関係を測る強力な道具だが、正しさや因果性を自動的に保証するものではない。外部評価と組み合わせる必要がある。
```

### Q7. 幾何学と厳密性

数式と直感を併用する理由として、適切なものはどれか。

```quiz
- 直感は初期の設計判断に使い、厳密な数式は後段の実装検証だけに使う
- 直感的に正しく見える主張は、数式で確認しなくても採用してよい
- [x]直感を厳密な条件で検証する
- 数式で導出できた性質は、適用条件を確認しなくても任意のデータに当てはまる
S: /series/15#_2-数式を恐れるな、しかし数式に溺れるな
A: 直感は新しい空間を理解する入口になり、数式はその射程と限界を明らかにする。どちらか一方だけでは設計の検証が不十分になる。
```

### Q8. 次のプラネタリウム

新しいモデルの候補が、球面では検索に強く、双曲空間では階層分類に強い。次の設計判断として、最も適切なものはどれか。

```quiz
- 空間の候補と計量を先に固定し、コストは明示せずに精度の数値だけを比較する
- [x]タスクの構造とコストを明示し、空間・計量・出力を比較する
- 検索と階層分類のどちらか一方を選び、他の指標は比較しない
- 候補空間を一つに固定し、評価指標も変更しない
S: /series/15#_3-次のプラネタリウムを建てよう
A: 空間の選択はタスクの構造、計量、出力の形式、計算コストと結びつく。単一の空間を信奉せず、目的ごとの評価で設計を決める。
```
