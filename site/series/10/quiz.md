# 第10回 理解度チェック：思考の連鎖

## 推論を経路として見る

### Q1. One-shotとMulti-step

One-shot推論とMulti-step推論の違いとして、適切な説明はどれか。

```quiz
- 両者は中間表現の有無に違いがない
- [x]直接答えるか、中間段階で問題を分解するかの違い
- Multi-stepでは計算量が増えない
- One-shotは正しく、Multi-stepは誤る
S: /series/10#multi-step推論-足場を使った旅
A: Multi-step推論は中間の足場を使うことで、問題を小さな段階へ分けられる。計算量や誤りの蓄積が増えるため、常に有利とは限らない。
```

### Q2. Chain of Thought（CoT、思考の連鎖）

Chain of Thought（CoT、思考の連鎖）の本質を説明したものはどれか。

```quiz
- 推論時の計算を一回に制限する
- 最終回答だけを短く出力する
- モデル内部の連続状態の軌道をそのまま観測する
- [x]中間トークンを足場にして段階的に推論する
S: /series/10#cotとは何か
A: CoTは中間的な言語トークンを通じて推論段階を表す。ただし、出力されたテキストが内部で実際に行われた計算を完全に反映するとは限らない。
```

### Q3. Test-time Compute Scaling

推論時の計算量を増やす方法として、適切なものはどれか。

```quiz
- 各モデルのパラメータを再学習する方法
- 学習率だけを増やす方法
- 入力データの次元を半分にする方法
- [x]推論時の生成や探索に計算を追加する
S: /series/10#計算量を増やす方法-分類
A: Test-time scalingには、長い推論、複数試行、木探索、検証と修正などがある。増やす計算の対象によって効果やコストは異なる。
```

### Q4. HMM（Hidden Markov Model、隠れマルコフモデル）との対比

HMM（Hidden Markov Model、隠れマルコフモデル）とTransformerによるCoTの対比として、適切な説明はどれか。

```quiz
- 両者は同じ確率モデルで、同じ依存構造を持つ
- HMMは大域的な依存を一度に扱い、局所制約を持たない
- [x]HMMは局所依存、Transformerは広域参照する
- Transformerは隠れ状態を持たず、出力だけを計算する
S: /series/10#transformerとcot-大域的な文脈
A: HMMの基本的な状態遷移は局所的な依存を持つ。一方、TransformerはAttentionで離れたトークン間の関係を参照できるため、広い文脈の推論を表しやすい。
```

## 探索と縮退

### Q5. ビームサーチの選択条件

デコーディング戦略の選択について、ビームサーチに関する最も適切な判断はどれか。

```quiz
- 可能な経路をすべて列挙するので、大域的に最良の系列を見つけられる
- ビーム幅を大きくするほど、計算量は減少する
- [x]貪欲法の局所最適を避けられるが、ビーム幅に応じて計算量が増えるため、正確性重視のタスクかで選ぶ
- ビームサーチは多様な経路をサンプリングするので、創作のように多様性が欲しいタスクに向く
S: /series/10#ビームサーチ-複数経路の同時探索
A: ビームサーチは上位候補を複数保持し、貪欲法が陥りやすい局所最適に対処する。ただし、ビーム幅が大きいほど計算量は増え、確実さ重視の探索であるため、多様性が欲しいタスクではTop-kサンプリングなどの戦略が候補になる。
```

### Q6. Model Collapse

Model Collapseの説明として、正しいものはどれか。

```quiz
- モデルが訓練データに過学習し、検証精度が下がる問題
- [x]生成データの再学習で分布の多様性が失われる
- 生成データを再学習に使うことで、むしろ元の分布より多様性が高まる現象
- モデルが大きくなる現象
S: /series/10#現象の説明
A: Model Collapseは、生成物に偏ったデータを繰り返し学習することで、元の分布にあった多様性が失われる問題である。表現の次元縮退とは別の現象である。
```

### Q7. Dimensional Collapse

Dimensional Collapseを検出する指標として、適切なものはどれか。

```quiz
- ビーム幅だけを増やす
- 生成された文章の文字数だけを数える
- [x]表現の特異値や有効ランクを調べる
- クラスラベルの頻度だけを調べる
S: /series/10#検出方法-特異値分解
A: 表現の特異値が一部の方向に偏ると、有効な次元が縮む。特異値分解や有効ランクは、この縮退を量的に調べる手がかりになる。
```

### Q8. 幾何学的比喩の限界

長いCoTは短いCoTより正答率が上がるが、誤答も長くなった。この現象を調べる方針として、最も適切なものはどれか。

```quiz
- 出力の長さだけを増やし、途中の検証は加えない
- CoTを滑らかな曲線として可視化し、離散的な出力の誤りを説明する
- 長い出力は内部計算も多いとみなし、正答率だけで原因を決める
- [x]推論段階・検証・探索コスト・誤りを分けて評価する
S: /series/10#幾何学的解釈-比喩
A: 長さと正答率の相関だけでは、検証の効果と誤りの蓄積を分けられない。出力トークン列、内部状態、探索手順を区別して評価する必要がある。
```
