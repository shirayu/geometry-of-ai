# 第10回 理解度チェック：思考の連鎖

## 推論を経路として見る

### Q1. One-shotとMulti-step

One-shot推論とMulti-step推論の違いとして、適切な説明はどれか。

```quiz
- One-shotは必ず正しく、Multi-stepは必ず誤る
- Multi-stepでは計算量が増えない
- [x]前者は直接答えを出し、後者は中間状態や段階を使って複雑な問題を分解する
- 両者は中間表現の有無に違いがない
S: /series/10#multi-step推論-足場を使った旅
A: Multi-step推論は中間の足場を使うことで、問題を小さな段階へ分けられる。計算量や誤りの蓄積が増えるため、常に有利とは限らない。
```

### Q2. Chain of Thought

Chain of Thoughtの本質を説明したものはどれか。

```quiz
- モデル内部の連続状態の軌道を完全に観測する
- 最終回答だけを短く出力する
- 推論時の計算を常に一回に制限する
- [x]中間トークン列を足場として使い、複数段階の推論を明示的に進める
S: /series/10#cotとは何か
A: CoTは中間的な言語トークンを通じて推論段階を表す。ただし、出力されたテキストが内部で実際に行われた計算を完全に反映するとは限らない。
```

### Q3. Test-time Compute Scaling

推論時の計算量を増やす方法として、適切なものはどれか。

```quiz
- [x]生成トークン数、サンプリング回数、探索幅、検証回数などを増やす方法
- 学習率だけを増やす方法
- 入力データの次元を必ず半分にする方法
- すべてのモデルのパラメータを再学習する方法
S: /series/10#計算量を増やす方法-分類
A: Test-time scalingには、長い推論、複数試行、木探索、検証と修正などがある。増やす計算の対象によって効果やコストは異なる。
```

### Q4. HMMとの対比

HMMとTransformerによるCoTの対比として、適切な説明はどれか。

```quiz
- HMMは必ず大域的な依存を一度に扱う
- [x]HMMは局所的なマルコフ依存を基本とし、TransformerはAttentionで広い文脈の関係を直接参照できる
- Transformerは隠れ状態を持てない
- 両者は同じ確率モデルである
S: /series/10#transformerとcot-大域的な文脈

```

## 探索と縮退

### Q5. ビームサーチ

ビームサーチが貪欲法と異なる点はどれか。

```quiz
- 常に最初の一手だけで最終解を決める
- すべての可能な経路を完全列挙することを保証する
- [x]複数の候補経路を保持し、各段階で有望な経路を比較する
- 確率を使わず、ランダムに一経路を選ぶ
S: /series/10#ビームサーチ-複数経路の同時探索
A: ビームサーチは上位候補を複数保持することで、局所的に最良な選択が後で不利になる可能性に対処する。ビーム幅が大きいほど計算量も増える。
```

### Q6. Model Collapse

Model Collapseの説明として、正しいものはどれか。

```quiz
- 表現ベクトルの特異値が均等になる現象
- 推論時に複数経路を探索する方法
- モデルが必ず大きくなる現象
- [x]生成データを再学習に使い続けることで、データ分布の多様性や裾野が失われる現象
S: /series/10#現象の説明
A: Model Collapseは、生成物に偏ったデータを繰り返し学習することで、元の分布にあった多様性が失われる問題である。表現の次元縮退とは別の現象である。
```

### Q7. Dimensional Collapse

Dimensional Collapseを検出する指標として、適切なものはどれか。

```quiz
- [x]表現行列の特異値分解や有効ランクを調べる
- 生成された文章の文字数だけを数える
- ビーム幅だけを増やす
- クラスラベルの頻度だけを調べる
S: /series/10#検出方法-特異値分解
A: 表現の特異値が一部の方向に偏ると、有効な次元が縮む。特異値分解や有効ランクは、この縮退を量的に調べる手がかりになる。
```

### Q8. 幾何学的比喩の限界

CoTを表現空間上の軌跡と呼ぶときの注意はどれか。

```quiz
- CoTは数学的に必ず滑らかな多様体上の曲線である
- [x]推論経路を理解する比喩として有用だが、離散トークン列や内部状態と滑らかな軌跡を同一視してはいけない
- 比喩なので推論過程の分析には使えない
- 軌跡と呼べば回答の正しさが保証される
S: /series/10#幾何学的解釈-比喩
A: 軌跡という言葉は、複数段階の探索や状態変化を考える助けになる。ただし、実際の出力は離散的で、比喩だけから内部計算や正しさを断定できない。
```
