# 第9回 理解度チェック：拡散と凝縮

## ノイズを加え、戻す

### Q1. Forward Process

拡散モデルのForward Processの役割はどれか。

```quiz
- ノイズを加えず、データをそのまま保存する
  R: Forward Processはデータを徐々にノイズで汚していく過程として定義されており、データをそのまま保存する操作ではない。
- ノイズをデータへ戻す手順を学ぶ
  R: ノイズをデータへ戻す手順を学ぶのはReverse Processの役割であり、Forward Processはその逆方向、データをノイズ化する過程を定義する。
- [x]データを徐々にノイズ化し、基準分布へ近づける
  R: Forward ProcessはSDEに従ってデータへ段階的にノイズを加え、時間の果てで標準ガウス分布という基準分布へ収束させる過程である。
- データを基準分布へ一度で写す手順を学ぶ
  R: Forward Processはドリフト項と拡散項を持つ連続的なSDEとして定義され、時間発展を経て基準分布へ近づく過程であり、一度で写す操作ではない。
S: /series/09#forward-process-データからノイズへ
A: Forward Processはデータを確率過程に沿ってノイズ化する。Reverse Processがその逆向きの生成を学ぶための基準となる。
```

### Q2. 閉形式解の前提

拡散過程の状態を閉形式で書けることが、学習時の直接サンプリングを可能にする。この性質について、最も適切な説明はどれか。

```quiz
- [x]ノイズスケジュールに従って任意時刻の状態を初期データとノイズから計算できるため、逐次シミュレーションが不要になる
  R: 閉形式解は $\mathbf{x}_t = \sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\boldsymbol{\epsilon}$ という形で任意時刻の状態を初期データとノイズから直接計算でき、$t=0$から逐次シミュレーションする必要がなくなる。
- 閉形式解によって各時刻の混合比がノイズスケジュールから切り離され、時刻に関わらず一定の値を取る
  R: 混合比を決める $\bar{\alpha}_t$ はノイズスケジュール $\beta_t$ の積分で定まる時刻依存の量であり、ノイズスケジュールから切り離されて一定になるわけではない。
- 閉形式解は初期データへの依存を消すため、任意時刻の状態はどのデータから出発しても同じ分布になる
  R: 閉形式解の式には初期データ $\mathbf{x}_0$ の項が明示的に残っており、任意時刻の状態は出発点のデータに依存する。
- 閉形式解が任意時刻の状態を与えるため、逆過程を学習しなくても同じ経路でデータへ戻れる
  R: 閉形式解が与えるのはデータからノイズへ向かう過程の直接計算であり、ノイズからデータへ戻るには別途スコア関数などを学習する逆過程が必要である。
S: /series/09#解の閉形式-任意時刻への直接ジャンプ
A: 閉形式解は、ノイズスケジュールに従って任意の時刻の状態を初期データとノイズから直接計算できることを意味し、学習時に逐次シミュレーションする必要がなくなる。ただし、各時刻の混合比はスケジュールで決まり、ノイズから生成するには逆過程の学習が別途必要である。
```

### Q3. Reverse Process

Reverse Processでモデルが学ぶものとして、適切な説明はどれか。

```quiz
- 元の訓練データをそのまま検索する手順
  R: Reverse ProcessはスコアやノイズをネットワークでモデリングしてSDEを解く生成過程であり、訓練データを検索する仕組みではない。
- Forward Processのノイズをそのまま記録した表
  R: Reverse Processが学ぶのはスコア関数による補正項を含む更新則であり、Forward Processで加えたノイズを記録した表ではない。
- クラスラベルを予測する分類境界
  R: Reverse Processはノイズ状態からデータらしい状態への連続的な遷移を学ぶ生成過程であり、クラスラベルの分類境界を求める問題ではない。
- [x]ノイズ状態をデータ分布へ戻す更新を学ぶ
  R: Reverse Processはスコア関数による補正を伴うSDEとして書き下され、ノイズからデータらしい状態へ向かう更新を反復的に学習する。
S: /series/09#reverse-process-ノイズからデータへ
A: 逆過程はノイズからデータらしい状態へ進む更新を反復する。実装ではノイズ予測やスコア予測など、等価な定式化が使われる。
```

### Q4. スコア関数

スコア関数 $\nabla_\mathbf{x}\log p(\mathbf{x})$ の幾何学的な意味はどれか。

```quiz
- [x]密度が増える方向を示す局所ベクトル
  R: スコアは対数密度の勾配であり、1次元ガウス分布の例でも常にモード（密度が最大の点）に向かう方向を指し示す。
- 確率密度そのものの値
  R: スコアは密度の対数を微分した勾配ベクトルであり、密度の値そのものではない。密度が同じでも勾配の向きは場所によって異なる。
- データ点から原点へ向かう固定ベクトル
  R: スコアは分布の形状に応じて場所ごとに変化するベクトル場であり、原点に向かう固定的な方向を表すものではない。多峰性の分布では最寄りのモードに向かう傾向を持つ。
- クラス数を表すスカラー
  R: スコアはベクトル場であり、分類問題のクラス数のようなスカラー量ではない。
S: /series/09#スコア関数の幾何学的意味
A: スコアは対数密度の勾配であり、その場所から見て確率密度が増える方向を表す。生成ではこの方向を利用してノイズからデータらしい領域へ移動する。
```

## 確率微分方程式（Stochastic Differential Equation、SDE）・常微分方程式（Ordinary Differential Equation、ODE）・サンプリング

### Q5. 確率フローODE（Ordinary Differential Equation、常微分方程式）

確率フローODE（Ordinary Differential Equation、常微分方程式）の特徴として正しいものはどれか。

```quiz
- ODEなので確率分布を扱えない
  R: 確率フローODEはSDEと同じ周辺分布 $p_t(\mathbf{x})$ を保つように設計されており、確率分布を扱えないわけではない。
- [x]SDEと同じ周辺分布を決定論的ODEで表す
  R: 確率フローODEはノイズ項を消して係数を調整することで、Reverse SDEと同じ周辺分布の流れを決定論的な軌道として表現する。
- Forward Processのノイズを増やし続ける
  R: 確率フローODEはノイズ項が消えた決定論的な式であり、ノイズを増やし続ける過程ではない。
- 各サンプルが同じ初期値を持つ
  R: 確率フローODEは同じ初期ノイズから常に同じ出力を与える決定論的な性質を持つが、初期値そのものはサンプルごとに異なるノイズから選ばれる。
S: /series/09#確率フローodeの利点
A: 確率フローODEは、適切なベクトル場を使えばSDEと同じ周辺分布の流れを決定論的に表現できる。サンプリングや尤度計算に利点がある。
```

### Q6. Langevin動力学

Langevin動力学によるスコアベースのサンプリングは、何を組み合わせるか。

```quiz
- 勾配を使わない決定論的な直線移動
  R: Langevin動力学の更新式にはスコア $\nabla_{\mathbf{x}}\log p(\mathbf{x}_k)$ による勾配項が含まれており、勾配を使わない移動ではない。
- ランダムな揺らぎを使わない、スコアに沿った決定論的な移動
  R: Langevin動力学の更新式にはノイズ項 $\sqrt{\eta}\boldsymbol{\epsilon}_k$ が含まれており、ランダムな揺らぎを使わない決定論的な移動ではない。
- ノイズをそのまま除去した後の一回の射影
  R: Langevin動力学は一回の射影ではなく、スコアによる更新とランダムノイズの付加を反復することで分布への収束を目指す手法である。
- [x]スコアによる更新とランダムノイズを組み合わせる
  R: Langevin動力学の更新式はスコアによる勾配項とランダムノイズ項の和で構成されており、両者を組み合わせて分布からのサンプリングを実現する。
S: /series/09#スコアベースのサンプリング
A: Langevin更新はスコアによる上昇方向とランダムな揺らぎを組み合わせる。確率分布からのサンプリングを反復的に行う方法である。
```

### Q7. Flow Matching

Flow Matchingが目指す統一的な見方はどれか。

```quiz
- [x]分布間を結ぶ時間依存ベクトル場を学ぶ
  R: Flow Matchingは確率フローODEのベクトル場 $\mathbf{v}_\theta(\mathbf{x}, t)$ を条件付きベクトル場との二乗誤差で直接学習する枠組みである。
- ノイズ過程を使わず、入力をそのままコピーする
  R: Flow Matchingはノイズ分布とデータ分布を結ぶパス上のベクトル場を学習する枠組みであり、入力をそのままコピーする操作ではない。
- 各生成を単一の分類問題へ変える
  R: Flow Matchingが学習するのは連続的なベクトル場であり、分類問題への変換ではない。
- ODEと確率分布の関係を切り離す
  R: Flow MatchingはODEの軌道が確率分布の流れに対応するという関係を前提として、そのベクトル場を学習する枠組みであり、両者を切り離すものではない。
S: /series/09#flow-matchingとは
A: Flow Matchingは、分布間を運ぶ条件付きまたは確率的な経路の速度場を学ぶ。拡散モデルと近い生成の視点を、ベクトル場の学習として整理できる。
```

### Q8. 球面拡散

球面上に正規化した表現へ、ユークリッド空間の拡散過程をそのまま適用したところ、ノルムがずれた。このときの判断として、最も適切なものはどれか。

```quiz
- ノルムのずれを確信度の情報として解釈し、方向の評価を省く
  R: ノルムのずれはユークリッド拡散が球面という状態空間の制約を考慮していないことの表れであり、確信度の情報として解釈して方向の評価を省く根拠にはならない。
- 正規化を後処理として加え、過程の幾何は変更しない
  R: 後処理での正規化は表面上ノルムを揃えるだけで、拡散過程自体が球面ではなくユークリッド空間を前提としている点は変わらないため、根本的な対処にならない。
- [x]球面上の確率過程を設計し、標準過程と比較する
  R: 球面拡散は状態空間を単位球面に取り、球面上のブラウン運動を用いる別の定式化であり、方向の構造や生成品質、計算コストを標準過程と比較して判断するのが妥当である。
- 球面上の表現でもユークリッド過程を使えば、曲率の影響は無視できる
  R: 球面制約とユークリッド拡散は状態空間とノイズ過程の前提が異なり、曲率の影響を無視できると決めつけることはできない。
S: /series/09#球面拡散の動機
A: 球面制約とユークリッド拡散は、状態空間とノイズ過程の前提が異なる。球面上の過程を設計する場合も、方向の構造、生成品質、計算コストを比較して判断する。
```
