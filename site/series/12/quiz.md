# 第12回 理解度チェック：双曲幾何学

## 階層に合う空間

### Q1. 木構造と空間の成長

階層構造の埋め込みで双曲空間が注目される理由はどれか。

```quiz
- [x]距離に応じた指数的な広がりが、木構造の分岐に合う
  R: 双曲空間では測地線円の周囲長が距離に対して指数的に増加し、深さごとにノード数が指数的に増える木構造の分岐を自然に収容できる。
- 双曲空間では階層の深さを表せないから
  R: 逆であり、双曲空間は中心からの距離で階層の深さを、角度で兄弟関係を表現できるため、階層構造を表す代表的な空間として扱われている。
- 木構造は平坦な空間に埋め込めないから
  R: ユークリッド空間にも木構造を埋め込むこと自体は可能だが、周囲長が距離に対して多項式的にしか増えないため、深い階層で歪みや次元の爆発が生じやすい。
- 球面よりも直線距離が短いから
  R: 双曲空間が階層構造に適する理由は直線距離の長さではなく、測地線円の周囲が指数的に広がるという成長率の違いにある。
S: /series/12#木構造の指数的成長
A: 木構造は深くなるほどノード数が指数的に増える。負の曲率を持つ双曲空間の広がりは、この構造との相性がよい。
```

### Q2. 球面の限界

階層構造を球面へ埋め込むときの困難として、適切な説明はどれか。

```quiz
- [x]球面は深い階層の分岐を保ちにくい
  R: 球面上の測地線円の周囲長はある地点を境に狭くなるため、指数的に分岐が増える階層構造を収容しきれない。
- 球面は中心からの距離が有界なため、階層が深くなるほど距離の分解能が上がる
  R: 球面の距離には上限があり、階層が深くなるにつれて限られた距離の中に多くの階層を詰め込まなければならず、分解能はむしろ不足する。半径方向に自由度がある双曲空間の方が、深い階層を表現しやすい。
- 球面上の角度は測地線距離に対応するため、階層の深さと直接一致する
  R: 球面は「対等な関係」を表すのに向いた空間であり、角度が階層の深さと直接対応するわけではない。周囲長がある地点から狭くなる性質がむしろ階層表現の妨げになる。
- 球面の測地線は大円に限られ、木構造の分岐を表す経路として適する
  R: 大円という測地線の形自体が問題なのではなく、球面の周囲長がある地点を境に狭くなることが、指数的に広がる木構造の分岐を表しにくくしている。
S: /series/12#球面空間での困難
A: 球面は方向中心の表現に向くが、階層の分岐が増える構造を効率よく収容する空間ではない場合がある。データ構造に応じた曲率の選択が必要である。
```

### Q3. 負の曲率

双曲空間の負の曲率が階層表現に与える効果はどれか。

```quiz
- 負の曲率は三角形の内角の和を180度より大きくする
  R: 三角形の内角の和が180度より大きくなるのは正の曲率を持つ球面の性質であり、負の曲率ではむしろ180度より小さくなる。
- 中心から遠ざかるほど空間はゆっくり広がるため、深い階層は中心付近に収まる
  R: 負の曲率の空間では中心から遠ざかるほど周囲がゆっくりではなく速く広がるため、深い階層はむしろ中心から離れた周辺に配置される。
- 階層構造は、曲率を0に固定した平坦な空間で最もよく保たれる
  R: 平坦な空間では測地線円の周囲長が距離に対して線形にしか増えず、指数的に分岐が増える階層構造を効率よく保つのは難しい。
- [x]負の曲率は階層の周辺を広げる
  R: 負の曲率の空間では中心から離れるにつれて周囲が速く広がるため、木構造の多分岐を表す余地が生まれる。
S: /series/12#負の曲率とは何か
A: 負の曲率の空間では、中心から離れるにつれて周囲が速く広がる。これが木構造の多分岐を表す余地になる。
```

### Q4. ポアンカレ円板

ポアンカレ円板モデルの特徴として、正しいものはどれか。

```quiz
- 境界上の各点を通常のデータ点として扱う
  R: 境界は無限遠に対応する極限であり、通常のデータ点が配置される場所ではない。
- 円板上のユークリッド距離がそのまま双曲距離になる
  R: 双曲距離はユークリッド距離とノルムを組み合わせた式で定まり、境界に近づくほど同じユークリッド距離でも双曲距離が大きく伸びるため、両者は一致しない。
- [x]無限の双曲空間を有限円板で表し、境界で尺度が変わる
  R: ポアンカレ円板は有限の見た目の中に無限の双曲空間を収めるモデルであり、境界に近づくほど同じユークリッド距離あたりの双曲距離が伸びる。
- 円板の中心付近でも境界付近でも、ユークリッド距離あたりの双曲距離の伸び方は変わらない
  R: 中心付近ではユークリッド距離に近い振る舞いをするが、境界に近づくほど同じユークリッド距離あたりの双曲距離は際限なく伸びていく。
S: /series/12#ポアンカレ円板の構造
A: ポアンカレ円板は双曲空間を有限の見た目に表すモデルである。境界は無限遠に対応し、ユークリッド図形の距離をそのまま使うことはできない。
```

## 適用と限界

### Q5. 測地線の形

ポアンカレ円板上の測地線について、適切な説明はどれか。

```quiz
- [x]円弧や直径に見えるが、双曲計量で定まる
  R: ポアンカレ円板上の測地線は円板の境界に直交する円弧として描かれ、中心を通る場合に限り直径（直線）になる。見た目は曲線でも双曲計量のもとでは「まっすぐ」な経路である。
- 各二点間で同じ形になる
  R: 測地線の形は二点の位置関係によって異なり、中心を通るかどうかで直径になるか円弧になるかが変わる。
- ユークリッド平面の水平線になる
  R: ポアンカレ円板モデルではユークリッド空間の直線がそのまま測地線になるわけではなく、境界に直交する円弧として現れる。
- 曲率に依存せず、球面の大円と同じである
  R: 測地線の形は空間の曲率に依存しており、正の曲率を持つ球面の大円と、負の曲率を持つポアンカレ円板の測地線は異なる形になる。
S: /series/12#測地線の形状
A: モデル上の見た目と内在的な測地線は区別する必要がある。ポアンカレ円板では境界に直交する円弧などが双曲的な「直線」を表す。
```

### Q6. Poincaré Embeddings（階層関係の双曲埋め込み）

Poincaré Embeddings（階層関係の双曲埋め込み）が適したデータの例はどれか。

```quiz
- 周期構造を持つデータに限定される
  R: 周期的な構造は円環や球面のような空間との相性がよく、Poincaré Embeddingsが主に対象とする親子関係を持つ階層データとは性質が異なる。
- [x]親子関係や分岐を含む階層データ
  R: Poincaré Embeddingsは、上位-下位関係を持つ概念を中心から外側へ配置することで、WordNetのような階層的語彙データベースを低次元で表現する代表的な手法である。
- 独立なカテゴリがそのまま一様に並ぶデータ
  R: 階層的な上下関係を持たず独立に並ぶだけのデータでは、双曲空間の指数的に広がる性質を活かす分岐構造がなく、恩恵は限定的である。
- データが同じ曲率を持つことが既知の画像
  R: Poincaré Embeddingsが対象とするのは画像データの曲率ではなく、概念間の階層関係というデータ構造である。
S: /series/12#poincare-embeddings
A: Poincaré Embeddingsは階層的な関係を双曲空間へ埋め込む代表例である。ただし、階層性が弱いデータで常に有利とは限らない。
```

### Q7. 曲率の選択

球面、ユークリッド、双曲空間の選択について、最も慎重な説明はどれか。

```quiz
- 曲率を変えると表現は壊れる
  R: 曲率の選択はデータ構造との適合度を左右する設計判断であり、曲率を変えること自体が表現を壊すわけではない。
- [x]データ構造に応じて曲率を選び、万能な空間を仮定しない
  R: 球面は対等な関係、ユークリッド空間は平坦な関係、双曲空間は階層に適するという目安があり、どの曲率にも万能性はなくデータ構造に応じた選択が必要である。
- 表現力の高い空間ほどデータへの適合が良いので、データ構造は見なくてよい
  R: 空間の表現力だけでなくデータが持つ階層性や類似関係といった構造との適合が重要であり、構造を見ずに空間を選ぶと有効性が損なわれうる。
- 双曲空間は球面より優れている
  R: 双曲空間と球面はそれぞれ階層構造と対等な関係という異なる性質に適しており、一方が常に優れているわけではない。
S: /series/12#適したデータ構造
A: 球面は方向、ユークリッド空間は平坦な関係、双曲空間は階層に適するという目安がある。実際の有効性はデータ、損失、次元、最適化に依存する。
```

### Q8. Mixed-Curvature Spaces

あるデータセットに、階層的なカテゴリと周期的な関係が同時に含まれている。空間設計の候補として、最も適切なものはどれか。

```quiz
- 曲率を固定したまま、データの構造差は損失で吸収する
  R: 単一の曲率に固定してしまうと、階層的な関係と周期的な関係のように異なる幾何学的性質を持つ構造のどちらかを表しにくくなる可能性がある。
- [x]部分構造ごとに曲率を選ぶ候補を作り、表現力と最適化・解釈のコストを比較する
  R: 複合曲率空間は異なる曲率を持つ部分空間を組み合わせる候補であり、実装の複雑さや学習の不安定性というコストも踏まえて比較検討する必要がある。
- どちらの構造も単一のユークリッド距離へ射影して比較する
  R: 階層的な関係も周期的な関係もユークリッド距離だけに押し込めると、それぞれの構造が持つ指数的な広がりや循環的な性質を表しにくくなる可能性がある。
- 複合曲率は最適化も解釈も複雑になるため、二つの構造を単一の曲率へ押し込む方がよい
  R: 複合曲率空間には実装や最適化の複雑さという課題があるが、単一の曲率へ押し込むと異なる構造のどちらかを表しにくくなる可能性があり、単純にどちらか一方が常によいとは言えない。
S: /series/12#複合曲率空間
A: 異なる構造を一つの曲率へ押し込むと、どこかの関係を表しにくくなる可能性がある。複合曲率は候補だが、パラメータ数、最適化、評価の複雑さも比較対象になる。
```
