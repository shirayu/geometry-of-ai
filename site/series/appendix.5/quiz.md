# Appendix 5: 情報幾何学における双対構造: 2種類のまっすぐ（理解度チェック）

## 二つの接続

### Q1. e-接続（exponential connection）とm-接続（mixture connection）

情報幾何学のe-接続（exponential connection）とm-接続（mixture connection）について、適切な説明はどれか。

```quiz
- [x]eとmは二つのパラメータに対応する双対接続である
  R: e-接続は自然パラメータの空間での直線構造、m-接続は期待値パラメータの空間での直線構造に対応し、Fisher計量に関して互いに双対な接続の組をなす。
- e-接続とm-接続はどちらもユークリッド計量から誘導される、同一の平坦接続を指す
  R: e-接続とm-接続は異なる座標系（自然パラメータと期待値パラメータ）でそれぞれ平坦になる接続であり、ユークリッド計量から誘導される単一の接続に還元されるわけではない。
- e-接続は自然パラメータの直線構造、m-接続はKLダイバージェンスの値そのものを表す
  R: m-接続は期待値パラメータ空間での直線構造（凸結合による測地線）を表す接続であり、KLダイバージェンスという距離の値そのものを表すものではない。
- m-接続は期待値パラメータではなく、確率分布のエントロピーを直線にする接続である
  R: m-接続が直線にするのは期待値パラメータの空間での凸結合であり、エントロピーという量そのものを直線化する接続ではない。
S: /series/appendix.5#e-接続とm-接続
A: e-接続とm-接続は、自然パラメータと期待値パラメータの異なる直線構造に対応する。両者は情報幾何学の双対性を表す。
```

### Q2. $\alpha$ -接続

$\alpha$ -接続の役割はどれか。

```quiz
- $\alpha$ -接続は確率分布をベクトルへ変換しない
  R: $\alpha$ -接続はFisher計量に関する接続の族を定めるものであり、確率分布をベクトルに変換するかどうかという操作について述べたものではない。
- $\alpha$ -接続は曲率を0にする
  R: 曲率が0（平坦）になるのはe-接続やm-接続のような特定の値のときであり、$\alpha$ -接続全般が曲率を0にするわけではない。
- [x]e-接続とm-接続を $\alpha$ で連続的に扱う
  R: $\alpha$ -接続はLevi-Civita接続を中心に、$\alpha=+1$ でe-接続、$\alpha=-1$ でm-接続となる接続族であり、一つのパラメータでこれらを連続的に記述する枠組みである。
- $\alpha$ は学習率を表すパラメータである
  R: $\alpha$ は接続の族を指定する幾何学的なパラメータであり、勾配降下法における学習率とは異なる概念である。
S: /series/appendix.5#alpha-接続の定義
A: $\alpha$ -接続は、異なる接続を一つのパラメータで記述する枠組みである。$\alpha=0$ はLevi-Civita接続に対応し、$\alpha=+1$ がe-接続、$\alpha=-1$ がm-接続で、接続族の両端をなす。
```

### Q3. Levi-Civita接続

$\alpha=0$ の接続の位置づけとして、正しいものはどれか。

```quiz
- e-接続とm-接続を同時に消去する
  R: $\alpha=0$ のLevi-Civita接続はe-接続・m-接続と並ぶ接続族の一点であり、他の接続を消去する働きを持つものではない。
- 確率分布を一様分布に固定する
  R: Levi-Civita接続は平行移動や測地線の定め方を規定する幾何学的な構造であり、確率分布を一様分布に固定するような操作とは無関係である。
- [x]計量と整合するリーマン幾何学的接続に対応する
  R: Levi-Civita接続は計量整合性と捩れなしという2条件で一意に定まる、リーマン幾何学における標準的な接続である。
- 双対性を持たないことを意味する
  R: Levi-Civita接続は$\alpha=-\alpha$すなわち自己双対な点として位置づけられ、双対性の枠組みから外れているわけではない。
S: /series/appendix.5#levi-civita接続-alpha-0-の位置づけ
A: $\alpha=0$ はLevi-Civita接続に対応し、計量整合性を持つ。e-接続とm-接続は、これとは異なる双対的な接続として現れる。
```

### Q4. 双対性のトレードオフ

情報幾何学における接続と計量の関係について、適切な説明はどれか。

```quiz
- e-接続とm-接続は互いに無関係である
  R: e-接続とm-接続はFisher計量に関して互いに双対な関係にある接続であり、無関係な二つの構造ではない。
- 双対接続は計量との関係を保ち、二つの接続はともに計量整合的である
  R: $\alpha\neq0$の接続は一般に計量整合的でなく、e-接続とm-接続がともに計量整合性を保つわけではない。計量整合性を満たすのは自己双対なLevi-Civita接続だけである。
- 計量は接続から独立なので、双対性を定義できない
  R: 双対性はまさにFisher計量を基準にして接続同士の関係を定める概念であり、計量と接続が無関係だとすると双対性という構造自体が成り立たない。
- [x]双対接続は計量との関係を保つが、二つの接続がともに計量整合的とは限らない
<!-- quiz-lint-ignore: hedge - 情報幾何学の定理的主張そのもので、誤答2が既に同型の裏返し構文になっている -->
  R: $\alpha$-接続と$-\alpha$-接続はFisher計量に関する双対関係の式を満たすが、この関係は計量整合性そのものとは別であり、$\alpha\neq0$では計量整合性は成り立たない。
S: /series/appendix.5#計量整合性と双対性のトレードオフ
A: 双対接続は計量と特定の整合関係を持つ。一方、Levi-Civita接続のように計量整合性とねじれの条件を同時に満たす接続とは位置づけが異なる。
```

## 双対平坦とSoftmax

### Q5. 双対平坦空間

双対平坦空間の特徴として、正しいものはどれか。

```quiz
- 確率分布を点として扱う見方を捨て、密度関数そのものを座標とする
  R: 双対平坦空間の議論は確率分布を多様体上の点として扱う立場を前提にしており、自然パラメータや期待値パラメータという座標を用いる。密度関数そのものを座標にする見方への転換ではない。
- e-接続とm-接続のどちらか一方だけが定義され、もう一方は打ち消し合って消える
<!-- quiz-lint-ignore: cue - 誤解の核心が「一方のみが定義される」という排他性そのものにあるため -->
  R: 双対平坦空間ではe-接続に関する平坦性（e-flat）とm-接続に関する平坦性（m-flat）が同時に成り立つのであり、一方が消えるわけではない。
- リーマン計量が定めるLevi-Civita接続と同じ形になり、e-接続・m-接続の区別が消える
  R: 統計多様体上ではLevi-Civita接続は一般に平坦にならず、e-接続とm-接続はLevi-Civita接続とは異なる座標でそれぞれ平坦になる接続として区別され続ける。
- [x]自然パラメータと期待値パラメータという双対座標で、e-接続とm-接続がそれぞれ平坦になる
  R: 双対平坦空間では、自然パラメータ座標でe-接続が、期待値パラメータ座標でm-接続がそれぞれ平坦であり、この2つの平坦性が同時に成り立つ。
S: /series/appendix.5#双対平坦空間
A: 双対平坦性では、互いに双対な座標でe-測地線やm-測地線を扱いやすい。Kullback–Leibler（KL）ダイバージェンスや情報射影の構造とも結びつく。
```

### Q6. ルジャンドル変換

ルジャンドル変換が情報幾何学で果たす役割はどれか。

```quiz
- [x]凸関数から双対座標を作る
  R: ルジャンドル変換は凸関数である対数分配関数の勾配を通じて、自然パラメータと期待値パラメータという互いに双対な座標系を結びつける。
- 物理量を同じ座標へコピーする
  R: ルジャンドル変換は座標をコピーする操作ではなく、点の軌跡としての記述と接線の包絡線としての記述という異なる視点の間を翻訳する操作である。
- 接続を使わずに曲率を計算する
  R: ルジャンドル変換は自然パラメータと期待値パラメータを結ぶ座標変換の仕組みであり、接続を経由せず曲率だけを直接計算する手続きではない。
- 確率分布を離散化する
  R: ルジャンドル変換は連続的な凸関数とその双対関数の間の変換であり、確率分布を離散的な値へ変換する操作ではない。
S: /series/appendix.5#ルジャンドル変換の幾何学的意味
A: ルジャンドル変換は凸ポテンシャルから双対な記述を作る。指数型分布族では、自然パラメータと期待値パラメータの関係を与える。
```

### Q7. Softmaxとの関係

双対平坦構造におけるSoftmaxの位置づけはどれか。

```quiz
- ロジットから確率への写像は一意で、定数加算の冗長性がない
  R: Softmaxはロジットの商空間上での写像であり、ロジットに一様な定数を加えても同じ確率を与えるという冗長性が残る。
- Softmaxは確率と無関係な座標変換である
  R: Softmaxはロジット（自然パラメータ）から確率（期待値パラメータ）への変換そのものであり、確率と無関係な操作ではない。
- Softmaxは単体の境界を出力する
  R: Softmaxの出力は確率単体の内部に値を取るのが通常であり、境界だけを出力する写像ではない。
- [x]対数分配関数の勾配として、ロジットを確率へ写す
  R: Softmaxは対数分配関数$\psi(\mathbf{z})$の勾配$\mathbf{p}=\nabla_{\mathbf{z}}\psi(\mathbf{z})$として定義され、自然パラメータであるロジットを期待値パラメータである確率へ写す。
S: /series/appendix.5#双対平坦空間
A: $\mathbf{p}(\mathbf{z})=\nabla_{\mathbf{z}}\psi(\mathbf{z})$ と見れば、Softmaxは対数分配関数の勾配写像になる。ロジットには一様な定数加算の冗長性が残る。
```

### Q8. 情報射影

確率分布を制約集合へ射影すると、ユークリッド最近傍とKullback–Leibler（KL）ダイバージェンスに基づく射影の結果が異なった。次の判断として、最も適切なものはどれか。

```quiz
- [x]基準分布と制約を明示し、KLの向きや射影を比較する
  R: 情報射影は距離の選択（KLの向きなど）と制約の表現に依存するため、どの基準分布とどの制約で比較しているかを明示したうえで、e-射影やm-射影の違いを整理するのが妥当な対応である。
- ユークリッド距離とKLダイバージェンスの両方で射影を計算し、一致する方を選択する
  R: ユークリッド距離に基づく射影とKLに基づく射影は異なる幾何学的構造に基づく別の操作であり、一致するかどうかは採用の基準にならない。どちらを使うかは分布のどの性質を重視するかで決まる。
- 双対平坦性があるため、座標系と射影の選択は評価へ影響しないとみなす
  R: 双対平坦性は座標系ごとに異なる平坦性（e-flatとm-flat）を与える構造であり、座標系や射影の選択が結果に影響しないことを意味するものではない。
- ユークリッド距離の結果を採用し、制約の表現はそのままにする
  R: ユークリッド距離はFisher計量に基づく情報幾何学的な構造を無視した選択であり、制約の表現を見直さずに一方の結果だけを採用する根拠にはならない。
S: /series/appendix.5#双対平坦空間
A: 情報射影は、距離の選択と制約の表現に依存する。双対平坦構造では、KLに対応するBregman構造とe・m座標を使って、その違いを整理できる。
```
