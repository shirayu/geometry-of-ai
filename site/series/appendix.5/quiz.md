# Appendix 5 理解度チェック：情報幾何学における双対構造

## 二つの接続

### Q1. e-接続とm-接続

情報幾何学のe-接続とm-接続について、適切な説明はどれか。

```quiz
- [x]指数型の自然パラメータ側と、期待値パラメータ側に対応する双対的な接続である
- どちらもユークリッド距離の別名である
- e-接続だけが確率分布を扱う
- m-接続はパラメータ化と無関係である
S: /series/appendix.5#e-接続とm-接続
A: e-接続とm-接続は、自然パラメータと期待値パラメータの異なる直線構造に対応する。両者は情報幾何学の双対性を表す。
```

### Q2. $\alpha$ -接続

$\alpha$ -接続の役割はどれか。

```quiz
- $\alpha$ は学習率だけを表す
- [x]e-接続とm-接続を含む一連の接続を、パラメータ $\alpha$ で連続的に扱う
- $\alpha$ -接続は曲率を必ず0にする
- $\alpha$ -接続は確率分布をベクトルへ変換しない
S: /series/appendix.5#alpha-接続の定義
A: $\alpha$ -接続は、異なる接続を一つのパラメータで記述する枠組みである。特定の $\alpha$ でe-接続やm-接続に対応し、$\alpha=0$ はLevi-Civita接続になる。
```

### Q3. Levi-Civita接続

$\alpha=0$ の接続の位置づけとして、正しいものはどれか。

```quiz
- [x]計量と整合する通常のリーマン幾何学的な接続に対応する
- e-接続とm-接続を同時に消去する
- 確率分布を一様分布に固定する
- 双対性を持たないことを意味する
S: /series/appendix.5#levi-civita接続-alpha-0-の位置づけ
A: $\alpha=0$ はLevi-Civita接続に対応し、計量整合性を持つ。e-接続とm-接続は、これとは異なる双対的な接続として現れる。
```

### Q4. 双対性のトレードオフ

情報幾何学における接続と計量の関係について、適切な説明はどれか。

```quiz
- [x]双対接続は計量との関係を保つが、二つの接続がともに計量整合的とは限らない
- すべての接続は常に同じ計量を持つ
- e-接続とm-接続は互いに無関係である
- 計量は接続から独立なので、双対性を定義できない
S: /series/appendix.5#計量整合性と双対性のトレードオフ
A: 双対接続は計量と特定の整合関係を持つ。一方、Levi-Civita接続のように計量整合性とねじれの条件を同時に満たす接続とは位置づけが異なる。
```

## 双対平坦とSoftmax

### Q5. 双対平坦空間

双対平坦空間の特徴として、正しいものはどれか。

```quiz
- [x]双対する座標系で接続が平坦になり、直線や射影を二つの座標から扱いやすい
- すべての曲率が必ず正になる
- 確率分布を点として扱えなくなる
- e-接続とm-接続が存在しない
S: /series/appendix.5#双対平坦空間
A: 双対平坦性では、互いに双対な座標でe-測地線やm-測地線を扱いやすい。KLダイバージェンスや情報射影の構造とも結びつく。
```

### Q6. ルジャンドル変換

ルジャンドル変換が情報幾何学で果たす役割はどれか。

```quiz
- 物理量をすべて同じ座標へコピーする
- [x]凸関数から双対座標や双対ポテンシャルを構成し、自然パラメータと期待値パラメータを結ぶ
- 確率分布を必ず離散化する
- 接続を使わずに曲率だけを計算する
S: /series/appendix.5#ルジャンドル変換の幾何学的意味
A: ルジャンドル変換は凸ポテンシャルから双対な記述を作る。指数型分布族では、自然パラメータと期待値パラメータの関係を与える。
```

### Q7. Softmaxとの関係

双対平坦構造におけるSoftmaxの位置づけはどれか。

```quiz
- [x]対数分配関数の勾配として、自然パラメータであるロジットから確率を得る写像と見なせる
- Softmaxは確率と無関係な座標変換である
- ロジットから確率への写像は一意で、定数加算の冗長性がない
- Softmaxは必ず単体の境界だけを出力する
S: /series/appendix.5#双対平坦空間
A: $\mathbf{p}(\mathbf{z})=\nabla_{\mathbf{z}}\psi(\mathbf{z})$ と見れば、Softmaxは対数分配関数の勾配写像になる。ロジットには一様な定数加算の冗長性が残る。
```

### Q8. 情報射影

双対平坦性と情報射影の関係として、適切な説明はどれか。

```quiz
- 情報射影は常にユークリッド最近傍点と同じである
- [x]KLダイバージェンスをBregmanダイバージェンスとして扱い、e-射影やm-射影を幾何学的に理解できる
- 双対平坦性があれば、すべての確率が正確に観測できる
- 情報射影はパラメータ化に依存しない単一の直線だけである
S: /series/appendix.5#双対平坦空間
A: 双対平坦構造では、KLに対応するBregman構造を通じて情報射影を整理できる。e-座標とm-座標で、異なる「まっすぐ」を使い分けられる。
```
