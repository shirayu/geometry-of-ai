# Appendix 4 理解度チェック：空間の「物差し」再考

## 距離と方向

### Q1. 内積とコサイン類似度

内積とコサイン類似度の違いとして、正しいものはどれか。

```quiz
- [x]内積はノルムを含み、コサインは方向を比べる
- コサイン類似度はノルムの積を含む
- 内積は方向に依存しない
- 両者は入力のノルムが異なっても同じ値になる
S: /series/appendix.4#コサイン類似度-方向だけを見る
A: 内積は $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ のように大きさの影響を受ける。L2正規化後の内積はコサイン類似度になり、方向を比較しやすい。
```

### Q2. 双曲距離

双曲距離を使う動機として、適切なものはどれか。

```quiz
- 双曲距離は確率分布にしか使えない
- [x]負の曲率の広がりで、階層の深さや分岐を表す
- 距離は階層構造を表現できない
- 双曲距離はデータを同じ位置に置く
S: /series/appendix.4#双曲距離-階層構造の深さを測る
A: 双曲空間は距離に応じた広がりが大きく、階層的な分岐を表しやすい。どの距離が有効かは、データの構造に依存する。
```

### Q3. Kullback–Leibler（KL）ダイバージェンス

Kullback–Leibler（KL）ダイバージェンスを通常の距離と区別する特徴はどれか。

```quiz
- 対称で、三角不等式を満たす
- 分布ではなくベクトルのノルムだけを比較する
- 負の値になる
- [x]一般に非対称で、引数の順序で値が異なる
S: /series/appendix.4#klダイバージェンス-分布の非対称な隔たり
A: KLダイバージェンスは分布の隔たりを測るが、方向を持つため一般には対称でない。学習では、この非対称性がどちらを基準にするかという意味を持つ。
```

### Q4. 非対称性と学習

KLダイバージェンスの非対称性が学習に与える意味はどれか。

```quiz
- KLは学習の駆動力にならない
- [x]基準と近似の役割が、重視する誤差を左右する
- 非対称性は数値計算上の誤差にすぎない
- 引数の順序を入れ替えても、学習の方向は同じになる
S: /series/appendix.4#非対称性が学習を駆動する
A: KL(P||Q)とKL(Q||P)は異なる最適化上の性質を持つ。どちらを使うかによって、分布のどの領域を重視するかが変わりうる。
```

## 計量と更新

### Q5. フィッシャー情報

フィッシャー情報行列が測るものとして、最も適切なのはどれか。

```quiz
- データ点の個数だけ
- 予測の正しさそのもの
- 各方向で同じ固定距離
- [x]パラメータ変化への分布の感度
S: /series/appendix.4#フィッシャー情報行列-分布の感度を測る
A: フィッシャー情報は、パラメータ方向ごとの分布の変化しやすさを表す計量になる。感度が高い方向と低い方向を区別できる。
```

### Q6. 自然勾配

自然勾配が通常の勾配と異なる点はどれか。

```quiz
- 自然勾配は学習率を必要としない
- [x]フィッシャー計量で更新を調整する
- 通常の勾配は確率分布の計量を使う
- 自然勾配は各パラメータを固定する
S: /series/appendix.4#自然勾配の幾何学的意味-「霧」をどう動かすか
A: 自然勾配は座標上の長さだけでなく、確率分布の変化量を考慮する。計量の逆行列を使うため、大規模モデルでは近似が必要になる。
```

### Q7. 物差しの選択

AIの表現を測る物差しの選択について、妥当な説明はどれか。

```quiz
- 物差しは結果に影響しない
- どのタスクでもユークリッド距離だけを使う
- 非対称な尺度は不適切である
- [x]問いに応じて物差しを選ぶ
S: /series/appendix.4#aiにとっての多層的な定規
A: 何を近いとみなすかは、尺度が定義する。単一の距離を万能とせず、表現したい構造と学習目的に合う物差しを選ぶことが重要である。
```

### Q8. 比喩の限界

同じ二つの分布を比べても、KLの引数の順序で学習結果が変わった。この現象への対応として、最も適切なものはどれか。

```quiz
- 引数の順序は実装上の差とみなし、学習目的は変えない
- 値が小さい向きを選び、分布の意味や評価指標は調べない
- 非対称性を平均化してから、どの領域を重視したかを記録しない
- [x]分布の役割を明示し、KLの向きと重視領域を比較する
S: /series/appendix.4#非対称性が学習を駆動する
A: KLの向きは、基準と近似の役割や重視する領域を変える。損失を選ぶときは、分布の役割、評価指標、目的への影響を明示する必要がある。
```
