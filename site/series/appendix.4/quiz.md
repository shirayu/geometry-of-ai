# Appendix 4 理解度チェック：空間の「物差し」再考

## 距離と方向

### Q1. 内積とコサイン類似度

内積とコサイン類似度の違いとして、正しいものはどれか。

```quiz
- [x]内積は方向とノルムの両方を含み、コサイン類似度は正規化によって方向を主に比較する
- コサイン類似度は必ずノルムの積を含む
- 内積は方向に依存しない
- 両者は入力のノルムが異なっても常に同じ値になる
S: /series/appendix.4#コサイン類似度-方向だけを見る
A: 内積は $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ のように大きさの影響を受ける。L2正規化後の内積はコサイン類似度になり、方向を比較しやすい。
```

### Q2. 双曲距離

双曲距離を使う動機として、適切なものはどれか。

```quiz
- 距離は階層構造を表現できない
- [x]負の曲率による空間の広がりを利用し、階層の深さや分岐を表現したい
- 双曲距離はすべてのデータを同じ位置に置く
- 双曲距離は確率分布にしか使えない
S: /series/appendix.4#双曲距離-階層構造の深さを測る
A: 双曲空間は距離に応じた広がりが大きく、階層的な分岐を表しやすい。どの距離が有効かは、データの構造に依存する。
```

### Q3. KLダイバージェンス

KLダイバージェンスを通常の距離と区別する特徴はどれか。

```quiz
- [x]一般に非対称であり、PからQを見る場合とQからPを見る場合で値が異なる
- 必ず対称で、三角不等式を満たす
- 分布ではなくベクトルのノルムだけを比較する
- 常に負の値になる
S: /series/appendix.4#klダイバージェンス-分布の非対称な隔たり
A: KLダイバージェンスは分布の隔たりを測るが、方向を持つため一般には対称でない。学習では、この非対称性がどちらを基準にするかという意味を持つ。
```

### Q4. 非対称性と学習

KLダイバージェンスの非対称性が学習に与える意味はどれか。

```quiz
- 基準分布と近似分布の役割を区別し、どの誤差を重く見るかに影響する
- [x]引数の順序を入れ替えても、学習の方向は必ず同じになる
- 非対称性は数値計算上の誤差にすぎない
- KLは学習の駆動力にならない
S: /series/appendix.4#非対称性が学習を駆動する
A: KL(P||Q)とKL(Q||P)は異なる最適化上の性質を持つ。どちらを使うかによって、分布のどの領域を重視するかが変わりうる。
```

## 計量と更新

### Q5. フィッシャー情報

フィッシャー情報行列が測るものとして、最も適切なのはどれか。

```quiz
- [x]パラメータの変化が確率分布をどれだけ変えるかという局所的な感度
- データ点の個数だけ
- すべての方向で同じ固定距離
- 予測の正しさそのもの
S: /series/appendix.4#フィッシャー情報行列-分布の感度を測る
A: フィッシャー情報は、パラメータ方向ごとの分布の変化しやすさを表す計量になる。感度が高い方向と低い方向を区別できる。
```

### Q6. 自然勾配

自然勾配が通常の勾配と異なる点はどれか。

```quiz
- 通常の勾配は確率分布の計量を必ず使う
- [x]自然勾配はフィッシャー計量を考慮し、分布の変化を基準に更新方向を調整する
- 自然勾配は学習率を必要としない
- 自然勾配はすべてのパラメータを固定する
S: /series/appendix.4#自然勾配の幾何学的意味-「霧」をどう動かすか
A: 自然勾配は座標上の長さだけでなく、確率分布の変化量を考慮する。計量の逆行列を使うため、大規模モデルでは近似が必要になる。
```

### Q7. 物差しの選択

AIの表現を測る物差しの選択について、妥当な説明はどれか。

```quiz
- [x]方向、階層、分布の非対称性、局所感度など、問いに応じて尺度を選ぶ
- どのタスクでもユークリッド距離だけを使う
- 物差しは結果に影響しない
- 非対称な尺度は必ず不適切である
S: /series/appendix.4#aiにとっての多層的な定規
A: 何を近いとみなすかは、尺度が定義する。単一の距離を万能とせず、表現したい構造と学習目的に合う物差しを選ぶことが重要である。
```

### Q8. 比喩の限界

AttentionやMoEを計量やダイバージェンスに対応づけるときの注意はどれか。

```quiz
- [x]対応は設計を考える比喩として有用だが、数学的な同一性や因果を自動的に意味しない
- 比喩で説明できれば厳密な定義は不要になる
- AttentionとMoEは必ず同じ計量を実装する
- 情報幾何学を使えばすべてのモデルの意味が確定する
S: /series/appendix.4#attentionとmoeとの比喩的対応
A: 幾何学的な対応づけは、モデルの設計を考える視点を与える。一方、実際に同じ構造が成立するかは、写像、計量、損失、条件を個別に確認する必要がある。
```
