# Appendix 4 理解度チェック：空間の「物差し」再考

## 距離と方向

### Q1. 内積とコサイン類似度

内積とコサイン類似度の違いとして、正しいものはどれか。

```quiz
- [x]内積はノルムを含み、コサインは方向を比べる
  R: 内積は $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ の形で大きさ（ノルム）と方向の両方を含むが、正規化後の内積であるコサイン類似度は向きだけを測る。
- コサイン類似度も内積と同様、ベクトルのノルムが大きいほど値が大きくなりやすい
  R: コサイン類似度はベクトルを単位長に正規化してから内積を取るため、ノルムの影響は打ち消され、値は方向（角度）だけで決まる。
- 内積はベクトルの向きが直交に近づくほど、ノルムの影響を強く受けるようになる
  R: 内積は常に大きさと方向の積として決まり、直交に近づくと $\cos\theta$ が0に近づいて内積自体が小さくなる。ノルムの影響が強まるわけではない。
- 両者はいずれもL2正規化を前提とする指標なので、正規化前のベクトルには使えない
  R: 内積はベクトルを正規化しなくてもそのまま計算できる指標であり、コサイン類似度だけが正規化後の内積として定義される。
S: /series/appendix.4#コサイン類似度-方向だけを見る
A: 内積は $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ のように大きさの影響を受ける。L2正規化後の内積はコサイン類似度になり、方向を比較しやすい。
```

### Q2. 双曲距離

双曲距離を使う動機として、適切なものはどれか。

```quiz
- 双曲距離は確率分布にしか使えない
  R: 双曲距離はPoincaré球モデルのようにベクトル空間上の点の間で定義される距離であり、確率分布に限定された道具ではない。
- [x]負の曲率の広がりで、階層の深さや分岐を表す
  R: 双曲空間は中心から離れるほど空間が指数的に広がる性質を持ち、この負の曲率による広がりが木構造のような階層の深さや分岐を表現するのに適している。
- 距離は階層構造を表現できない
  R: 距離の測り方次第で階層構造の表現力は変わり、双曲距離はまさに階層構造を表現しやすい性質を持つ測り方として導入されている。
- 双曲距離はユークリッド距離より計算コストが低い
  R: 双曲距離の動機は負の曲率による広がりで階層構造を表現することであり、計算コストの低さとは無関係である。
S: /series/appendix.4#双曲距離-階層構造の深さを測る
A: 双曲空間は距離に応じた広がりが大きく、階層的な分岐を表しやすい。どの距離が有効かは、データの構造に依存する。
```

### Q3. Kullback–Leibler（KL）ダイバージェンス

Kullback–Leibler（KL）ダイバージェンスを通常の距離と区別する特徴はどれか。

```quiz
- 対称で、三角不等式を満たす
  R: KLダイバージェンスは一般に $D_{\text{KL}}(P\|Q) \neq D_{\text{KL}}(Q\|P)$ であり対称性を持たず、数学的に厳密な意味での距離の公理を満たさない。
- 二つの分布が近いほど、引数の順序による値の差が大きくなる
  R: 分布が近づくほどKL(P‖Q)とKL(Q‖P)はいずれも0に近づいていき、引数の順序による差もむしろ小さくなっていく。
- 分布の台が重なっている限り、値は0から1の間に収まる有界な量になる
  R: KLダイバージェンスは対数比の期待値として定義される量であり、分布の隔たりが大きい場合には0から1の範囲を超えて発散しうる。
- [x]一般に非対称で、引数の順序で値が異なる
  R: KLダイバージェンスは真の分布とモデル分布のどちらを基準に測るかによって値が変わり、Forward KLとReverse KLは一般に異なる値を取る。
S: /series/appendix.4#klダイバージェンス-分布の非対称な隔たり
A: KLダイバージェンスは分布の隔たりを測るが、方向を持つため一般には対称でない。学習では、この非対称性がどちらを基準にするかという意味を持つ。
```

### Q4. 非対称性と学習

KLダイバージェンスの非対称性が学習に与える意味はどれか。

```quiz
- KLは学習の駆動力にならない
  R: クロスエントロピー損失はForward KLダイバージェンスとエントロピーの和として表され、KLダイバージェンスはまさに学習を駆動するエネルギーとして機能する。
- [x]基準と近似の役割が、重視する誤差を左右する
  R: KL(P‖Q)は真の分布Pの確率が高い場所でQがズレることを重く罰し、KL(Q‖P)はモデルQの確率が高い場所でのズレを重く罰するため、どちらを基準にするかで学習が重視する誤差の領域が変わる。
- 非対称性は数値計算上の誤差にすぎない
  R: KLの非対称性は数値計算の丸め誤差ではなく、対数比の期待値をどちらの分布で取るかという定義そのものに由来する数学的な性質である。
- 引数の順序を入れ替えても、学習の方向は同じになる
  R: KL(P‖Q)とKL(Q||P)は一般に異なる値と異なる勾配を与えるため、引数の順序を入れ替えると学習が重視する領域や更新の方向も変わりうる。
S: /series/appendix.4#非対称性が学習を駆動する
A: KL(P||Q)とKL(Q||P)は異なる最適化上の性質を持つ。どちらを使うかによって、分布のどの領域を重視するかが変わりうる。
```

## 計量と更新

### Q5. フィッシャー情報

フィッシャー情報行列が測るものとして、最も適切なのはどれか。

```quiz
- データ点の個数
  R: フィッシャー情報行列はスコア関数の共分散として定義される量であり、観測されたデータ点の個数そのものを表す量ではない。
- 予測の正しさそのもの
  R: フィッシャー情報行列はパラメータ変化に対する分布の感度を測る計量であり、予測が正しいかどうかという評価とは異なる概念である。
- 各方向で同じ固定距離
  R: フィッシャー情報行列は方向ごとに異なる値を持つ行列であり、パラメータ空間の各方向で感度が異なることを表現する。すべての方向で同じ固定距離になるわけではない。
- [x]パラメータ変化への分布の感度
  R: フィッシャー情報行列はパラメータをわずかに動かしたときに予測分布がどれだけ敏感に変化するかを、スコア関数の共分散として定量化したものである。
S: /series/appendix.4#フィッシャー情報行列-分布の感度を測る
A: フィッシャー情報は、パラメータ方向ごとの分布の変化しやすさを表す計量になる。感度が高い方向と低い方向を区別できる。
```

### Q6. 自然勾配

自然勾配が通常の勾配と異なる点はどれか。

```quiz
- 自然勾配は学習率を必要としない
  R: 自然勾配法もフィッシャー情報行列の逆行列で勾配を補正したうえで更新幅を決める学習率 $\eta$ を用いており、学習率が不要になるわけではない。
- [x]フィッシャー計量で更新を調整する
  R: 自然勾配法はフィッシャー情報行列の逆行列を勾配に掛けることで、パラメータ空間の曲がりを考慮した更新方向を計算する。
- 通常の勾配は確率分布の計量を使う
  R: 通常の勾配降下法はパラメータ空間を平坦なユークリッド空間として扱っており、確率分布の計量であるフィッシャー情報行列は用いない。
- 自然勾配は各パラメータを固定する
  R: 自然勾配法はすべてのパラメータを更新する最適化手法であり、フィッシャー計量に基づいて更新幅を方向ごとに調整するのであって、パラメータを固定するものではない。
S: /series/appendix.4#自然勾配の幾何学的意味-「霧」をどう動かすか
A: 自然勾配は座標上の長さだけでなく、確率分布の変化量を考慮する。計量の逆行列を使うため、大規模モデルでは近似が必要になる。
```

### Q7. 物差しの選択

AIの表現を測る物差しの選択について、妥当な説明はどれか。

```quiz
- ユークリッド距離は座標変換に対して不変なので、表現空間の設計にかかわらず最初に選ぶべき物差しである
  R: ユークリッド距離は配置のための対称的な距離の一つに過ぎず、学習の方向性を決める非対称な尺度としての役割は持たない。表現したい構造と学習目的に応じて適切な物差しを選ぶべきであり、特定の距離を最初に選ぶべきものとして優先することはできない。
- 双曲距離は階層構造を表しやすい性質があるため、他の距離より優先的に採用するべきである
  R: 双曲距離が有効なのは階層・木構造を表現したい場合であり、方向の多様性を重視する場合には球面、特定の構造を前提しない場合にはユークリッド距離が適するなど、空間の選び方は表現したい構造に応じて変わる。
- KLダイバージェンスのような非対称な尺度は、学習の損失関数としては使えても評価指標には転用できない
  R: KLダイバージェンスは損失関数として学習を駆動する一方で分布間の隔たりを表す尺度としての性質自体は変わらず、評価指標として使えないと決まっているわけではない。
- [x]表現したい構造と学習目的に合う物差しを選ぶ
  R: 何を近いとみなすかは尺度が定義するものであり、単一の距離を万能とせず、表現したい構造と学習目的に応じて内積・双曲距離・KLダイバージェンスなどを使い分けるのが妥当である。
S: /series/appendix.4#aiにとっての多層的な定規
A: 何を近いとみなすかは、尺度が定義する。単一の距離を万能とせず、表現したい構造と学習目的に合う物差しを選ぶことが重要である。
```

### Q8. 比喩の限界

同じ二つの分布を比べても、KLの引数の順序で学習結果が変わった。この現象への対応として、最も適切なものはどれか。

```quiz
- 引数の順序は実装上の差とみなし、学習目的は変えない
  R: KLの引数の順序は単なる実装上の違いではなく、どちらの分布を基準にしてどの領域のズレを重く罰するかという学習目的そのものに関わる選択である。
- 両方の向きのKLを計算し、値が小さい方を損失として採用する
  R: KLの値の大小は向きの適否を決める根拠にならない。どの向きが適切かは、基準と近似の役割や重視する領域で決まり、値の大小だけでは学習目的に沿った選択ができない。
- 非対称性を平均化してから、どの領域を重視したかを記録しない
  R: 非対称性を平均化してしまうとForward KLとReverse KLがそれぞれ重視する領域の違いという情報が失われ、学習がどちらの誤差を重視したのかを追跡できなくなる。
- [x]分布の役割を明示し、KLの向きと重視領域を比較する
  R: KLの向きは基準と近似の役割や重視する領域を左右するため、どちらの分布を基準に置いたかを明示し、向きによって学習結果がどう変わったかを比較することが適切な対応になる。
S: /series/appendix.4#非対称性が学習を駆動する
A: KLの向きは、基準と近似の役割や重視する領域を変える。損失を選ぶときは、分布の役割、評価指標、目的への影響を明示する必要がある。
```
