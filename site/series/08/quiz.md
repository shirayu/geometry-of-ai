# 第8回 理解度チェック：時間の発見

## 一撃からプロセスへ

### Q1. GANとVAEの生成

GANやVAEについて、「一撃変換」と呼ばれる限界は何を指すか。

```quiz
- GANが画像を生成できない
- [x]潜在表現から出力までの中間過程が明示されず、途中の制御や修正が難しい
- 生成器が時間刻みを使う
- VAEが確率分布を扱えない
S: /series/08#一撃変換の限界
A: 一撃変換では、始点と終点の関係は学べても、途中で何が起きたかを操作しにくい。モード崩壊や学習不安定性も制御を難しくする。
```

### Q2. 残差接続

ResNetの残差接続 $\mathbf{h}_{t+1}=\mathbf{h}_t+f(\mathbf{h}_t)$ の効果として、適切な説明はどれか。

```quiz
- 各層を同じ関数に固定する
- [x]恒等写像への近道を残し、勾配や情報が深い層を通過しやすくする
- 各層の入力をそのまま消去する
- 連続時間のODEを厳密に解く
S: /series/08#残差接続-resnet
A: 残差接続には入力をそのまま伝える経路がある。残差が小さければ状態変化も小さく、勾配や情報の流れを安定させやすい。
```

### Q3. ベクトル場としての解釈

ニューラルネットワークをベクトル場として見るとき、関数の出力は何を表すか。

```quiz
- 最終出力の座標そのもの
- データセット全体の平均だけ
- [x]その地点で状態をどの方向へどれだけ変化させるかという更新規則
- 各地点で同じ固定ベクトル
S: /series/08#ベクトル場としてのニューラルネットワーク
A: ベクトル場の見方では、関数は完成品を一撃で返すのではなく、現在の状態に応じた局所的な変化を返す。反復や積分によって軌道が生じる。
```

### Q4. ResNetとNeural ODE

ResNetとNeural ODEの関係について、最も慎重な説明はどれか。

```quiz
- [x]ResNetをオイラー法による離散的な時間発展と解釈できるが、両者は同一ではない
- 残差接続と時間発展には関係がない
- ResNetは連続時間の微分方程式を厳密に解いている
- Neural ODEは離散層を持たないため学習できない
S: /series/08#残差接続の幾何学的再解釈
A: 残差更新はODEのオイラー法に似た形を持つ。この対応は有用な解釈だが、実際のResNetは離散的なネットワークであり、厳密な同一性ではない。
```

## 安定した時間発展

### Q5. 正規化層

LayerNormとL2正規化の違いとして、正しいものはどれか。

```quiz
- LayerNormは単位ノルムを実現する
- [x]LayerNormは平均と分散を正規化するが、一般にベクトルを単位ノルムへ固定する操作ではない
- L2正規化は特徴の平均と分散をバッチごとに合わせる
- 両者は数学的にそのまま同じ操作である
S: /series/08#正規化層の役割
A: LayerNormやRMSNormは活性化のスケールを整えるが、L2正規化とは目的と制約が異なる。正規化の名前だけで球面制約と同一視してはいけない。
```

### Q6. Neural ODEの表現力

Neural ODEの表現力について注意すべき点はどれか。

```quiz
- 次元を増やす拡張は連続時間の考え方と矛盾する
- 連続時間にすれば任意の写像を表現できる
- [x]通常の連続時間フローには、軌道の交差や次元の変化に関する制約があり、Augmented Neural ODEsなどの拡張が提案される
- ODEは初期値に依存しない
S: /series/08#neural-odeの表現力の限界とaugmented-neural-odes
A: ODEで生成される流れは連続性や可逆性に関する制約を受ける。表現力を補うため、補助次元を加える拡張などが考えられる。
```

### Q7. 時間の明示化

生成モデルに時間軸を導入する利点として、最も適切な説明はどれか。

```quiz
- ノイズを学習前に消去できる
- 生成の計算を一度で終えられる
- [x]生成状態の変化を段階として記述し、途中の状態や更新方向を設計・観察できる
- 時間軸を入れると潜在表現は不要になる
S: /series/08#時間の明示化
A: 時間を明示すると、始点から終点への変換を中間状態の連鎖として扱える。制御性が増す一方、計算量や数値積分の設計も必要になる。
```

### Q8. 時間発展を導入する意義

生成モデルの出力品質は同じだが、時間刻みを変えると軌道が大きく変わる。この結果への対応として、最も適切なものはどれか。

```quiz
- [x]ベクトル場、刻み幅、数値積分の安定性を切り分け、品質と計算量を比較する
- 空間の表現だけを比較し、積分器や刻み幅は固定した要因とみなす
- 刻み幅を細かくするほど、モデルの誤差も同じ割合で減るとみなす
- 軌道を可視化すれば、生成分布の一致も確認できたとみなす
S: /series/08#まとめ-時間という次元の発見
A: 時間発展では、ベクトル場の学習と数値積分の誤差が分かれる。軌道の見た目だけでなく、刻み幅、安定性、生成品質、計算量を併せて評価する。
```
