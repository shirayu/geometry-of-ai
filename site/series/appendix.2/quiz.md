# Appendix 2 理解度チェック：多様体の純度問題

## データ品質を測る

### Q1. 「正しさ」の類型

データ品質の「正しさ」を複数の類型に分ける理由はどれか。

```quiz
- データ品質はラベル誤りの割合だけで決まるため、類型を分ける実益は小さいから
- 正しさは表現空間での距離が近いかどうかで判定できるから
- [x]論理整合性・事実整合性・規範整合性は互いに独立した基準だから
- ラベルが正しければ、事実との一致も同時に満たされるから
S: /series/appendix.2#「正しさ」の3類型
A: データの正しさは、推論規則に従うか（論理整合性）、観測や世界知識と一致するか（事実整合性）、価値判断として望ましいか（規範整合性）という側面に分かれる。検証に必要なものが類型ごとに異なるため、形や距離だけで全てを判定することはできない。
```

### Q2. 正規化の射程

正規化が解決しうる問題と、解決しない問題の組み合わせはどれか。

```quiz
- 正規化はデータの真偽や意味の妥当性を判定できるが、学習のスケールや安定性への効果は乏しい
- [x]正規化は学習のスケールや安定性を助けうるが、データの真偽や意味の妥当性を保証しない
- 正規化を使えば外部検証は不要になる
- 正規化は事実誤認を直接検出し、表現のスケールには影響しない
S: /series/appendix.2#正規化が解決したこと、しなかったこと
A: 正規化は最適化や表現のスケールに関わる効果を持つが、データが真実か、タスクに適切かまでは判定しない。幾何学的な整形と意味の検証は分けて考える必要がある。
```

### Q3. 幾何学的データ選別

表現空間を使ったデータ選別の注意点はどれか。

```quiz
- [x]距離や密度は表現に依存し、品質そのものではない
- 低密度の領域は正しいデータである
- 高密度の領域は有害データである
- 表現距離が近いデータは同じ品質である
S: /series/appendix.2#測定空間に関する注意
A: 距離や密度は、どの表現空間と計量を使ったかに依存する。幾何学的な異常が見つかっても、それだけでデータの真偽や有害性を断定できない。
```

### Q4. 識別不能性

幾何学単独でデータ品質を識別しにくい原理的な理由はどれか。

```quiz
- [x]同じ表現上の位置や形が、異なる意味や真偽を持ちうるから
<!-- quiz-lint-ignore: length - 「位置・形」と「意味・真偽」という2軸の対応関係を正確に述べるため正解が長くなるのが必然 -->
- データ品質は距離の定義そのものであるから
- 各データは異なる座標に置かれるから
- 曲率を測れば意味が一意に決まるから
S: /series/appendix.2#原理的な識別不能性
A: 同じ幾何学的配置でも、文脈や外部知識によって意味は異なりうる。形状の観測は品質の手がかりになるが、意味の識別には別の情報が必要である。
```

## 確信と動態へ

### Q5. 確信した嘘

「確信した嘘」と「無知の捏造」の違いとして、適切な説明はどれか。

```quiz
- 両者は生成時のロジットのピーク幅を測れば区別できる
- 前者は学習データの誤りに由来し、後者はモデル構造の欠陥にのみ由来する
- 前者は訓練データの偏りの問題であり、モデルの推論過程とは切り離して扱える
- [x]前者は誤信念、後者は知識不足をもっともらしく補う
S: /series/appendix.2#幾何学的な2類型の対比
A: 誤った知識を確信している場合と、知らない内容を補って生成する場合では、必要な検出や対策が異なる。確信度だけで原因を一意に決めることはできない。
```

### Q6. 鶏と卵問題

データ選別と表現学習の「鶏と卵問題」とは何か。

```quiz
- データ選別は学習前に定義できるので、表現学習と相互作用しないこと
- [x]選別に使う表現も選別前データで学習されること
- データ選別の誤りは、その後の学習で平均化されて表現に影響しないこと
- 表現空間を適切に選べば、選別基準の誤判定は起きないこと
S: /series/appendix.2#鶏と卵問題
A: データ品質を測る表現はデータから学習されるため、品質の悪いデータが測定空間を歪める可能性がある。選別と表現学習を独立に置けない難しさである。
```

### Q7. 静的と動的

静的なデータ品質の問題が、推論時にはどのように現れうるか。

```quiz
- 推論時のサンプリング温度を調整すれば、学習データの偏りの影響は打ち消せる
- データ品質の問題は学習時にのみ現れ、推論時の出力とは別の指標で評価すればよい
- 動的な問題は静的な配置を時間方向に引き延ばしただけで、原因は別に存在する
- [x]学習空間の歪みが、推論時の軌道のトラップになりうる
S: /series/appendix.2#静的な問題と動的な問題の対応
A: 静的なデータの偏りや誤りは、学習された表現やエネルギー地形を通じて推論の動きを歪めうる。この対応は研究課題であり、単純な同一視ではない。
```

### Q8. 成功指標

表現空間の密度でデータを選別したところ、データ量は減ったが下流の事実性と頑健性が悪化した。成功を判定する指標として、最も適切なものはどれか。

```quiz
- 一つのベンチマークの精度を、ほかの目的にも共通の基準として使う
- データ数の削減率を主指標にし、下流の変化は補足にする
- 密度の高い領域を残せたかで品質を判定する
- [x]幾何学的な変化と、下流性能・事実性・頑健性・運用コストを目的別に併用する
S: /series/appendix.2#成功指標の分類
A: データ量や密度は選別の結果であって、目的そのものではない。下流性能、事実性、頑健性、運用コストを、用途に応じた指標として組み合わせる。
```
