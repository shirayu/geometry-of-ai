# Appendix 2 理解度チェック：多様体の純度問題

## データ品質を測る

### Q1. 「正しさ」の類型

データ品質の「正しさ」を複数の類型に分ける理由はどれか。

```quiz
- データ品質はラベル誤りの割合だけで決まるため、類型を分ける実益は小さいから
  R: 論理整合性・事実整合性・規範整合性はそれぞれ検証に必要なものが異なり、ラベル誤りの割合という単一の指標だけに還元できない。
- 正しさは表現空間での距離が近いかどうかで判定できるから
  R: 距離は表現の取り方に依存する量であり、論理・事実・規範のいずれの整合性も表現距離だけで判定できるとは限らない。
- [x]論理整合性・事実整合性・規範整合性は互いに独立した基準だから
  R: 推論規則に従うか、観測や世界知識と一致するか、価値判断として望ましいかは、それぞれ検証方法が異なる独立した基準であり、一つを満たしても他が自動的に満たされるわけではない。
- ラベルが正しければ、事実との一致も同時に満たされるから
  R: ラベルの正しさは教師信号としての整合性であり、それが事実整合性という別の基準を同時に満たす根拠にはならない。
S: /series/appendix.2#「正しさ」の3類型
A: データの正しさは、推論規則に従うか（論理整合性）、観測や世界知識と一致するか（事実整合性）、価値判断として望ましいか（規範整合性）という側面に分かれる。検証に必要なものが類型ごとに異なるため、形や距離だけで全てを判定することはできない。
```

### Q2. 正規化の射程

正規化が解決しうる問題と、解決しない問題の組み合わせはどれか。

```quiz
- 正規化はデータの真偽や意味の妥当性を判定できるが、学習のスケールや安定性への効果は乏しい
  R: 正規化が実際に効果を持つのは学習の発散抑制や収束の安定化といったスケール面であり、データの真偽や意味の妥当性の判定とは効果の方向が逆になっている。
- [x]正規化は学習のスケールや安定性を助けうるが、データの真偽や意味の妥当性を保証しない
  R: 正規化はノルムを一定に保つことで学習の発散抑制や収束の安定化に寄与するが、ベクトルの向いている方向が正しいかどうかは判定しない。
- 正規化を使えば外部検証は不要になる
  R: 正規化は形式の安定を与えるだけであり、内容の真偽を判定する仕組みではないため、外部検証の必要性をなくすものではない。
- 正規化は事実誤認を直接検出し、表現のスケールには影響しない
  R: 正規化が直接作用するのはベクトルのノルムというスケール面であり、事実誤認の検出とは無関係である。
S: /series/appendix.2#正規化が解決したこと、しなかったこと
A: 正規化は最適化や表現のスケールに関わる効果を持つが、データが真実か、タスクに適切かまでは判定しない。幾何学的な整形と意味の検証は分けて考える必要がある。
```

### Q3. 幾何学的データ選別

表現空間を使ったデータ選別の注意点はどれか。

```quiz
- [x]距離や密度は表現に依存し、品質そのものではない
  R: 距離や密度は、どの表現空間とどの計量を使ったかによって値が変わる測定量であり、データ品質という実体そのものと同一視できない。
- 低密度の領域は正しいデータである
  R: 低密度は珍しいデータであることを示すに過ぎず、珍しさと正しさは別の性質であるため、低密度をもって正しいと判定することはできない。
- 高密度の領域は有害データである
  R: 高密度は単に近傍にサンプルが多く集まっていることを示すだけであり、それが有害性を意味するわけではない。
- 表現距離が近いデータは同じ品質である
  R: 表現距離は選んだ表現空間や計量に依存する量であり、距離が近いことがデータの品質の同一性を保証するわけではない。
S: /series/appendix.2#測定空間に関する注意
A: 距離や密度は、どの表現空間と計量を使ったかに依存する。幾何学的な異常が見つかっても、それだけでデータの真偽や有害性を断定できない。
```

### Q4. 識別不能性

幾何学単独でデータ品質を識別しにくい原理的な理由はどれか。

```quiz
- [x]同じ表現上の位置や形が、異なる意味や真偽を持ちうるから
  R: 幾何学が捉えるのは距離・曲率・位相といった内在的性質であり、同じ配置に対して外部知識や文脈によって異なる意味や真偽が付与されうるため、形だけから意味を一意に決められない。
<!-- quiz-lint-ignore: length - 「位置・形」と「意味・真偽」という2軸の対応関係を正確に述べるため正解が長くなるのが必然 -->
- データ品質は距離の定義そのものであるから
  R: データ品質は距離という測定量に還元される概念ではなく、距離は品質を測るための手段の一つに過ぎない。
- 各データは異なる座標に置かれるから
  R: 座標が異なること自体は単なる番地の違いであり、それが幾何学単独での品質識別の困難さを説明する理由にはならない。
- 曲率を測れば意味が一意に決まるから
  R: 曲率も内在的性質の一つであり、意味を一意に定めるものではない。曲率の測定だけで識別できるなら、識別不能性という問題自体が生じない。
S: /series/appendix.2#原理的な識別不能性
A: 同じ幾何学的配置でも、文脈や外部知識によって意味は異なりうる。形状の観測は品質の手がかりになるが、意味の識別には別の情報が必要である。
```

## 確信と動態へ

### Q5. 確信した嘘

「確信した嘘」と「無知の捏造」の違いとして、適切な説明はどれか。

```quiz
- 両者は生成時のロジットのピーク幅を測れば区別できる
  R: 確信した嘘は集中度が高く、無知の捏造は集中度が低いという幾何学的な違いはあるが、集中度が高いこと自体は正しい方向を向いているかどうかを教えないため、ピーク幅だけで両者を区別できるとは限らない。
- 前者は学習データの誤りに由来し、後者はモデル構造の欠陥にのみ由来する
  R: 無知の捏造は知識の欠如から生じる曖昧な予測であり、モデル構造の欠陥だけに原因を限定する根拠はない。
- 前者は訓練データの偏りの問題であり、モデルの推論過程とは切り離して扱える
  R: 確信した嘘は訓練データの誤りに由来するとしても、それは確信という形でモデルの推論過程に組み込まれており、切り離して扱えるものではない。
- [x]前者は誤信念、後者は知識不足をもっともらしく補う
  R: 確信した嘘は集中度が高いまま間違った方向を指す誤信念の表出であり、無知の捏造は集中度が低い状態で知識不足をもっともらしい形で埋める現象であり、原因も対策も異なる。
S: /series/appendix.2#幾何学的な2類型の対比
A: 誤った知識を確信している場合と、知らない内容を補って生成する場合では、必要な検出や対策が異なる。確信度だけで原因を一意に決めることはできない。
```

### Q6. 鶏と卵問題

データ選別と表現学習の「鶏と卵問題」とは何か。

```quiz
- データ選別は学習前に定義できるので、表現学習と相互作用しないこと
  R: 選別に使う表現自体が選別前のデータから学習されるため、データ選別と表現学習は独立に定義できず、循環的な依存関係にある。
- [x]選別に使う表現も選別前データで学習されること
  R: 品質を測るための表現空間が、まだ選別されていないデータから学習されているため、品質の悪いデータが測定空間そのものを歪めうるという循環依存が生じる。
- データ選別の誤りは、その後の学習で平均化されて表現に影響しないこと
  R: 選別の誤りは正しい多様体を前提に検出を行う構造の中に組み込まれており、平均化されて自動的に打ち消される保証はない。
- 表現空間を適切に選べば、選別基準の誤判定は起きないこと
  R: 表現空間自体が選別前のデータから学習される以上、表現空間の選び方を工夫するだけでは循環依存という原理的な問題を回避できない。
S: /series/appendix.2#鶏と卵問題
A: データ品質を測る表現はデータから学習されるため、品質の悪いデータが測定空間を歪める可能性がある。選別と表現学習を独立に置けない難しさである。
```

### Q7. 静的と動的

静的なデータ品質の問題が、推論時にはどのように現れうるか。

```quiz
- 推論時のサンプリング温度を調整すれば、学習データの偏りの影響は打ち消せる
  R: 温度調整はサンプリングの多様性を変えるだけであり、学習された表現やエネルギー地形そのものに刻まれた歪みを解消するものではない。
- データ品質の問題は学習時にのみ現れ、推論時の出力とは別の指標で評価すればよい
  R: 静的なデータの偏りや誤りは学習された表現やエネルギー地形を通じて推論の動きに影響しうるため、学習時と推論時を切り離して評価することはできない。
- 動的な問題は静的な配置を時間方向に引き延ばしただけで、原因は別に存在する
  R: 動的な問題は静的なデータ品質の歪みが推論の軌道に現れたものであり、原因が別にあるとする根拠はない。
- [x]学習空間の歪みが、推論時の軌道のトラップになりうる
  R: 静的なデータの偏りや誤りは学習された表現やエネルギー地形を通じて刻まれ、それが推論時の軌道を偽の極小値に引き込むトラップとして現れうる。
S: /series/appendix.2#静的な問題と動的な問題の対応
A: 静的なデータの偏りや誤りは、学習された表現やエネルギー地形を通じて推論の動きを歪めうる。この対応は研究課題であり、単純な同一視ではない。
```

### Q8. 成功指標

表現空間の密度でデータを選別したところ、データ量は減ったが下流の事実性と頑健性が悪化した。成功を判定する指標として、最も適切なものはどれか。

```quiz
- 一つのベンチマークの精度を、ほかの目的にも共通の基準として使う
  R: 下流性能・事実性・頑健性・運用コストはそれぞれ異なる目的に対応する指標であり、一つのベンチマーク精度を万能の基準として流用すると、実際に悪化した事実性や頑健性の変化を見落としうる。
- データ数の削減率を主指標にし、下流の変化は補足にする
  R: データ量の削減は選別の結果であって目的そのものではなく、削減率を主指標にすると下流性能や事実性の悪化を見逃しかねない。
- 密度の高い領域を残せたかで品質を判定する
  R: 密度は表現空間での測定量に過ぎず、密度の高い領域を残せたかどうかは下流性能や事実性・頑健性の変化を直接反映しない。
- [x]幾何学的な変化と、下流性能・事実性・頑健性・運用コストを目的別に併用する
  R: データ量や密度といった幾何学的な変化は選別の結果であり、実際の成功は下流性能・事実性・頑健性・運用コストといった用途に応じた指標を組み合わせて評価する必要がある。
S: /series/appendix.2#成功指標の分類
A: データ量や密度は選別の結果であって、目的そのものではない。下流性能、事実性、頑健性、運用コストを、用途に応じた指標として組み合わせる。
```
