# 第3回 理解度チェック：プラネタリウムの建設

## 球面を選ぶ

### Q1. 正規化と球面制約

通常の正規化と、球面制約を徹底する設計の違いとして正しいものはどれか。

```quiz
- 正規化は表現を一定ノルムの空間に置く設計であり、球面制約は局所的なスケール調整にすぎない
  R: 正規化と球面制約の役割が入れ替わっている。ノルムを厳密に1へ固定するのは球面制約側であり、統計量によるスケール調整は従来の正規化側の性質である。
- 両者は同じ操作であり、目的も同じである
  R: 従来の正規化は統計量でスケールを安定させる操作であり、ノルムは必ずしも1にならない。球面制約は幾何学的な長さを厳密に1に固定して球面上で計算することを目的としており、両者は操作も目的も異なる。
- 球面制約はベクトルの方向を使えなくする
  R: 球面制約はノルムを1に固定することで方向を主な自由度として残す設計であり、方向を使えなくするどころか方向こそが表現の中心になる。
- [x]正規化は局所調整、球面制約は一定ノルムを保つ
  R: 従来の正規化は計算の一部で行うスケール調整であるのに対し、球面制約は表現空間全体を一定ノルムの球面として扱い、方向を主な自由度にする設計である。
S: /series/03#「正規化」と「球面制約」の違い
A: 正規化は計算の一部で行うスケール調整でもある。一方、球面制約は表現空間そのものを一定ノルムの球面として扱い、方向を主な自由度にする。
```

### Q2. nGPT（正規化Transformer設計）の設計思想

nGPT（正規化Transformer設計）のように表現や重みを球面上に置く設計の狙いはどれか。

```quiz
- 各意味情報をノルムに集約し、方向には含めない
  R: nGPTはノルムを1に固定して自由度から外す設計であり、意味情報をノルムに集約するのではなく、角度（方向）に意味を担わせる。
- 任意のデータで球面が最適になることを実現する
  R: 球面制約は仮説段階のメカニズムに基づく設計であり、あらゆるデータや高速化の要因が厳密に証明されているわけではない。球面が常に最適になることを保証するものではない。
- SoftmaxやAttentionを使わずに済ませる
  R: nGPTは注意機構やFFNの出力を含むTransformerの構成要素すべてに正規化を課す設計であり、SoftmaxやAttention自体を置き換えたり不要にしたりするものではない。
- [x]ノルムの自由度を制御し、角度を中心に表現と計算を設計する
  R: nGPTは埋め込み・注意機構の出力・FFNの出力・残差接続後のすべてを正規化し、ノルムの暴走や役割の混線を抑えて角度（方向）を中心に表現と計算を組み立てる設計である。
S: /series/03#ngptとは何か
A: 球面化はノルムの暴走や役割の混線を抑え、方向による表現を明示的に扱う設計である。ただし、球面が常に最適な空間だと保証するものではない。
```

### Q3. 球面上の距離

球面上で二つの表現の近さを測るとき、中心的な情報になるものはどれか。

```quiz
- 各ベクトルのノルムであり、方向は無関係である
  R: 球面上ではノルムは1に固定されており自由度として使われないため、近さを決めるのはノルムではなく方向（角度）である。
- 原点を通る直線の長さである
  R: 球面上の自然な経路は原点を通る直線ではなく、球面に沿った大円の弧であり、その弧長（角度）が測地線距離に対応する。
- [x]角度であり、球面上では測地線距離に対応する
  R: 同じ球面上のベクトル同士では内積や角度が方向の近さを表し、球面上の自然な経路である大円の弧の長さが測地線距離になる。
- 座標成分の順番である
  R: 座標成分の並び順は表現の意味とは無関係であり、球面上の近さは内積や角度といった幾何学的な量で測られる。
S: /series/03#測地線距離
A: 同じ球面上にあるベクトルでは、内積や角度が方向の近さを表す。球面上の自然な経路は大円の弧であり、その長さが測地線距離になる。
```

## 球面上の確率と学習

### Q4. von Mises–Fisher（vMF）分布の役割

von Mises–Fisher（vMF）分布を球面上で使う理由として、適切なものはどれか。

```quiz
- 確率を持たない決定論的なベクトルを扱う
  R: vMF分布は平均方向と集中度によって球面上の確率密度を定める分布であり、確率を持たない決定論的なベクトルを扱う枠組みではない。
- ユークリッド空間の全方向に無制限のノルムを持たせる
  R: vMF分布は単位球面上に定義される分布であり、ノルムが固定された球面上での方向の集中を表すものであって、ユークリッド空間で無制限のノルムを扱うものではない。
- [x]球面上の方向の確率集中を表現できる
  R: vMF分布は平均方向と集中度を使い、球面上のどの方向の周囲に確率が集まるかを表現する、球面に合わせた確率モデルである。
- どの方向も同じ確率に固定する
  R: 集中度パラメータが0のときは一様分布になるが、集中度が大きくなると平均方向の周囲に確率が集中するため、どの方向も常に同じ確率になるわけではない。
S: /series/03#vmf分布の定義
A: vMF分布は平均方向と集中度を使い、球面上でどの方向の周囲に確率が集まるかを表す。球面に合わせた確率モデルである。
```

### Q5. 集中度 $\kappa$

vMF分布の集中度 $\kappa$ が大きくなると、一般に何が起きるか。

```quiz
- [x]大きいほど平均方向の周囲に集中する
  R: 集中度は分布の鋭さを制御するパラメータであり、大きくなるほど分布は平均方向の周囲に集中し、不確実性が小さくなる。
- 球面全体へ一様に広がる
  R: 球面全体への一様分布に対応するのは集中度が0の場合であり、集中度が大きくなるにつれて分布はむしろ平均方向へ狭く集中していく。
- 集中度が上がると平均方向が消える
  R: 平均方向は集中度とは別に指定されるパラメータであり、集中度が大きくなっても平均方向が消えるのではなく、分布がその方向へより鋭く集まる。
- 球面の半径が変わり、分布の幅は変わらない
  R: 集中度は球面の半径ではなく分布の広がり方を制御するパラメータであり、大きくなるほど分布の幅は狭くなる。
S: /series/03#集中度-kappa-の直感
A: $\kappa$ は球面上の分布が平均方向へどれだけ集中しているかを表す。大きいほど不確実性が小さく、方向がはっきりした分布になる。
```

### Q6. vMFと正規分布

vMF分布と正規分布の関係について、慎重な説明はどれか。

```quiz
- vMFには集中度に相当するパラメータがない
  R: vMF分布の集中度は正規分布の分散の逆数に対応するパラメータであり、集中度に相当する要素を欠いているわけではない。
- [x]vMFは球面上、正規分布はユークリッド空間の分布である
<!-- quiz-lint-ignore: length - 定義域の違いという事実を簡潔に述べただけで、短い誤答3つとの語数差は内容の必然（固有名詞2つを含むため） -->
  R: 平均方向と集中度の対応など類似点は多いが、vMF分布は単位球面上に定義され、正規分布はユークリッド空間全体に定義されるという、定義される空間そのものの違いがある。
- 正規分布は球面上でしか定義できない
  R: 正規分布はユークリッド空間全体で定義される分布であり、球面上でしか定義できないという説明は正規分布とvMF分布の定義域を取り違えている。
- vMFは正規分布と同じ分布である
  R: 平均方向や集中度のように類似した構造はあるが、定義される空間や分布全体の形は異なり、両者は同じ分布ではない。
S: /series/03#vmfと正規分布の対応
A: 高い集中度の近傍などでは、球面上の分布とユークリッド空間の正規分布に対応する直感を持てる。ただし、定義される空間と全体の形は異なる。
```

### Q7. 正規化による近似

球面上の学習で、通常の勾配を正規化して使う方法の位置づけはどれか。

```quiz
- 厳密なリーマン最適化そのものであり、近似ではなく球面上の測地線を正確に計算している
  R: ユークリッド勾配で更新してから球面へ射影する方法は射影勾配法の一種であり、学習率が十分小さいときにリーマン勾配降下法に近い挙動を示す近似にすぎず、厳密な計算ではない。
- [x]球面制約の近似で、厳密なリーマン最適化とは異なる
<!-- quiz-lint-ignore: hedge - 「近似であり厳密最適化ではない」という区別自体が問いへの正確な答えで、誤答1が既に同型の裏返し構文になっている -->
  R: ユークリッド勾配で更新した後に球面へ射影する手法は球面制約を保つ実用的な近似であり、接空間や測地線を厳密に扱うリーマン最適化とは区別される。
- 勾配の方向をそのまま消してしまう
  R: 正規化はユークリッド勾配で更新した結果を球面上へ射影する操作であり、勾配の方向情報を消し去るのではなく制約を保つために利用する。
- 正規化すれば学習率は不要になる
  R: 正規化は更新後に球面へ戻す操作であり、更新のステップ幅を決める学習率の必要性とは無関係で、学習率が大きい場合には近似が不正確になる。
S: /series/03#正規化による近似
A: 勾配の正規化や更新後の再正規化は、球面制約を保つ実用的な近似になる。一方、球面上の接空間や測地線を厳密に扱うリーマン最適化とは区別が必要である。
```

### Q8. 球面設計の限界

方向検索では球面制約モデルが有効だが、階層データと未知入力の検出では改善が見られない。この状況での次の設計判断はどれか。

```quiz
- 球面制約を維持し、改善しないタスクも同じ角度指標で評価する
  R: ノルムに意味があるタスクでは球面制約によって情報が失われるため、改善が見られないタスクにまで同じ角度指標を当てはめ続けるのは、球面設計の限界を無視した判断である。
- 方向検索の結果から、階層性と不確実性も説明できるとみなす
  R: 方向検索での有効性と、階層構造や不確実性の表現力は別の性質であり、片方の結果だけをもって他方まで説明できるとみなすのは過剰な一般化である。
- 未知入力を既知クラスの方向へ寄せ、分類確率を尖らせる
  R: 未知入力の検出が課題である状況で、未知入力を既知クラスの方向へ寄せてしまうと不確実性の情報がかえって失われ、検出の改善にはつながらない。
- [x]球面が担う役割を明示し、集中度や別の曲率を含む表現とタスク指標を比較する
  R: 球面は方向の比較には向くが、データの階層性や未知性まで同じ表現で扱えるとは限らないため、集中度や曲率の異なる表現を含めてタスクごとに比較する必要がある。
S: /series/03#球面設計の限界と注意点
A: 球面は方向の比較に向くが、データの階層性や未知性まで同じ表現で扱えるとは限らない。集中度、曲率、評価指標を分けて比較する必要がある。
```
