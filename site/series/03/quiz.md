# 第3回 理解度チェック：プラネタリウムの建設

## 球面を選ぶ

### Q1. 正規化と球面制約

通常の正規化と、球面制約を徹底する設計の違いとして正しいものはどれか。

```quiz
- 正規化は表現を一定ノルムの空間に置く設計であり、球面制約は局所的なスケール調整にすぎない
- 両者は同じ操作であり、目的も同じである
- 球面制約はベクトルの方向を使えなくする
- [x]正規化は局所調整、球面制約は一定ノルムを保つ
S: /series/03#「正規化」と「球面制約」の違い
A: 正規化は計算の一部で行うスケール調整でもある。一方、球面制約は表現空間そのものを一定ノルムの球面として扱い、方向を主な自由度にする。
```

### Q2. nGPT（正規化Transformer設計）の設計思想

nGPT（正規化Transformer設計）のように表現や重みを球面上に置く設計の狙いはどれか。

```quiz
- 各意味情報をノルムだけに集約する
- 任意のデータで球面が最適になることを実現する
- SoftmaxやAttentionを使わずに済ませる
- [x]ノルムの自由度を制御し、角度を中心に表現と計算を設計する
S: /series/03#ngptとは何か
A: 球面化はノルムの暴走や役割の混線を抑え、方向による表現を明示的に扱う設計である。ただし、球面が常に最適な空間だと保証するものではない。
```

### Q3. 球面上の距離

球面上で二つの表現の近さを測るとき、中心的な情報になるものはどれか。

```quiz
- 各ベクトルのノルムだけであり、方向は無関係である
- 原点を通る直線の長さだけである
- [x]角度であり、球面上では測地線距離に対応する
- 座標成分の順番だけである
S: /series/03#測地線距離
A: 同じ球面上にあるベクトルでは、内積や角度が方向の近さを表す。球面上の自然な経路は大円の弧であり、その長さが測地線距離になる。
```

## 球面上の確率と学習

### Q4. von Mises–Fisher（vMF）分布の役割

von Mises–Fisher（vMF）分布を球面上で使う理由として、適切なものはどれか。

```quiz
- 確率を持たない決定論的なベクトルだけを扱う
- ユークリッド空間の全方向に無制限のノルムを持たせる
- [x]球面上の方向の確率集中を表現できる
- どの方向も同じ確率に固定する
S: /series/03#vmf分布の定義
A: vMF分布は平均方向と集中度を使い、球面上でどの方向の周囲に確率が集まるかを表す。球面に合わせた確率モデルである。
```

### Q5. 集中度 $\kappa$

vMF分布の集中度 $\kappa$ が大きくなると、一般に何が起きるか。

```quiz
- [x]大きいほど平均方向の周囲に集中する
- 球面全体へ一様に広がる
- 集中度が上がると平均方向が消える
- 球面の半径が変わり、分布の幅は変わらない
S: /series/03#集中度-kappa-の直感
A: $\kappa$ は球面上の分布が平均方向へどれだけ集中しているかを表す。大きいほど不確実性が小さく、方向がはっきりした分布になる。
```

### Q6. vMFと正規分布

vMF分布と正規分布の関係について、慎重な説明はどれか。

```quiz
- vMFには集中度に相当するパラメータがない
- [x]vMFは球面上、正規分布はユークリッド空間の分布である
<!-- quiz-lint-ignore: length - 定義域の違いという事実を簡潔に述べただけで、短い誤答3つとの語数差は内容の必然（固有名詞2つを含むため） -->
- 正規分布は球面上でしか定義できない

```

### Q7. 正規化による近似

球面上の学習で、通常の勾配を正規化して使う方法の位置づけはどれか。

```quiz
- 厳密なリーマン最適化そのものであり、近似ではなく球面上の測地線を正確に計算している
- [x]球面制約の近似で、厳密なリーマン最適化とは異なる

```

### Q8. 球面設計の限界

方向検索では球面制約モデルが有効だが、階層データと未知入力の検出では改善が見られない。この状況での次の設計判断はどれか。

```quiz
- 球面制約を維持し、改善しないタスクも同じ角度指標で評価する
- 方向検索の結果だけで、階層性と不確実性も説明できるとみなす
- 未知入力を既知クラスの方向へ寄せ、分類確率を尖らせる
- [x]球面が担う役割を明示し、集中度や別の曲率を含む表現とタスク指標を比較する
S: /series/03#球面設計の限界と注意点
A: 球面は方向の比較に向くが、データの階層性や未知性まで同じ表現で扱えるとは限らない。集中度、曲率、評価指標を分けて比較する必要がある。
```
