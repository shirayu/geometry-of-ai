# Appendix 1 理解度チェック：量子化の幾何学

## 量子化と空間

### Q1. 量子化の基本

ニューラルネットワークの量子化とは何か。

```quiz
- 各重みをゼロにすること
- 学習データを確率分布へ変換すること
- [x]重みや活性を有限個の値へ写像すること
- 重みの次元を増やすこと
S: /series/appendix.1#基本概念
A: 量子化は、重みや活性化を低ビットの有限な表現へ写す操作である。メモリ使用量や演算コストを下げられる一方、量子化誤差が生じる。
```

### Q2. 重み空間の格子化

量子化を重み空間の「格子化」と見る説明として、正しいものはどれか。

```quiz
- 格子点は入力データごとに無限に増える
- [x]連続空間上の重みを、離散的な格子点へ近似的に射影する
- 格子化によってモデルの層数が増える
- 量子化後も重みは連続空間の任意の点を取る
S: /series/appendix.1#重み空間の「格子化」
A: 量子化は連続的な重みを有限個の代表値へ丸めるため、重み空間を離散的な格子として扱う操作に見なせる。射影先と誤差の大きさが性能に影響する。
```

### Q3. 決定境界への影響

量子化誤差が分類の決定境界付近で問題になりやすい理由はどれか。

```quiz
- 決定境界から遠い点ほど誤分類されるから
- 境界は量子化によって消えるから
- 量子化は出力確率に影響しないから
- [x]境界付近では小さな摂動で判定が反転しうるから
S: /series/appendix.1#決定境界への影響
A: 境界から十分離れた点は小さな誤差に頑健な場合が多いが、境界近傍では同じ誤差が判定を変えうる。量子化の評価では境界付近の挙動も確認する必要がある。
```

### Q4. 多様体仮説との接続

量子化と多様体仮説の関係について、最も慎重な説明はどれか。

```quiz
- 多様体仮説を満たしていれば、量子化ビット数を減らすほど局所構造の再現性は上がる
- 多様体上の表現を量子化すると、元の次元と同じ数の格子点が確保される
- 量子化された表現でも、内在次元は量子化前の値をそのまま保つ
- [x]分解能低下で局所構造が変わりうる
S: /series/appendix.1#多様体仮説との接続
A: 量子化は連続表現を粗くするため、近傍関係や局所構造が保たれるかが重要になる。多様体という見方は誤差の偏りを考える手がかりだが、性能を保証するものではない。
```

## 手法と誤差を選ぶ

### Q5. PTQ（Post-Training Quantization、学習後量子化）とQAT（Quantization-Aware Training、量子化認識学習）

PTQ（Post-Training Quantization、学習後量子化）とQAT（Quantization-Aware Training、量子化認識学習）の違いとして、正しいものはどれか。

```quiz
- PTQは学習中に量子化を意識し、QATは学習後にだけ量子化する
- PTQは校正データで統計量を集めるだけなので、QATより高精度になる傾向がある
- [x]PTQは学習後、QATは量子化を模擬して学習する
- QATは推論時の量子化誤差を学習でなくすため、PTQと違って誤差はほぼ0になる
S: /series/appendix.1#post-training-quantization-ptq
S: /series/appendix.1#quantization-aware-training-qat
A: PTQは学習済みモデルへ後から量子化を施す。QATは学習中に量子化誤差を意識させ、量子化後の性能低下を補いやすくする。
```

### Q6. 層ごとの感度

量子化ビット幅を層ごとに変える設計の理由はどれか。

```quiz
- [x]層ごとの感度に応じて、重要な層を高精度に保てるから
- 層ごとの感度は入力に依存しないから
- ビット幅を変えると量子化が無効になるから
- 各層が量子化誤差に同じ感度を持つから
S: /series/appendix.1#層ごとの感度
A: 量子化誤差の影響は層や入力によって異なる。感度の高い層を高ビットにする混合精度は、容量と性能の折り合いをつける方法になる。
```

### Q7. 活性化とKV cache（Key-Value cache、キー・バリューキャッシュ）

LLM（Large Language Model、大規模言語モデル）の量子化で、重み以外にも量子化対象になりうるものはどれか。

```quiz
- 活性化は非線形関数の出力なので、量子化の対象にならない
- KV cacheはサイズが固定されているため、量子化の必要がない
- [x]活性化やKV cacheも量子化できる
- 活性化の量子化はLayerNormと同じ操作で、暗黙に行われる
S: /series/appendix.1#量子化は「重み」だけでは終わらない-kv-cache-活性
A: LLM推論では重みだけでなく、活性化や蓄積されるKV cacheもメモリを消費する。それらを量子化すると効率は上がるが、誤差の影響も評価が必要になる。
```

### Q8. 量子化の限界

代表的な入力ではPTQ後の精度が保たれたが、まれな入力で誤分類が増えた。次の検証として、最も適切なものはどれか。

```quiz
- [x]層・入力分布ごとの感度と校正データを調べ、ビット幅やQATを比較する
- 球面制約があるため、量子化後の再正規化は検討しない
- 量子化誤差を一つの平均値で表し、入力別の誤差は見ない
- 代表的な入力だけで評価を続け、まれな入力は外れ値として扱う
S: /series/appendix.1#まとめ-量子化の幾何学
A: 量子化の誤差は層や入力で偏る。代表例の平均精度だけでなく、感度の高い層、まれな入力、校正、QATの効果を分けて評価する必要がある。
```
