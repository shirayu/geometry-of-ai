# Appendix 1 理解度チェック：量子化の幾何学

## 量子化と空間

### Q1. 量子化の基本

ニューラルネットワークの量子化とは何か。

```quiz
- [x]連続的な重みや活性を、より少ない有限個の値へ写像すること
- 重みの次元を必ず増やすこと
- 学習データを確率分布へ変換すること
- すべての重みをゼロにすること
S: /series/appendix.1#基本概念
A: 量子化は、重みや活性化を低ビットの有限な表現へ写す操作である。メモリ使用量や演算コストを下げられる一方、量子化誤差が生じる。
```

### Q2. 重み空間の格子化

量子化を重み空間の「格子化」と見る説明として、正しいものはどれか。

```quiz
- 量子化後も重みは連続空間の任意の点を取る
- [x]連続空間上の重みを、離散的な格子点へ近似的に射影する
- 格子化によってモデルの層数が増える
- 格子点は入力データごとに無限に増える
S: /series/appendix.1#重み空間の「格子化」
A: 量子化は連続的な重みを有限個の代表値へ丸めるため、重み空間を離散的な格子として扱う操作に見なせる。射影先と誤差の大きさが性能に影響する。
```

### Q3. 決定境界への影響

量子化誤差が分類の決定境界付近で問題になりやすい理由はどれか。

```quiz
- [x]小さな摂動でも、境界の近くではクラス判定が反転する可能性があるから
- 決定境界から遠い点ほど必ず誤分類されるから
- 量子化は出力確率に影響しないから
- 境界は量子化によって必ず消えるから
S: /series/appendix.1#決定境界への影響
A: 境界から十分離れた点は小さな誤差に頑健な場合が多いが、境界近傍では同じ誤差が判定を変えうる。量子化の評価では境界付近の挙動も確認する必要がある。
```

### Q4. 多様体仮説との接続

量子化と多様体仮説の関係について、最も慎重な説明はどれか。

```quiz
- [x]量子化は表現の分解能を落とすため、データが集中する構造をどの程度保てるかが問題になる
- 多様体上の表現は量子化できない
- 量子化すると多様体の次元は必ず増える
- 多様体仮説があれば量子化誤差は必ずゼロになる
S: /series/appendix.1#多様体仮説との接続
A: 量子化は連続表現を粗くするため、近傍関係や局所構造が保たれるかが重要になる。多様体という見方は誤差の偏りを考える手がかりだが、性能を保証するものではない。
```

## 手法と誤差を選ぶ

### Q5. PTQとQAT

PTQとQATの違いとして、正しいものはどれか。

```quiz
- PTQは学習中に量子化を意識し、QATは学習後にだけ量子化する
- [x]PTQは学習後に量子化し、QATは量子化を模擬しながら学習する
- 両者は量子化を使わない
- QATは推論時だけ量子化する
S: /series/appendix.1#post-training-quantization-ptq
S: /series/appendix.1#quantization-aware-training-qat
A: PTQは学習済みモデルへ後から量子化を施す。QATは学習中に量子化誤差を意識させ、量子化後の性能低下を補いやすくする。
```

### Q6. 層ごとの感度

量子化ビット幅を層ごとに変える設計の理由はどれか。

```quiz
- すべての層が量子化誤差に同じ感度を持つから
- [x]層によって出力や決定境界への感度が異なるため、重要な層を高精度に保てるから
- ビット幅を変えると量子化が無効になるから
- 層ごとの感度は入力に依存しないから
S: /series/appendix.1#層ごとの感度
A: 量子化誤差の影響は層や入力によって異なる。感度の高い層を高ビットにする混合精度は、容量と性能の折り合いをつける方法になる。
```

### Q7. 活性化とKV cache

LLMの量子化で、重み以外にも量子化対象になりうるものはどれか。

```quiz
- 重みだけで、活性化やKV cacheは対象にならない
- [x]活性化やAttentionのKV cacheも対象になり、推論時のメモリ削減に関係する
- 学習データのラベルだけ
- 参考文献の文字列だけ
S: /series/appendix.1#量子化は「重み」だけでは終わらない-kv-cache-活性
A: LLM推論では重みだけでなく、活性化や蓄積されるKV cacheもメモリを消費する。それらを量子化すると効率は上がるが、誤差の影響も評価が必要になる。
```

### Q8. 量子化の限界

量子化について、最も妥当な結論はどれか。

```quiz
- 低ビット化すれば、どのモデルでも同じ性能を保てる
- [x]冗長性が誤差を吸収する場合がある一方、極端な低ビット化や高感度な領域では性能低下が起こりうる
- 量子化誤差はすべての入力で同じである
- 球面制約のある表現では再正規化は不要である
S: /series/appendix.1#まとめ-量子化の幾何学
A: 量子化が壊れにくい理由には冗長性や過剰パラメータ化が関係する場合がある。しかし、誤差は一様ではなく、ビット幅、層、入力、表現の制約に依存する。
```
