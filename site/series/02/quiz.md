# 第2回 理解度チェック：ノルムの呪い

## 要点をつかむ

### Q1. ノルムの三重の意味

あるベクトルのノルムが、概念の表現強度、予測の確信度、学習中に生じた偶然のスケールのすべてに影響しているとする。この状態を問題視する理由として、最も適切な説明はどれか。

```quiz
- ノルムを固定すれば、確信度を独立に取り出せるから
  R: ノルムを固定するのは混線を避けるための対応の一つであって、混線している現状そのものを問題視する理由の説明にはなっていない。
- 複数の意味が混ざっていても、勾配のノルムを見れば区別できるから
  R: 勾配のノルムを観察しても、意味の強度・確信度・偶然のスケールという三つの要因のどれが変化しているかを切り分ける手段にはならない。
- [x]意味の強度・確信度・偶然のスケールが混在し、どの要因の変化かを判別できないから
  R: 一つの数値に複数の異なる意味が同時に混ざっているため、その数値が変化しても何が原因かを判別できないことが問題の核心である。
- 学習が十分に進めば、複数の意味は自然に一つの尺度へ収束するから
  R: 学習を進めても、意味の強度・確信度・スケーリングノイズという性質の異なる要因が自然に一つの尺度へ収束する根拠はなく、混線は解消されない。
S: /series/02#三重の意味
A: 一つの数値に意味の強度、モデルの確信度、スケーリングノイズが混在すると、ノルムの変化が何を意味するのか判別できない。意味ごとに分離して制御できないことが問題である。
```

### Q2. Word2Vec（単語ベクトル学習手法）のノルム

Word2Vec（単語ベクトル学習手法）の学習後の単語ベクトルでノルムの大きさを解釈するとき、最も慎重な説明はどれか。

```quiz
- 入力側と出力側のベクトルでは、ノルムの傾向は同じになる
  R: どの表現を観察するか（入力側・出力側・その平均）によってノルムの傾向は異なりうるため、両者が同じ傾向になるとは限らない。
- [x]語の有意性や頻度などの影響が混ざり、手法や観察する表現によって傾向が変わりうる
  R: ノルムには有意性（頻度と情報量が絡み合った量）が反映される傾向があるが、手法や学習条件、観察する表現によって傾向が変わるため、単純な解釈はできない。
- ノルムは語の意味の強度を表す
  R: ノルムには意味の強度（解釈A）だけでなく、学習の偏り（解釈B）や情報量（解釈C）などが絡み合っており、強度だけを表すと言い切ることはできない。
- ノルムは訓練データ全体で正規化されているため、頻度の影響は学習前に除去されている
  R: 学習後の単語ベクトルのノルムは訓練データ全体で正規化されているわけではなく、むしろ頻度などの影響を反映した結果としてばらつきが生じる。
S: /series/02#word2vecにおけるノルムの曖昧さ
A: Word2Vecのノルムには、頻度や情報量などが絡む有意性が反映されうる。ただし、手法や学習条件、入力側・出力側など、どの表現を観察するかによって傾向は変わりうる。
```

### Q3. 距離の集中

各成分が独立に標準正規分布に従うランダムベクトル $\mathbf{x}$ を考える。 $r=\|\mathbf{x}\|$ について、次元 $d$ が大きくなると何が起きるか。

```quiz
- 次元が大きくなると、距離は定義できなくなる
  R: 距離 r は各次元でも計算できる量であり、次元が大きくなっても定義できなくなるわけではない。
- 距離の相対的なばらつきが大きくなり、外れ値が増える
  R: rの二乗の変動係数は次元が大きくなるほど0に近づくため、相対的なばらつきはむしろ小さくなる。
- 各点が原点に近づき、$r$ は0に集中する
  R: 距離の期待値は次元が大きくなるほど0ではなく大きくなっていくため、原点に近づくという説明は逆である。
- [x]距離は $\sqrt{d}$ 付近に集中する
  R: 距離の期待値はおおむね $\sqrt{d}$ であり、相対的なばらつきが次元とともに0に近づくため、距離はその値付近に集中する。
S: /series/02#距離の集中-すべてが「同じくらい遠い」
A: $\mathbb{E}[r^2]=d$ で、$r^2$ の変動係数は $\sqrt{2/d}$ となる。したがって相対的なばらつきは0に近づくが、距離そのものはおおむね $\sqrt{d}$ まで大きくなる。
```

### Q4. 直交性の祝福

高次元空間でランダムに選んだ二つのベクトルがほぼ直交することは、なぜ「呪い」ではなく「祝福」にもなりうるのか。

```quiz
- 直交するベクトルは計算コストが低いから
  R: 直交性そのものは計算コストの低さを保証する性質ではなく、なぜ「祝福」になるかの説明としては的外れである。
- [x]ほぼ直交する方向を多数配置できるから
  R: 高次元空間には内積が小さいベクトルを大量に配置できるため、互いに干渉しない表現を多数詰め込む余地が生まれる。

  R: 直交するベクトル同士の内積は0に近く、距離が近いことを意味しない。距離の近さと直交性は別の性質である。

<!-- quiz-lint-ignore: cue - 誤解の核心が「直交性のみで十分」という排他性そのものにあるため -->

A: 高次元空間には、互いに干渉しにくい方向を大量に確保できる。ただし、ランダムな直交性だけでは意味構造は生まれず、データと目的に基づく学習が必要である。
```

### Q5. 距離の集中が成り立つ条件

距離の集中について、最も適切な前提はどれか。

```quiz
- データが低次元多様体上にある
  R: データが低次元多様体上に集中している場合はむしろ集中の程度が緩和されるため、これは前提ではなく緩和する条件である。
- [x]各成分が独立同分布に近いランダムベクトルを考えている
  R: 距離の集中は各成分が独立同分布であるという確率的な仮定のもとで導かれる性質であり、これが成立の前提となる。
- 学習済みの各埋め込みが独立なランダムベクトルである
  R: 学習済みの埋め込みは意味構造や相関を反映しており、独立なランダムベクトルという仮定をそのまま満たすとは限らない。
- ベクトルのノルムを学習可能なパラメータにしている
  R: ノルムを学習可能にするかどうかは距離の集中という統計的性質の成立条件とは無関係である。
S: /series/02#距離の集中-すべてが「同じくらい遠い」
A: 距離の集中は、独立同分布などの確率的な仮定から導かれる。相関の強いデータに、その結論を無条件で適用してはいけない。
```

### Q6. アンビエント次元と内在次元

1000次元空間に埋め込まれているが、データ自体は10次元程度の多様体上に集中している場合、最も適切な説明はどれか。

```quiz
- 内在次元が低いので、アンビエント空間で測ったユークリッド距離は多様体に沿った近さと一致する
  R: アンビエント空間で測った弦距離と多様体に沿った内在的な近さは一般に一致せず、多様体の曲がりや埋め込み方の影響を受ける。
- アンビエント次元が高いので、近傍探索は意味を失う
  R: 座標の数であるアンビエント次元だけでなく、データが実際に変化する自由度である内在次元も考慮する必要があり、アンビエント次元の高さだけで近傍探索の有効性を断定できない。
- 内在次元が低いデータでは、ユークリッド距離が定義できない
  R: ユークリッド距離はアンビエント次元上のベクトルであれば内在次元の高低にかかわらず定義できる量であり、定義できないという説明は誤りである。
- [x]内在次元が低ければ、多様体に沿った近さは意味を保つ可能性がある
  R: アンビエント次元が高くても内在次元が低ければ、多様体上の距離は依然として意味を持ちうるため、近さの概念が保たれる可能性がある。
S: /series/02#ユークリッド距離が情報を失う瞬間
A: 座標の数であるアンビエント次元と、データが実際に変化する自由度である内在次元は区別する必要がある。高いアンビエント次元だけで、距離の有効性を断定してはいけない。
```

### Q7. 学習済み表現への適用

ランダムベクトルの高次元幾何を、学習済みの意味表現へ適用するときの注意として正しいものはどれか。

```quiz

- 意味構造がある表現では、直交性は成立しない
  R: 意味構造を持つ表現でも、関連しない語同士は依然としてほぼ直交に近く配置されうるため、直交性が一律に成立しなくなるわけではない。

  R: 学習済み表現は意味構造や相関を反映しており単純なランダムベクトルとは性質が異なるため、前提を確認せずに同じ公式を適用するのは危険である。
- 学習済み表現では、ノルムと方向を区別する必要がなくなる
  R: 学習済み表現でもノルムには意味の強度や確信度、方向には別の情報が乗りうるため、両者を区別する必要性はなくならない。
S: /series/02#注意事項
A: ランダムベクトルについての距離集中や直交性は、条件付きの幾何学的性質である。学習済み表現には意味構造や相関が入るため、前提を確認してから解釈する必要がある。
```

### Q8. ハブ化と内積

内積 $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ を類似度に使う。方向の類似度が同程度なら、どのベクトルがハブ化しやすいか。

```quiz
- ノルムが0のベクトル。各相手と同じ内積になるから
  R: ノルムが0のベクトルはどの相手との内積も0になり、上位に現れやすくなるハブ化とは逆の振る舞いをする。
- [x]ノルムが大きいベクトル。方向に関わらず内積を押し上げやすいから
  R: 内積はノルムの積と方向の類似度の積で決まるため、ノルムが大きいベクトルは方向の類似度が高くない相手に対しても内積を押し上げ、上位に現れやすくなる。
- コサイン類似度で正規化すれば、ノルムのばらつきに起因するハブ化の影響は除かれる
  R: コサイン類似度はノルムの影響を除くが、高次元ではベクトルの方向自体が特定の方向に集中しやすく、ハブ化はノルムに加えて高次元の幾何にも起因するため、コサイン類似度への切り替えでは緩和されない。
- ノルムが小さいベクトル。相手の方向を細かく区別できるから
  R: ノルムが小さいベクトルは内積を押し上げにくく、むしろハブ化しにくい側であり、方向を細かく区別できることとハブ化のしやすさは別の話である。
S: /series/02#正規化しない時代の問題
A: 内積にはノルムの積が含まれる。ノルムが大きいベクトルは、方向の類似度が高くない相手に対しても内積が大きくなり、検索結果の上位に現れやすくなる。
```

### Q11. ノルムの混線への対応

ノルムが表現強度・確信度・偶然のスケールを同時に表し、解釈しにくくなっているモデルを考える。この混線への、一つの対応方針はどれか。

```quiz
- [x]ノルムを定数に固定し、方向を主な自由度として扱う
  R: ノルムを捨てるのではなく定数に固定して方向と分離すると、混在していた役割のうち少なくとも方向による類似度を独立に扱えるようになる。
- ノルムにさらに多くの意味を持たせ、学習で解決する
  R: 表現強度・確信度・偶然のスケールが混線している原因はノルムに複数の意味を持たせていることそのものであり、さらに意味を追加すれば混線はむしろ悪化する。
- ノルムを大きくすれば、意味構造と確信度を同時に制御できる
  R: ノルムを大きくする操作は一つの数値を動かすだけであり、意味構造と確信度という異なる要因を同時に、かつ個別に制御できるわけではない。
- ノルムをそのまま削除し、方向情報も使わない
  R: ノルムを削除してしまうと方向による類似度を測る土台まで失われるため、混線への対応としては方向情報も使わないという選択は的外れである。
S: /series/02#まとめ-ノルムの呪いと高次元の逆説
A: ノルムを捨てるのではなく、定数に固定して方向と分離する。すると、ノルムに混在していた役割のうち、少なくとも方向による類似度を独立に扱える。
```

### Q13. 角度中心の設計の適用範囲

ノルムに予測の確信度と偶然のスケールが混在しているモデルで、ノルムを固定して方向の類似度を使う設計を考える。この設計についての最も慎重な説明はどれか。

```quiz
  R: 正規化されたデータでも、角度中心の設計が常に優れているとは限らず、有効性はデータやタスクによって左右されるため、この一般化は慎重さを欠く。

  R: ノルムを固定することは方向を主な自由度として扱う手段にはなるが、確信度を適切に扱えるかどうかはタスクや校正の設計に依存し、固定だけで自動的に解決するわけではない。
- [x]有効性はデータ・タスク・正規化に依存する
  R: 角度中心の設計はノルムの意味を制御しやすくする一つの方針だが、角度が常に最適とは限らず、データ、タスク、正規化の有無を確認して使う必要がある。
```

### Q14. LayerNorm（Layer Normalization、層正規化）の位置づけ

学習済み表現を内積で検索すると、特定のベクトルが意味の違いを越えて上位に現れる。最初に行う診断として、最も適切なものはどれか。

```quiz
- LayerNormの有無を見て、検索指標や確信度の校正は調べない
  R: LayerNormの有無だけを確認しても、内積の順位に混ざっているノルムと方向のどちらが原因かは切り分けられず、診断として不十分である。
- [x]ノルムと角度を分けて順位を再計算し、正規化の有無と下流性能を比較する
  R: 内積の順位にはノルムと方向の両方が影響するため、両者を分離して再計算し、正規化の有無と下流性能を比較することでハブ化と意味構造の混線を切り分けられる。
```
