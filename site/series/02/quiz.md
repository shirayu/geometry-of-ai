# 第2回 理解度チェック：ノルムの呪い

## 要点をつかむ

### Q1. ノルムの三重の意味

あるベクトルのノルムが、概念の表現強度、予測の確信度、学習中に生じた偶然のスケールのすべてに影響しているとする。この状態を問題視する理由として、最も適切な説明はどれか。

```quiz
- ノルムを固定すれば、確信度だけを独立に取り出せるから
- 複数の意味が混ざっていても、勾配のノルムを見れば区別できるから
- [x]意味の強度・確信度・偶然のスケールが混在し、どの要因の変化かを判別できないから
- 学習が十分に進めば、複数の意味は自然に一つの尺度へ収束するから
S: /series/02#三重の意味
A: 一つの数値に意味の強度、モデルの確信度、スケーリングノイズが混在すると、ノルムの変化が何を意味するのか判別できない。意味ごとに分離して制御できないことが問題である。
```

### Q2. Word2Vec（単語ベクトル学習手法）のノルム

Word2Vec（単語ベクトル学習手法）の学習後の単語ベクトルでノルムの大きさを解釈するとき、最も慎重な説明はどれか。

```quiz
- 入力側と出力側のベクトルでは、ノルムの傾向は同じになる
- [x]語の有意性や頻度などの影響が混ざり、手法や観察する表現によって傾向が変わりうる
- ノルムは語の意味の強度だけを表す
- ノルムは訓練データ全体で正規化されているため、頻度の影響は学習前に除去されている
S: /series/02#word2vecにおけるノルムの曖昧さ
A: Word2Vecのノルムには、頻度や情報量などが絡む有意性が反映されうる。ただし、手法や学習条件、入力側・出力側など、どの表現を観察するかによって傾向は変わりうる。
```

### Q3. 距離の集中

各成分が独立に標準正規分布に従うランダムベクトル $\mathbf{x}$ を考える。 $r=\|\mathbf{x}\|$ について、次元 $d$ が大きくなると何が起きるか。

```quiz
- 次元が大きくなると、距離は定義できなくなる
- 距離の相対的なばらつきが大きくなり、外れ値が増える
- 各点が原点に近づき、$r$ は0に集中する
- [x]距離は $\sqrt{d}$ 付近に集中する
S: /series/02#距離の集中-すべてが「同じくらい遠い」
A: $\mathbb{E}[r^2]=d$ で、$r^2$ の変動係数は $\sqrt{2/d}$ となる。したがって相対的なばらつきは0に近づくが、距離そのものはおおむね $\sqrt{d}$ まで大きくなる。
```

### Q4. 直交性の祝福

高次元空間でランダムに選んだ二つのベクトルがほぼ直交することは、なぜ「呪い」ではなく「祝福」にもなりうるのか。

```quiz
- 直交するベクトルは計算コストが低いから
- [x]ほぼ直交する方向を多数配置できるから
- 直交すれば距離が近くなるから
- 直交性だけで意味構造が生まれるから
S: /series/02#呪いを祝福に変える
A: 高次元空間には、互いに干渉しにくい方向を大量に確保できる。ただし、ランダムな直交性だけでは意味構造は生まれず、データと目的に基づく学習が必要である。
```

## 条件を見極める

### Q5. 距離の集中が成り立つ条件

距離の集中について、最も適切な前提はどれか。

```quiz
- データが低次元多様体上にある
- [x]各成分が独立同分布に近いランダムベクトルを考えている
- 学習済みの各埋め込みが独立なランダムベクトルである
- ベクトルのノルムを学習可能なパラメータにしている
S: /series/02#距離の集中-すべてが「同じくらい遠い」
A: 距離の集中は、独立同分布などの確率的な仮定から導かれる。相関の強いデータに、その結論を無条件で適用してはいけない。
```

### Q6. アンビエント次元と内在次元

1000次元空間に埋め込まれているが、データ自体は10次元程度の多様体上に集中している場合、最も適切な説明はどれか。

```quiz
- どのデータでも距離の集中はそのままなくなる
- アンビエント次元が高いので、近傍探索は意味を失う
- 内在次元が低いデータでは、ユークリッド距離が定義できない
- [x]内在次元が低ければ、多様体に沿った近さは意味を保つ可能性がある
S: /series/02#ユークリッド距離が情報を失う瞬間
A: 座標の数であるアンビエント次元と、データが実際に変化する自由度である内在次元は区別する必要がある。高いアンビエント次元だけで、距離の有効性を断定してはいけない。
```

### Q7. 学習済み表現への適用

ランダムベクトルの高次元幾何を、学習済みの意味表現へ適用するときの注意として正しいものはどれか。

```quiz
- [x]学習済み表現の相関を確認し、ランダム性質をそのまま適用しない
- 意味構造がある表現では、直交性は成立しない
- 学習済み表現はランダムなので、同じ公式を前提を確認せずに適用できる
- 学習済み表現では、ノルムと方向を区別する必要がなくなる
S: /series/02#注意事項
A: ランダムベクトルについての距離集中や直交性は、条件付きの幾何学的性質である。学習済み表現には意味構造や相関が入るため、前提を確認してから解釈する必要がある。
```

## 仕組みを考える

### Q8. ハブ化と内積

内積 $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ を類似度に使う。方向の類似度が同程度なら、どのベクトルがハブ化しやすいか。

```quiz
- ノルムが0のベクトル。各相手と同じ内積になるから
- [x]ノルムが大きいベクトル。方向に関わらず内積を押し上げやすいから
- 内積は方向だけで決まるので、ノルムの大きさは順位に影響しない
- ノルムが小さいベクトル。相手の方向を細かく区別できるから
S: /series/02#正規化しない時代の問題
A: 内積にはノルムの積が含まれる。ノルムが大きいベクトルは、方向の類似度が高くない相手に対しても内積が大きくなり、検索結果の上位に現れやすくなる。
```

### Q9. スケールと確信度

ロジットを $\mathbf{z}\mapsto\alpha\mathbf{z}$ （ $\alpha>1$ ） と変換したとき、Softmaxの出力について正しい説明はどれか。

```quiz
- [x]分布がより尖るが、情報が増えたとは限らない
<!-- quiz-lint-ignore: hedge - 「尖るが情報増加は別問題」という2段構えの主張が正確さの核で、誤答2が既に同型の裏返し構文になっている -->
- ロジットのスケールはSoftmaxの出力に影響しない
- クラス間の相対的な差が消え、一様分布になる
- 各クラスの確率が同じ割合で増える
S: /series/02#確信度とノルムの混同
A: ロジットを拡大すると、最大値付近に確率が集中する。出力が確信ありげに見えても、それが新しい情報や正しい不確実性を意味するとは限らない。
```

### Q10. 直交性と意味構造

高次元空間でランダムベクトルがほぼ直交するという事実だけから、意味のある埋め込み空間が得られるか。

```quiz
- 得られる。ノルムを大きくすれば意味構造が生まれるから
- 得られる。直交性が意味の近さを表すから
- [x]得られない。意味構造は学習で獲得する
- 得られない。高次元ではベクトルを配置できないから
S: /series/02#大規模言語モデルへの示唆
A: 直交性は、表現を干渉させずに配置できる空間的余地を与える。しかし、どの方向が意味的に近いかは、データと目的に基づく学習で獲得される。
```

## 設計につなぐ

### Q11. ノルムの混線への対応

ノルムが表現強度・確信度・偶然のスケールを同時に表し、解釈しにくくなっているモデルを考える。この混線への、一つの対応方針はどれか。

```quiz
- [x]ノルムを定数に固定し、方向を主な自由度として扱う
- ノルムにさらに多くの意味を持たせ、学習だけで解決する
- ノルムだけを大きくすれば、意味構造と確信度を同時に制御できる
- ノルムをそのまま削除し、方向情報も使わない
S: /series/02#まとめ-ノルムの呪いと高次元の逆説
A: ノルムを捨てるのではなく、定数に固定して方向と分離する。すると、ノルムに混在していた役割のうち、少なくとも方向による類似度を独立に扱える。
```

### Q12. カプセルネットワークの位置づけ

ある表現方式が、ベクトルの方向を物体の姿勢、長さを物体の存在確率として扱う設計を採用しているとする。この方式への評価として、最も適切なものはどれか。

```quiz
- [x]向きと長さを分けた問題提起には意義があるが、計算コストと拡張性に課題が残る
- ノルムを使わない設計だったため、表現を学習できなかった
- 向きと長さを分離したため、理論的に誤りであることが示された
- 現在のTransformerをそのまま置き換える方式として定着した
S: /series/02#カプセルネットワークの評価
A: 向きと長さを明示的に分ける問題意識には意義がある。一方、計算コスト、スケーラビリティ、大規模ベンチマークでの性能は別途評価する必要があり、設計意図だけで実用性は保証されない。
```

ノルムに予測の確信度と偶然のスケールが混在しているモデルで、ノルムを固定して方向の類似度を使う設計を考える。この設計についての最も慎重な説明はどれか。

### Q14. LayerNorm（Layer Normalization、層正規化）の位置づけ

学習済み表現を内積で検索すると、特定のベクトルが意味の違いを越えて上位に現れる。最初に行う診断として、最も適切なものはどれか。

```quiz
- LayerNormの有無だけを見て、検索指標や確信度の校正は調べない
- [x]ノルムと角度を分けて順位を再計算し、正規化の有無と下流性能を比較する
- 検索上位のベクトルのノルムをさらに大きくして差を強調する
- ベクトルをゼロにして、内積の偏りを消す
S: /series/02#正規化しない時代の問題
A: 内積の順位にはノルムと方向の両方が影響する。両者を分離して検索性能と確信度を比較すると、ハブ化と意味構造の混線を切り分けやすい。
```
