# 第14回 理解度チェック：トポロジーという顕微鏡

## 形ではなくつながりを見る

### Q1. 幾何学とトポロジー

幾何学とトポロジーの違いを表す説明として、適切なものはどれか。

```quiz
- トポロジーは座標の数値だけを扱う
- 幾何学は形を扱わず、トポロジーだけが距離を扱う
- [x]幾何学は距離や角度などの量を、トポロジーは連結性や穴などの変形に不変な構造を主に扱う
- 両者は完全に同じ物差しである
S: /series/14#何を測るか
A: 幾何学は長さや曲率などの量を測り、トポロジーは連続変形で保たれるつながりや穴を捉える。表現空間を見る補完的な視点である。
```

### Q2. ベッチ数

ベッチ数が数える対象として、正しいものはどれか。

```quiz
- データ点のノルムの平均
- 曲率の最大値だけ
- 学習層の数
- [x]各次元にある独立な穴やループなど、トポロジー構造の数
S: /series/14#ベッチ数-穴を数える
A: ベッチ数は連結成分、ループ、空洞などの穴の数を次元ごとに表す。具体的に何を意味するかは、対象とホモロジーの次元に依存する。
```

### Q3. フィルトレーション

パーシステントホモロジーにおけるフィルトレーションとは何か。

```quiz
- [x]距離や半径などのスケールを変えながら、形の構造が現れたり消えたりする過程を追うこと
- データを一度だけ固定した順序に並べること
- すべての穴を最初から除去すること
- 学習率を時間ごとに変えること
S: /series/14#フィルトレーション-スケールの掃引
A: フィルトレーションはスケールを段階的に変える構成である。小さいスケールの局所構造から大きいスケールの全体構造まで、穴の生死を追跡できる。
```

### Q4. パーシステンス図

パーシステンス図の一点が表すものはどれか。

```quiz
- 二つのデータ点のユークリッド座標
- [x]あるトポロジー構造が生まれたスケールと消えたスケール
- 学習モデルの重みとバイアス
- クラス確率と温度
S: /series/14#パーシステンス図-穴の「寿命」を可視化する
A: パーシステンス図では、構造の誕生と消滅を座標に取る。対角線から遠い点ほど広いスケールで長く残る構造として解釈されやすい。
```

## 表現を解析する

### Q5. ノイズと持続性

パーシステントホモロジーでノイズと構造を区別する手がかりはどれか。

```quiz
- すべての穴を同じ重要度とみなす
- 小さい穴だけを必ず真の構造とみなす
- [x]短いスケールで現れてすぐ消える特徴より、広いスケールで長く残る特徴を重視する
- スケールを変えずに一枚の図だけを見る
S: /series/14#パーシステンス図-穴の「寿命」を可視化する
A: 持続時間は構造の頑健さを考える一つの手がかりになる。ただし、どの構造がタスクに意味を持つかはデータと目的に依存する。
```

### Q6. 表現空間への応用

表現空間にTDAを適用する目的として、適切なものはどれか。

```quiz
- 表現の正しさをトポロジーだけで保証する
- すべての表現を低次元へ射影する
- 損失関数を必ずゼロにする
- [x]点間距離だけでは見えにくい連結性やループなどの構造を調べる
S: /series/14#表現空間のトポロジー
A: TDAは表現のつながりや穴を解析する追加のレンズになる。幾何学的な距離や分類精度を置き換えるのではなく、別の構造情報を補う。
```

### Q7. TDAの限界

深層学習にTDAを使うときの注意として、正しいものはどれか。

```quiz
- [x]計算コストや特徴の意味づけに課題があり、トポロジー量だけで設計や性能を決められるわけではない
- TDAはすべての構造を自動的に意味づける
- パーシステンス図はノイズの影響を必ず受けない
- トポロジー解析は表現空間に適用できない
S: /series/14#tdaの現在地
A: TDAは有用な構造情報を与えるが、どの穴がタスクに重要か、損失へどう組み込むか、計算量をどう扱うかは別途検討が必要である。
```

### Q8. 本回のメッセージ

第14回の主張を最もよく表すものはどれか。

```quiz
- 距離や曲率はすべて不要になる
- [x]表現空間を理解するには、形や距離だけでなく、スケールを超えて残るつながりも調べるべきである
- トポロジーを使えば予測の真偽を直接判定できる
- 穴が多い表現ほど必ず優れている
S: /series/14#本回のメッセージ
A: トポロジーは「どれだけ」ではなく「どのようにつながっているか」を見る。幾何学と補完的に使うことで、表現の別の構造を問い直せる。
```
