# 第14回 理解度チェック：トポロジーという顕微鏡

## 形ではなくつながりを見る

### Q1. 幾何学とトポロジー

幾何学とトポロジーの違いを表す説明として、適切なものはどれか。

```quiz
- トポロジーは座標の数値そのものを扱う
  R: トポロジーが測るのは連結性やループなどのつながり方であり、座標の数値そのものではなく連続変形で保たれる性質を対象とする。
- [x]幾何学は距離・角度、トポロジーは連結性・穴を主に扱う
  R: 幾何学は距離・角度・曲率という定量的な量を測り、トポロジーは連結成分やループといったつながりの性質を定性的に捉える、補完的な二つのレンズである。
- 幾何学は形を扱わず、トポロジーが距離や連結性を扱う
  R: 距離や角度を測るのは幾何学の役割であり、トポロジーはむしろ距離を手放す代わりに連続変形で保たれるつながりを捉える視点であるため、役割が入れ替わっている。
- 両者はそのまま同じ物差しである
  R: コーヒーカップとドーナツは幾何学的には異なる数値を返すがトポロジー的には同一視されるように、両者は異なる問いに答える別の物差しである。
S: /series/14#何を測るか
A: 幾何学は長さや曲率などの量を測り、トポロジーは連続変形で保たれるつながりや穴を捉える。表現空間を見る補完的な視点である。
```

### Q2. ベッチ数

ベッチ数が数える対象として、正しいものはどれか。

```quiz
- 学習層の数
  R: ベッチ数はネットワークのアーキテクチャに関する量ではなく、対象となる空間そのものが持つ連結成分やループなどの穴を数える不変量である。
- [x]各次元の穴の数
  R: ベッチ数は連結成分の数、ループの数、空洞の数というように、次元ごとに異なる種類の穴を数える。
- 曲率の最大値
  R: 曲率は距離や角度を測る幾何学の量であり、ベッチ数が対象とするつながりの構造とは異なる不変量である。
- データ点のノルムの平均
  R: データ点のノルムの平均は個々の点の大きさに関する統計量であり、点群全体の連結性やループの構造を数えるベッチ数とは無関係である。
S: /series/14#ベッチ数-穴を数える
A: ベッチ数は連結成分、ループ、空洞などの穴の数を次元ごとに表す。具体的に何を意味するかは、対象とホモロジーの次元に依存する。
```

### Q3. フィルトレーション

パーシステントホモロジーにおけるフィルトレーションとは何か。

```quiz
- [x]スケールごとの構造の変化を追う
  R: フィルトレーションはスケールを表すパラメータを0から動かしながら単体複体の列を構成し、その過程で穴が生まれては塞がる様子を追跡する構成である。
- 各穴を最初から除去すること
  R: フィルトレーションは穴を除去する操作ではなく、スケールを動かしながら穴の誕生と消滅をそのまま記録していく構成である。
- データを固定した一つの順序に並べ、スケールも一つに固定すること
  R: フィルトレーションは一つの順序とスケールに固定するのではなく、スケールを連続的に変化させながら単体複体が段階的に成長していく列を作る手続きである。
- 学習率を時間ごとに変えること
  R: 学習率のスケジューリングは最適化の話であり、点群からスケールごとの単体複体を構成するフィルトレーションとは別の概念である。
S: /series/14#フィルトレーション-スケールの掃引
A: フィルトレーションはスケールを段階的に変える構成である。小さいスケールの局所構造から大きいスケールの全体構造まで、穴の生死を追跡できる。
```

### Q4. パーシステンス図

パーシステンス図の一点が表すものはどれか。

```quiz
- 一点が一つのデータ点に対応し、その座標を持つ
  R: パーシステンス図の点はデータ点そのものの座標ではなく、フィルトレーションの過程で現れる一つの穴の誕生と死亡のスケールを座標として持つ。
- 対角線付近に集中する点が、最も頑健な構造を表す
  R: 対角線上の点は誕生と同時に死亡する寿命の短い構造であり、頑健な構造を表すのはむしろ対角線から遠い点である。
- 全データを合わせた連結成分の総数を表す
  R: 連結成分の総数のような集計値ではなく、パーシステンス図の各点は個々の穴が持つ誕生時刻と死亡時刻の組を表している。
- [x]構造の誕生と消滅のスケール
  R: パーシステンス図の各点は、フィルトレーションの過程である穴が現れるスケール（誕生）と消えるスケール（死亡）を座標として記録したものである。
S: /series/14#パーシステンス図-穴の「寿命」を可視化する
A: パーシステンス図では、構造の誕生と消滅を座標に取る。対角線から遠い点ほど広いスケールで長く残る構造として解釈されやすい。
```

## 表現を解析する

### Q5. ノイズと持続性

パーシステントホモロジーでノイズと構造を区別する手がかりはどれか。

```quiz
- 各穴を同じ重要度とみなす
  R: すべての穴を同列に扱うと、対角線付近の寿命が短い穴と長く残る穴の違いが失われ、ノイズと構造を区別する手がかりを捨てることになる。
- [x]長く残る特徴を構造の手がかりにする
  R: 広いスケール範囲にわたって存在し続ける長寿命の特徴は、局所的な揺らぎであるノイズよりも本質的な構造を反映していると考えられる手がかりになる。
- 小さい穴（寿命の短い穴）を真の構造とみなす
  R: 小さい穴、すなわち寿命の短い穴はむしろ対角線に近くノイズである可能性が高く、構造の手がかりとして重視すべき対象ではない。
- スケールを変えずに単一の図で構造を判断する
  R: パーシステントホモロジーの利点はスケールを連続的に動かして穴の生死を追跡できる点にあり、単一の図で判断することはその利点を放棄することになる。
S: /series/14#パーシステンス図-穴の「寿命」を可視化する
A: 持続時間は構造の頑健さを考える一つの手がかりになる。ただし、どの構造がタスクに意味を持つかはデータと目的に依存する。
```

### Q6. 表現空間へのTDA（Topological Data Analysis、トポロジカルデータ解析）の応用

表現空間にTDA（Topological Data Analysis、トポロジカルデータ解析）を適用する目的として、適切なものはどれか。

```quiz
- [x]連結性やループを距離と別に調べる
  R: TDAは表現のクラスタリングの質や学習過程の変化を、距離に基づく幾何分析とは別の角度である連結性やループの構造から捉える追加のレンズとして使われる。
- 各表現を低次元へ射影する
  R: 低次元への射影は次元削減の手法であり、TDAが行う連結成分やループといったトポロジー的構造の解析とは異なる操作である。
- トポロジーの解析結果で表現の設計を直接最適化する
  R: TDAは連結性やループを記述する診断ツールであり、その解析結果を損失関数の代わりに使って表現を直接最適化する手法ではない。
- 表現の正しさをトポロジーで実現する
  R: トポロジーは連結性やループといった構造を測る視点であり、幾何学的な距離や分類精度を置き換えて表現の正しさそのものを保証するものではない。
S: /series/14#表現空間のトポロジー
A: TDAは表現のつながりや穴を解析する追加のレンズになる。幾何学的な距離や分類精度を置き換えるのではなく、別の構造情報を補う。
```

### Q7. TDAの限界

深層学習にTDAを使うときの注意として、正しいものはどれか。

```quiz
- 表現空間の連結性やループを調べれば、距離に基づく幾何分析は不要になる
  R: TDAは幾何学的な距離や分類精度を置き換えるものではなく、別の構造情報を補う追加のレンズであるため、幾何分析が不要になるわけではない。
- [x]コストと意味づけがあり、単独では決められない
  R: どの穴がタスクに重要か、損失へどう組み込むか、計算量をどう扱うかはTDAの出力だけでは決められず、別途の検討とコストの見積もりが必要である。
- パーシステンス図では対角線に近い点ほどノイズではなく頑健な構造を表す
  R: 対角線に近い点は誕生後すぐに死亡する寿命の短い構造であり、頑健な構造を表すのは対角線から遠い点である。
- 持続時間が長い構造ほど、タスクにとって重要な意味を持つ
  R: 長い持続時間は構造が頑健であることの手がかりにはなるが、その構造がタスクの性能にとって重要かどうかは別途の検証が必要であり、自動的には結びつかない。
S: /series/14#tdaの現在地
A: TDAは有用な構造情報を与えるが、どの穴がタスクに重要か、損失へどう組み込むか、計算量をどう扱うかは別途検討が必要である。
```

### Q8. トポロジーを使う意義

表現空間に長く残るループが見つかったが、その表現を使うタスクの性能は改善していない。この結果の読み方として、最も適切なものはどれか。

```quiz
- ループを増やす正則化を加え、性能の変化は後から確認する
  R: 性能への影響を確認する前にループを増やす正則化を先に加えてしまうと、頑健な構造であることとタスクへの有用性を混同したまま設計を進めることになる。
- [x]持続性を手がかりに、タスク指標や幾何分析と意味を検証する
  R: 長い持続性は頑健な構造の手がかりにすぎず、それがタスクにとって有用かどうかはタスク指標や距離に基づく幾何分析と突き合わせて別途検証する必要がある。
- 長い持続性は頑健な構造の手がかりだが、タスクへの有用性も同時に表すので別途の検証は不要である
  R: 長い持続性が示すのは構造の頑健さであり、タスク上の有用性を自動的に意味するわけではないため、別途の検証を省略してよい根拠にはならない。
- トポロジー量を損失へ直接入れれば、ループの意味づけは不要になる
  R: トポロジー量を損失に組み込む手法は計算上の課題を含む発展途上の段階にあり、それによってループが持つ意味の検証が不要になるわけではない。
S: /series/14#本回のメッセージ
A: 長い持続性は頑健な構造の手がかりだが、タスク上の有用性を意味しない。トポロジー量を距離や性能と併せて解釈する必要がある。
```
