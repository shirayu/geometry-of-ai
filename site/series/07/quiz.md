# 第7回 理解度チェック：点から分布へ

## 点から分布へ

### Q1. 分布表現への移行

点表現から分布表現へ移る主な理由はどれか。

```quiz
- 各入力を同じ確率分布にするから
  R: 分布表現の目的は入力ごとに異なる確信度や広がりを表すことであり、すべてを同じ分布にしてしまっては個々の入力の違いを表現できなくなる。
- 分布表現では距離や方向を使えなくなるから
  R: 分布表現は方向（平均方向 $\boldsymbol{\mu}$）を意味として保持したまま、広がり（集中度）という次元を新たに加えるものであり、方向や距離という道具を失うわけではない。
- [x]位置と広がりを分け、不確実性も表現するため
  R: 点表現は代表的な位置しか持たず曖昧さを表せないのに対し、分布表現は方向で意味を、広がりで確信度を分けて表すことで不確実性を扱えるようにする。
- 点表現でもノルムが不確実性を表すため、分布表現に置き換える必要はないから
  R: 従来の点埋め込みは不確実性を表現する次元を持たず、ノルムは頻度や学習の進行度など不確実性以外の意味を担ってきた。確信度を扱うには設計段階で分布表現を採用する必要がある。
S: /series/07#ノルムの分離という思想
A: 点表現は代表的な位置を表すが、曖昧さやばらつきを直接持たない。分布表現では位置と広がりを分け、意味と確信度を別の形で扱える。
```

### Q2. VAE（Variational Autoencoder、変分オートエンコーダ）の限界

VAE（Variational Autoencoder、変分オートエンコーダ）のユークリッド空間潜在表現について、適切な説明はどれか。

```quiz
- ガウス分布は球面上の分布より表現力が高い
  R: ガウス分布は半径方向にも自由度を持つため、意味が方向で決まる潜在構造に対しては、必要のない自由度に典型帯という制約をかけてしまい、球面上の分布より有利とは言えない。
- VAEでは潜在変数を学習できない
  R: VAEはまさに潜在変数を確率分布として学習する枠組みであり、潜在変数を学習できないという説明は前提そのものと矛盾する。
- [x]単純なガウスでは方向や曲率を表しにくい場合がある
  R: 高次元のガウス分布では確率質量が原点から離れた薄い殻に集中し、意味が方向で決まる構造や球面上の曲率を素直に表しにくい場合がある。
<!-- quiz-lint-ignore: hedge - 「常に表せない」ではなく「表しにくい場合がある」が技術的に正確な主張で、断定化すると誤りになる -->
- ガウス分布は等方的なので、潜在空間のどの方向でも不確実性を均等に表せる
  R: ガウス分布が等方的であっても、高次元では確率質量が原点でも遠方でもなく特定の半径の殻に集中する不均一性が生じるため、空間全体を均等に使えるわけではない。
S: /series/07#ユークリッド空間の不均一性
A: VAEは確率的な潜在表現を導入するが、ユークリッド空間上の単純なガウス仮定では、方向性や球面上の構造を表しにくい場合がある。
```

### Q3. von Mises–Fisher（vMF）分布のパラメータ

球面上のvon Mises–Fisher（vMF）分布が持つ二つの中心的なパラメータはどれか。

```quiz
- [x]平均方向 $\boldsymbol{\mu}$ と $\kappa$
  R: vMF分布は球面上の平均方向で意味の位置を、集中度でその位置への確信の強さを表す設計であり、この二つが分布を特徴づける中心的なパラメータである。
<!-- quiz-lint-ignore: length - 数式記号2つを含む固有の定義文であり、短い誤答3つとの字数差は内容の必然 -->
- 平均方向とユークリッド空間の分散で定める
  R: vMF分布は球面上の方向分布であり、ユークリッド空間の分散は球面上の広がり（集中度 $\kappa$）とは異なる概念である。
- クラス数とバッチサイズを分布の中心にする
  R: クラス数やバッチサイズは学習設定に関する量であり、分布そのものの中心（平均方向）や集中度を表すパラメータではない。
- 平均ベクトルと共分散行列で定める
  R: 平均ベクトルと共分散行列はガウス分布のパラメータであり、vMF分布の平均方向 $\boldsymbol{\mu}$ と集中度 $\kappa$ とは異なる概念である。
S: /series/07#vmf分布とは何か
A: vMF分布は球面上の平均方向 $\boldsymbol{\mu}$ と、そこへの集中の強さを表す $\kappa$ で特徴づけられる。位置と確信度を分ける設計に対応する。
```

### Q4. エントロピーと不確実性

分布のエントロピーを不確実性の指標として読むとき、一般に正しい説明はどれか。

```quiz
- エントロピーが大きいほど、予測が正しい
  R: エントロピーは分布の広がりという不確実性の指標であり、予測が正しいかどうかという別の評価軸とは同じ概念ではない。
- [x]分布が広いほどエントロピーが大きく、不確実性も高い
  R: エントロピーは確率が複数の可能性に分散するほど大きくなる量であり、分布が広がっているほど不確実性が高いことを反映する。
- エントロピーは確率の最大値と同じである
  R: エントロピーは分布全体の広がりを平均として捉える量であり、確率の最大値という一点の情報だけで決まるものではない。
- 一点に集中した分布ほどエントロピーが大きい
  R: 一点に集中した分布は確率が狭い領域に集約される極限であり、エントロピーはむしろ最小に近づく。
S: /series/07#エントロピーとしての不確実性
A: エントロピーは分布の広がりを測る量で、確率が複数の可能性へ分散すると大きくなる。ただし、不確実性と正しさは同じ概念ではない。
```

## 不確実性を使う

### Q5. OOD（Out-of-Distribution、分布外）検知

球面上の表現で、OOD（Out-of-Distribution、分布外）データの検出が難しくなる理由として適切なのはどれか。

```quiz
- 分布表現は未知データを正しく分類するから
  R: 分布表現を使ってもモデルが未知データを常に正しく分類できるわけではなく、この説明はOOD検出が難しくなる理由とは逆の内容になっている。
- 球面上では距離が定義できないから
  R: 球面上でも方向間の角度や内積に基づく距離は定義できるため、距離が定義できないことがOOD検出の困難さの理由ではない。
- [x]未知入力が既知方向の近くに見える場合がある
  R: 点埋め込みは方向という一つの軸しか持たず、未知の入力でも最も近い既知方向に強制的に対応づけられてしまう場合があるため、見分けが難しくなる。
<!-- quiz-lint-ignore: hedge - 「常に近くに見える」ではなく「場合がある」が技術的に正確な主張で、断定化すると誤りになる -->
- OODデータは原点に移るから
  R: 単位球面上の点はノルムが1に固定されているため、OODデータだからといって原点に移動するわけではない。
S: /series/07#問題-ドーム上の「盲点」
A: 点の方向だけを見ると、既知クラスの近くに見える未知入力を高い確信度で受け入れることがある。分布の広がりや確信度を使うことで、盲点を検出しやすくする。
```

### Q6. ハルシネーションと確信度

ハルシネーションへの幾何学的な対策として、最も適切な方針はどれか。

```quiz
- 各入力を既知クラスへ近づける
  R: 各入力を既知クラスへ近づける操作は、確信度が低い入力にまで無理に断定的な出力を割り当てることになり、ハルシネーションを助長しかねない。
- [x]位置だけでなく広がりと確信度を扱う
  R: ハルシネーションは確信度の情報がないまま出力を確定させてしまうことに起因するため、位置に加えて広がりや確信度を扱うことが幾何学的な対策になる。
- 不確実性を消去して、最大確率の答えを返す
  R: 不確実性を消去して最大確率の答えを常に返す方針は、確信度が低い場合にも断定的な出力を強いることになり、ハルシネーションの原因となる構造をむしろ温存する。
- 出力のノルムを大きくして断定的にする
  R: 出力を断定的にすること自体は確信度の低さという実情を反映しないため、ハルシネーションへの対策にはならない。
S: /series/07#ハルシネーションとは何か
A: ハルシネーションは、モデルが不確かな入力に対してももっともらしい出力を生成する問題として読める。不確実性を表現し、確信度の低い領域を検出することが対策の一つになる。
```

### Q7. 座標フリーの比較

分布表現を座標系に強く依存せず比較する考え方として、適切なものはどれか。

```quiz
- 座標変換を行うと確率分布は比較できなくなる
  R: 座標に依存しにくい量を使えば座標変換の影響を受けにくくなるのであり、座標変換によって比較そのものが不可能になるわけではない。
- 各分布を同じ一点へ移動する
  R: 各分布を同じ一点へ移動してしまうと、集中度のような比較したい情報自体が失われてしまい、座標フリーな比較の実現にはならない。
- [x]分布間の関係や集中度など、座標に依存しにくい量を使う
  R: 集中度のような回転不変統計量は座標系に依存しないため、座標を揃える整列を行わずに異なる表現空間の分布を比較できる。
- 座標軸を固定し、各成分をそのまま比較する
  R: 座標軸を固定して成分をそのまま比較する方法は座標系の不一致に弱く、異なるモデルや空間の間では従来の整列と同様の問題を抱える。
S: /series/07#kappa-による座標フリーの比較
A: 表現の座標系が変わっても意味を保つ比較量を選ぶと、単純な座標合わせへの依存を減らせる。分布間の距離や集中度などを目的に応じて検討する。
```

### Q8. 分布埋め込みの課題

未知データに対して分類精度は保たれているが、予測分布が極端に尖っている。このとき追加で確認すべき設計はどれか。

```quiz
- 表現の位置を可視化し、分布の広がりは評価対象から外す
  R: 予測分布が極端に尖っているという兆候は広がり（集中度）に関する情報であり、それを評価対象から外してしまうと問題の所在を確認できない。
- 分布の形は変えず、分類精度を再測定する
  R: 分類精度は正しい分類の評価であり、校正された不確実性とは別の評価軸であるため、精度だけを再測定しても集中度の偏りは確認できない。
- [x]集中度の安定性・校正と、OOD指標を比較する
  R: 分類精度と校正された不確実性は別の評価であるため、集中度の安定性や校正、OOD指標を確認することで、極端な尖りの原因を切り分けられる。
- 集中度を上げて、未知データへの確信をさらに強める
  R: 予測分布がすでに極端に尖っている状況で集中度をさらに上げることは、確信度の崩壊という課題を悪化させる方向であり、診断や対策にはならない。
S: /series/07#学習の課題
A: 正しい分類と校正された不確実性は別の評価である。集中度、損失、数値安定性を確認し、未知検知など目的に合う指標で分布の広がりを評価する。
```
