# 第7回 理解度チェック：不確実性の復権

## 点から分布へ

### Q1. 分布表現への移行

点表現から分布表現へ移る主な理由はどれか。

```quiz
- 各入力を同じ確率分布にするから
- 分布表現では距離や方向を使えなくなるから
- [x]一つの代表ベクトルだけでなく、意味の広がりや確信度、不確実性を表したいから
- 分布表現なら学習データが不要になるから
S: /series/07#ノルムの分離という思想
A: 点表現は代表的な位置を表すが、曖昧さやばらつきを直接持たない。分布表現では位置と広がりを分け、意味と確信度を別の形で扱える。
```

### Q2. VAE（Variational Autoencoder、変分オートエンコーダ）の限界

VAE（Variational Autoencoder、変分オートエンコーダ）のユークリッド空間潜在表現について、適切な説明はどれか。

```quiz
- ガウス分布は球面上の分布より表現力が高い
- VAEでは潜在変数を学習できない
- [x]単純なガウス潜在分布では、方向や曲率を持つ表現の構造や不確実性を十分に表せない場合がある
- ガウス分布は等方的なので、潜在空間のどの方向でも不確実性を均等に表せる
S: /series/07#ユークリッド空間の不均一性
A: VAEは確率的な潜在表現を導入するが、ユークリッド空間上の単純なガウス仮定では、方向性や球面上の構造を表しにくい場合がある。
```

### Q3. von Mises–Fisher（vMF）分布のパラメータ

球面上のvon Mises–Fisher（vMF）分布が持つ二つの中心的なパラメータはどれか。

```quiz
- [x]平均方向 $\boldsymbol{\mu}$ と集中度 $\kappa$
- 平均距離とユークリッド曲率
- クラス数とバッチサイズ
- 温度と学習率だけ
S: /series/07#vmf分布とは何か
A: vMF分布は球面上の平均方向 $\boldsymbol{\mu}$ と、そこへの集中の強さを表す $\kappa$ で特徴づけられる。位置と確信度を分ける設計に対応する。
```

### Q4. エントロピーと不確実性

分布のエントロピーを不確実性の指標として読むとき、一般に正しい説明はどれか。

```quiz
- エントロピーが大きいほど、予測が正しい
- [x]確率が広く分散した分布ほどエントロピーが大きく、予測の不確実性が高いと解釈できる
- エントロピーは確率の最大値と同じである
- 一点に集中した分布ほどエントロピーが大きい
S: /series/07#エントロピーとしての不確実性
A: エントロピーは分布の広がりを測る量で、確率が複数の可能性へ分散すると大きくなる。ただし、不確実性と正しさは同じ概念ではない。
```

## 不確実性を使う

### Q5. OOD（Out-of-Distribution、分布外）検知

球面上の表現で、OOD（Out-of-Distribution、分布外）データの検出が難しくなる理由として適切なのはどれか。

```quiz
- 分布表現は未知データを正しく分類するから
- 球面上では距離が定義できないから
- [x]球面上のどの方向にも表現を置けるため、未知の入力が既知クラスの方向の近くに見える盲点が生じうる
- OODデータは原点に移るから
S: /series/07#分布表現による解決策
A: 点の方向だけを見ると、既知クラスの近くに見える未知入力を高い確信度で受け入れることがある。分布の広がりや確信度を使うことで、盲点を検出しやすくする。
```

### Q6. ハルシネーションと確信度

ハルシネーションへの幾何学的な対策として、最も適切な方針はどれか。

```quiz
- 各入力を既知クラスへ近づける
- [x]表現の位置だけでなく分布の広がりや確信度を扱い、未知や曖昧な入力を区別する
- 不確実性を消去して、最大確率の答えを返す
- 出力のノルムを大きくして断定的にする
S: /series/07#ハルシネーションとは何か
A: ハルシネーションは、モデルが不確かな入力に対してももっともらしい出力を生成する問題として読める。不確実性を表現し、確信度の低い領域を検出することが対策の一つになる。
```

### Q7. 座標フリーの比較

分布表現を座標系に強く依存せず比較する考え方として、適切なものはどれか。

```quiz
- 座標変換を行うと確率分布は比較できなくなる
- 各分布を同じ一点へ移動する
- [x]分布間の関係や集中度など、座標の取り方に依存しにくい量を使って比較する
- 座標軸を固定し、各成分をそのまま比較する
S: /series/07#座標フリーの分布比較
A: 表現の座標系が変わっても意味を保つ比較量を選ぶと、単純な座標合わせへの依存を減らせる。分布間の距離や集中度などを目的に応じて検討する。
```

### Q8. 分布埋め込みの課題

未知データに対して分類精度は保たれているが、予測分布が極端に尖っている。このとき追加で確認すべき設計はどれか。

```quiz
- 表現の位置だけを可視化し、分布の広がりは評価対象から外す
- 分布の形は変えず、分類精度だけを再測定する
- [x]集中度の数値安定性と校正を調べ、OOD検知や下流タスクで不確実性の指標を比較する
- 集中度を上げて、未知データへの確信をさらに強める
S: /series/07#学習の課題
A: 正しい分類と校正された不確実性は別の評価である。集中度、損失、数値安定性を確認し、未知検知など目的に合う指標で分布の広がりを評価する。
```
