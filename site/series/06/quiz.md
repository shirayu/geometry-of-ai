# 第6回 理解度チェック：Transformerという測量士

## 動的な空間

### Q1. Transformerの構成

Transformerを構成する要素の組み合わせとして、適切なものはどれか。

```quiz
- 畳み込みだけで系列の位置関係を表す
- 入力を一度だけ固定特徴へ射影し、相互作用を計算しない
- [x]Attention、位置情報、Feed-Forward層、残差接続、正規化などを組み合わせる
- すべてのトークンを独立に分類する
S: /series/06#構成要素
A: TransformerはAttentionによるトークン間の相互作用に、位置情報、非線形変換、残差接続、正規化を組み合わせる。単一の部品だけで動くモデルではない。
```

### Q2. カーネル法との違い

カーネル法とAttentionの違いとして、最も適切な説明はどれか。

```quiz
- カーネル法だけが内積を使える
- Attentionは入力データに依存しない固定行列である
- 両者とも必ず同じ特徴空間を使う
- [x]カーネル法は特徴空間や類似度を固定するのに対し、Attentionは入力に応じて関係の重みを動的に変える
S: /series/06#固定性という制約
A: カーネル法では選んだカーネルが類似度の構造を固定する。AttentionはQueryとKeyから入力ごとの重みを計算し、関係そのものを動的に構成する。
```

### Q3. Query・Key・Value

Scaled Dot-Product AttentionにおけるQuery、Key、Valueの役割として正しいものはどれか。

```quiz
- [x]QueryとKeyの類似度で参照重みを作り、その重みでValueを加重平均する
- QueryとValueの距離だけでKeyを更新する
- Keyが出力を直接生成し、Valueは使わない
- 三つは常に同じベクトルでなければならない
S: /series/06#query-key-valueの直感
A: Queryは何を探すか、Keyは何に反応するか、Valueは取り出す内容に対応する。Query-Keyの類似度をSoftmaxで重みにし、Valueを集約する。
```

### Q4. 球面解釈の条件

Attentionを球面上の角度中心の計算として解釈するとき、必要な注意はどれか。

```quiz
- 内積は正規化の有無にかかわらず常に角度だけを表す
- [x]QueryとKeyの正規化やスケールの扱いを確認し、内積を角度と同一視できる条件を確かめる
- Valueも必ず単位ノルムでなければAttentionは計算できない
- Softmaxの温度は球面解釈に影響しない
S: /series/06#cosine-attention-l2正規化版
A: 正規化されたQueryとKeyの内積はコサイン類似度になり、角度として解釈しやすい。非正規化の内積にはノルムの影響が残るため、条件の確認が必要である。
```

## 複数の視点と位置

### Q5. Multi-head Attention

Multi-head Attentionの意義として、適切な説明はどれか。

```quiz
- 一つのAttentionを同じ入力に何度も繰り返すだけで、視点は増えない
- ヘッドを増やすとトークンの順序情報が自動的に得られる
- [x]複数の射影された部分空間で異なる関係を同時に捉え、最後に統合する
- 各ヘッドは必ず同じ部分空間を担当する
S: /series/06#multi-head-attention-複数の視点
A: 各ヘッドは異なる射影空間でAttentionを計算できる。複数の関係や特徴の見方を並行して持ち、出力を統合する仕組みである。
```

### Q6. RoPE

RoPEが位置情報を表現する方法として、正しいものはどれか。

```quiz
- 各トークンへ独立な乱数を加えて位置を表す
- 位置情報をValueだけに追加し、QueryとKeyには与えない
- すべての位置を同じ角度で回転させる
- [x]位置に応じてQueryとKeyの各2次元部分を回転させ、内積に相対位置の情報を反映する
S: /series/06#ropeの仕組み-回転による相対位置
A: RoPEは位置に応じた回転をQueryとKeyへ適用する。内積では回転角の差が現れるため、相対位置を扱いやすく、回転はノルムも保存する。
```

### Q7. Attentionのスケーリング

Scaled Dot-Product Attentionで内積をキー次元の平方根で割る理由はどれか。

```quiz
- [x]次元が大きいと内積の分散が増え、Softmaxが過度に尖るのを抑える
- QueryとKeyの次元を必ず1にする
- Valueのノルムを0にする
- 位置情報を削除する
S: /series/06#構成要素
A: 内積は次元が増えるとスケールが大きくなりやすい。平方根で割ることでSoftmaxの入力を扱いやすい範囲に保ち、勾配の極端な飽和を抑える。
```

### Q8. 連続と離散の橋渡し

AttentionにおけるSoftmaxとValueの加重和の役割として、適切な説明はどれか。

```quiz
- Softmaxは必ず一つのValueだけを選び、他を完全に捨てる
- [x]連続的な類似度を確率的な重みに変換し、Valueの情報を選択的に集約する
- 加重和はトークン間の関係を消去する
- Attentionの出力は常に入力の一つをそのまま返す
S: /series/06#softmaxの役割-連続から離散への橋渡し
A: 内積は連続的な類似度だが、Softmaxで重みに変換すると参照の強さとして扱える。加重和は複数のValueから文脈に応じた表現を作る。
```
