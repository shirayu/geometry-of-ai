# 第13回 理解度チェック：高次元の深淵

## 高次元の集中

### Q1. ほぼ直交

高次元でランダムなベクトルがほぼ直交する現象の読み方として、正しいものはどれか。

```quiz
- 高次元ではベクトルを配置できなくなる
- 直交性だけで意味構造が自動的に生まれる
- [x]内積の相対的な揺らぎが小さくなり、互いに干渉しにくい方向を多数確保できる
- すべてのベクトルが同じ意味を持つ
S: /series/13#「ほぼ直交」という奇妙な世界
A: 高次元の直交性は、独立な方向を詰め込む余地を与える。一方、それだけでは意味的な配置やタスクに有効な構造を保証しない。
```

### Q2. ほぼ等距離

高次元で距離が集中すると、近傍探索にどのような問題が起きうるか。

```quiz
- すべての点が原点へ集まる
- 距離が必ず負になる
- 内在次元が低くても必ず近傍探索が失敗する
- [x]最近傍と最遠傍の距離の相対差が小さくなり、近さの順位が区別しにくくなる
S: /series/13#「ほぼ等距離」という落とし穴
A: 距離の集中は、アンビエント次元が高く典型的な確率条件が成り立つ場合に、近傍と遠方の差を相対的に小さくしうる。内在構造や距離の選択も確認が必要である。
```

### Q3. 赤道集中

高次元球面で赤道集中が起きるという説明はどれか。

```quiz
- [x]固定した北極から見ると、表面積の大部分が直角に近い方向へ集まる
- すべての点が北極に集まる
- 球面の半径が次元とともに0になる
- 赤道集中は平面上の現象である
S: /series/13#「ほぼすべての点が赤道付近」
A: 高次元球面では、固定方向との内積が0付近に集中する。そのため角度は90度付近になり、表面積の大半が赤道帯にあるように見える。
```

### Q4. kNNと内在次元

高次元空間でのkNNについて、最も慎重な説明はどれか。

```quiz
- 座標の数が多ければ、kNNは必ず無意味になる
- [x]アンビエント次元だけでなく、データの内在次元や距離の性質を見て有効性を判断する
- 内在次元が低くても距離は定義できない
- kNNは高次元データでは一切使えない
S: /series/13#高次元でのknnの困難
A: 高いアンビエント次元は近傍探索を難しくしうるが、低次元構造や適切な表現があれば機能する。高次元という一語だけで結論を決めてはいけない。
```

## スパース性と設計

### Q5. ANNとスパース性

近似最近傍探索（ANN）が大規模検索で使われる理由はどれか。

```quiz
- すべての点との距離を必ず計算する
- 次元を無限に増やして距離を正確にする
- [x]厳密な全探索を避け、構造や索引を使って高速に近い候補を探す
- 近傍の定義を完全に捨てる
S: /series/13#近似最近傍探索-ann-とスパース性の活用
A: ANNは速度と検索精度のトレードオフを受け入れ、全候補の厳密な比較を避ける。高次元の構造やスパース性を利用して規模を扱う。
```

### Q6. MoEのルーティング

MoEのルーティングとkNNの類似性として、適切な説明はどれか。

```quiz
- MoEはすべてのExpertを同じ重みで必ず使う
- kNNは学習済みExpertを持つモデルである
- ルーティングには入力表現が不要である
- [x]入力表現とExpertの関係をスコア化し、近いまたは適した少数のExpertを選ぶ点に類似性がある
S: /series/13#ルーティングの幾何学-knnとの類似性
A: MoEのゲートは入力ごとにExpertを選ぶ。これは表現空間で適切な領域や方向を選ぶ操作として、近傍探索と似た見方ができる。
```

### Q7. MoEの課題

MoEでルーティングが偏ると起きる問題はどれか。

```quiz
- [x]一部のExpertに負荷が集中し、容量超過や学習の不均衡が起きる
- すべてのExpertが必ず同じ知識を学ぶ
- 計算量が必ず無限に増える
- 入力ごとの専門化が完全に失われる
S: /series/13#moeの課題と幾何学的理解
A: ゲートが特定のExpertばかり選ぶと、負荷の偏りやExpertの未使用が生じる。負荷分散などの補助損失やルーティング設計が必要になる。
```

### Q8. 高次元の設計原理

高次元の「恐怖と恩寵」を設計へつなぐ説明として、適切なものはどれか。

```quiz
- 高次元の問題は次元を下げれば常に解決する
- [x]距離集中やスパース性を前提に、表現・検索・ルーティングの仕組みを設計し直す
- 直交性と距離集中は同じ現象なので一方だけを扱えばよい
- 高次元では意味表現を作れない
S: /series/13#まとめ-高次元の恐怖と恩寵
A: 高次元には近傍探索を難しくする側面と、独立な方向や疎な計算を可能にする側面がある。条件を理解し、欠点を設計原理へ転換することが要点である。
```
