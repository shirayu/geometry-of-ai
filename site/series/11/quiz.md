# 第11回 理解度チェック：感覚の統合

## 異なる空間をつなぐ

### Q1. 異種多様体

異なるモダリティを別々の空間として扱う理由はどれか。

```quiz
- すべてのモダリティは同じ統計構造を持つから
- 別空間にすると学習が必ず不可能になるから
- [x]画像、言語、音声などが持つ局所構造や時間構造が異なるため、それぞれの性質を保つ必要がある
- モダリティには表現空間が存在しないから
S: /series/11#モダリティごとの構造的特性
A: 画像の空間的隣接、言語の構文、音声の時間的連続性は異なる。共有空間へ写す場合も、固有構造が取り出しにくくなる可能性を考慮する。
```

### Q2. CLIPの対照学習

CLIPの基本的な学習目標はどれか。

```quiz
- 画像とテキストを別々の分類器で学習し、関係を使わない
- すべての画像とテキストを同じ一点へ移す
- ペアの対応を使わず、ノルムだけを最大化する
- [x]正しい画像とテキストのペアを近づけ、誤ったペアを相対的に遠ざける
S: /series/11#対照学習の基本アイデア
A: CLIPは画像エンコーダとテキストエンコーダの出力を比較し、正例ペアの類似度を上げ、バッチ内の負例との順位を下げる。
```

### Q3. CLIPと角度

CLIPの類似度を角度として解釈できる条件はどれか。

```quiz
- [x]画像とテキストの埋め込みをL2正規化し、内積をコサイン類似度として使う
- 正規化せずにノルムを自由に変える
- Valueベクトルだけを正規化する
- 温度を無限大に固定する
S: /series/11#損失関数の幾何学
A: L2正規化により内積がコサイン類似度になり、球面上の角度として読める。正規化なしではノルムの影響が残る。
```

### Q4. 温度パラメータ

CLIPの温度パラメータを下げると、一般に何が起きるか。

```quiz
- すべてのペアが同じ重みになる
- [x]類似度の差が強調され、最も高いペアへの分布が尖る
- 正例と負例の区別がなくなる
- 埋め込みの次元が変わる
S: /series/11#温度パラメータの役割
A: 温度はSoftmaxの鋭さを調整する。低温では類似度の小さな差が強調されるが、学習の安定性や負例の扱いとのトレードオフがある。
```

## 統一と分離

### Q5. モダリティギャップ

モダリティギャップとは何か。

```quiz
- モダリティ間の次元数が必ず異なること
- 画像とテキストを同じデータとして保存できないこと
- [x]同じベクトル空間へ写した後も、モダリティごとの埋め込みが異なる領域に分布する現象
- すべてのモダリティが同じ一点へ収束すること
S: /series/11#モダリティギャップ
A: 共有空間への射影は、単一の滑らかな分布や完全な混合を保証しない。モダリティごとの領域分離が残ることをモダリティギャップと呼ぶ。
```

### Q6. FEDA

FEDAの幾何学的な設計はどれか。

```quiz
- すべてのドメインを同じ一点へ押し込む
- ドメイン固有情報を完全に削除する
- 入力特徴を必ず低次元へ圧縮する
- [x]共通特徴とドメイン固有特徴を別ブロックへ配置し、空間を拡張して干渉を減らす
S: /series/11#幾何学的な本質-次元の直交化
A: FEDAは特徴を共通ブロックとソース・ターゲット固有ブロックへ分ける。次元は増えるが、固有情報の棲み分けを明示できる。
```

### Q7. 統一か分離か

CLIP型の統一とFEDA型の拡張について、妥当な評価はどれか。

```quiz
- [x]統一は共通概念の検索に有利で、分離は固有構造の干渉を減らすが、どちらが適切かはタスクに依存する
- 統一は常に分離より優れている
- 分離すればモダリティ間の対応を学習できない
- 両者は同じ空間操作なので区別できない
S: /series/11#clipとの対比-「統一」か「分離」か
A: 共有空間はモダリティ横断の比較を容易にする一方、固有構造を圧縮する可能性がある。空間を拡張して分離する設計にも次元増加の代償があり、目的に応じた選択が必要である。
```

### Q8. ImageBindと統合の質

多モダリティ統合を評価するとき、単に共有空間があること以外に確認すべきことはどれか。

```quiz
- 埋め込み次元が大きいかだけ
- [x]モダリティ間の対応だけでなく、各モダリティ固有の構造や下流タスクの性能も保たれているか
- すべてのモダリティのノルムが同じかだけ
- 共有空間へ写せた時点で、すべての課題が解決したとみなす
S: /series/11#「統一」の質を問う
A: 統合の成功は、同じ座標へ置けたかだけで決まらない。ゼロショット転移、構成性、固有構造の保持など、目的に応じた評価が必要である。
```
