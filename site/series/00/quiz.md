# 第0回 理解度チェック：幾何学という言語

## 道具をつかむ

### Q1. 多様体の局所と大域

多様体を説明するものとして、最も適切なのはどれか。

```quiz
- 局所的には曲がって見えるが、大域的には一つの平坦な座標系に展開できる空間
- 大域的な構造は保つが、局所的にはユークリッド空間との対応が失われる空間
- [x]局所的にはユークリッド空間に見えるが、大域的には異なる構造を持つ空間
- 距離や角度を持たない、単なる有限集合
S: /series/00#多様体とは何か
A: 多様体は局所的な平坦さと大域的な構造の違いを同時に扱う。球面のように、近くでは平らに見えても全体では曲がった空間が典型例である。
```

### Q2. 構造の階層

位相多様体、可微分多様体、リーマン多様体の関係として正しいものはどれか。

```quiz
- 位相多様体だけが距離と角度を定義できる
- [x]構造を追加するほど、扱える道具が増える
- リーマン多様体では微分を定義できない
- 三つは名前が違うだけで、扱える道具は同じである
S: /series/00#多様体の機能的階層
A: 位相多様体はつながりを、可微分多様体は微分可能な方向を、リーマン多様体は計量に基づく距離や角度を扱う。構造を追加するほど使える道具も増える。
```

### Q3. 測地線の意味

曲がった空間における測地線について、最も慎重な説明はどれか。

```quiz
- 局所的にまっすぐ進む曲線だが、平坦な空間に限っては大域的な最短経路と一致する
- 二点間の大域的な最短経路になる
- [x]その空間の構造に沿って局所的にまっすぐ進む曲線で、常に大域的な最短経路とは限らない
- 大域的な最短経路として定義され、局所的な振る舞いは考慮しない
S: /series/00#測地線とは何か
A: 測地線は「曲がった空間での直線」に当たる概念である。長さやエネルギーの変分が停留する局所的な条件で定まり、経路全体の最短性とは区別される。
```

### Q4. 曲率と平行移動

曲率を直感的に理解する説明として、適切なものはどれか。

```quiz
- データ点の個数だけで決まる量である
- 各空間で0になる量である
- 座標の名前を変えると自由に変更できる量である
- [x]方向や測地線の振る舞いの変化を表す量である
S: /series/00#曲率とは何か
A: 曲率は空間の曲がり具合を定量化する。平坦なユークリッド空間、正の曲率を持つ球面、負の曲率を持つ双曲空間では、測地線や平行移動の振る舞いが異なる。
```

## 計量と情報をつなぐ

### Q5. リーマン計量の役割

リーマン計量は、表現空間で何を定めるために導入されるか。

```quiz
- [x]距離・角度を定める計量である
- 局所座標だけで距離や角度まで定める
- 接空間の方向を決め、距離は別の構造で扱う
- 確率分布の形を決め、測地線は定めない
S: /series/00#リーマン計量とは何か
A: 多様体だけでは距離や角度は定まらない。リーマン計量を入れることで、どの方向をどれだけ進んだか、どの経路が自然かを測れるようになる。
```

### Q6. 自然勾配の考え方

自然勾配が通常の勾配降下と異なる点はどれか。

```quiz
- [x]計量を考慮し、分布の変化を基準に更新する
- ユークリッド距離をそのまま無視して、ランダムな方向へ進む
- 学習率を使わずに更新できる
- 各パラメータを同じ値に固定する
S: /series/00#自然勾配と学習の効率
A: 自然勾配は、パラメータの座標上の距離ではなく、計量が表す分布の変化を基準に更新方向を調整する。座標の取り方に依存しにくい学習を目指す考え方である。
```

### Q7. 多様体仮説の読み方

高次元データに対する多様体仮説について、最も適切な説明はどれか。

```quiz
- 見かけの次元より低い自由度の構造にデータが集中するという見方であり、厳密な多様体であることも保証される
- 多様体仮説は画像や表現学習には適用できない
- [x]見かけの次元より低い自由度の構造にデータが集中するという見方だが、厳密な多様体を仮定できるとは限らない
- データが多様体上にあるかどうかは、ラベルの正しさを判定すれば分かる
S: /series/00#多様体とは何か
A: 多様体仮説は、データの実効的な自由度を理解する有力な見方である。一方、ノイズ、離散性、自己交差、場所による次元の違いなどがあり、厳密な多様体と同一視してはいけない。
```

### Q8. 五つの道具の使い分け

同じデータを座標変換しただけで近傍関係と予測性能が変わった。最初の診断として、最も適切なものはどれか。

```quiz
- [x]空間の形・計量・実装の座標変換への整合を確認する
- モデルの層数を増やして、座標依存性を学習で吸収する
- 距離の値だけを比較し、空間の形や分布の仮定は固定する
- 正解ラベルを見直さず、予測精度の変化だけをノイズとみなす
S: /series/00#まとめ-五つの道具
A: 座標変換で結果が変わるなら、空間の形、経路、曲率、計量、分布のどこを測っているかを分けて確認する。幾何学的な整合性と予測の正しさは別の評価である。
```
