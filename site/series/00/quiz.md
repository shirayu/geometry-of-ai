# 第0回 理解度チェック：幾何学という言語

## 道具をつかむ

### Q1. 多様体の局所と大域

多様体を説明するものとして、最も適切なのはどれか。

```quiz
- 局所的には曲がって見えるが、大域的には一つの平坦な座標系に展開できる空間
  R: 多様体の局所と大域の関係が逆になっている。局所的に平坦で大域的に曲がっているのが多様体であり、この説明は主従が反転している。
- 大域的な構造は保つが、局所的にはユークリッド空間との対応が失われる空間
  R: 多様体の定義そのものが「局所的にユークリッド空間に見える」ことを要件とするため、局所的な対応が失われるという説明は定義と矛盾する。
- [x]局所的にはユークリッド空間に見えるが、大域的には異なる構造を持つ空間
  R: 球面のように、近くでは平らに見えても全体を見渡すと曲がっている空間が多様体の典型であり、局所的な平坦さと大域的な構造の違いを同時に捉えている。
- 距離や角度を持たない、単なる有限集合
  R: 多様体は連続的な広がりを持つ空間であり、有限集合という離散的な対象とは別の概念である。距離や角度は計量を入れて初めて定まるが、多様体そのものが有限集合であるわけではない。
S: /series/00#多様体とは何か
A: 多様体は局所的な平坦さと大域的な構造の違いを同時に扱う。球面のように、近くでは平らに見えても全体では曲がった空間が典型例である。
```

### Q2. 構造の階層

位相多様体、可微分多様体、リーマン多様体の関係として正しいものはどれか。

```quiz
- 位相多様体だけが距離と角度を定義できる
  R: 距離と角度を定めるのはリーマン計量の役割であり、それを備えるのはリーマン多様体である。位相多様体はつながりだけを扱い、距離や角度は定義されていない。
- [x]構造を追加するほど、扱える道具が増える
  R: 位相多様体はつながりを、可微分多様体は微分可能な方向を、リーマン多様体は計量に基づく距離や角度を扱う。構造を積み重ねるごとに使える道具が段階的に増えていく。
- リーマン多様体では微分を定義できない
  R: リーマン多様体は可微分多様体の上にさらに計量を加えたものであり、微分可能性は失われずに引き継がれる。
- 三つは名前が違うだけで、扱える道具は同じである
  R: 三つはそれぞれ「つながり」「微分可能な方向」「距離・角度」という異なる道具を扱う階層であり、名称の違いだけでなく扱える構造そのものが異なる。
S: /series/00#多様体の機能的階層
A: 位相多様体はつながりを、可微分多様体は微分可能な方向を、リーマン多様体は計量に基づく距離や角度を扱う。構造を追加するほど使える道具も増える。
```

### Q3. 測地線の意味

曲がった空間における測地線について、最も慎重な説明はどれか。

```quiz
- 局所的にまっすぐ進む曲線だが、平坦な空間に限っては大域的な最短経路と一致する
  R: 測地線が大域的な最短経路と一致するかどうかは空間の曲率だけで決まるわけではなく、平坦な空間でも区間の取り方次第では最短性が崩れる場合があるため、この限定は正確ではない。
- 二点間の大域的な最短経路になる
  R: 測地線は局所的にまっすぐ進む条件で定義されるものであり、大域的な最短経路であることは保証されない。球面上の大円のように、区間によっては最短でない測地線も存在する。
- [x]その空間の構造に沿って局所的にまっすぐ進む曲線で、常に大域的な最短経路とは限らない
<!-- quiz-lint-ignore: hedge - 測地線の定義上「局所的にまっすぐ」かつ「大域的最短とは限らない」の両条件が必須で、誤答1がすでに同型の裏返し構文になっている -->
  R: 測地線は長さやエネルギーの変分が停留する局所的な条件で定まる概念であり、経路全体としての最短性とは区別される。球面の対蹠点のように最短経路が一意に定まらない場合もある。
- 大域的な最短経路として定義され、局所的な振る舞いは考慮しない
  R: 測地線の定義は局所的な条件（変分の停留）が出発点であり、大域的な最短性を定義の前提にしているわけではない。
S: /series/00#測地線とは何か
A: 測地線は「曲がった空間での直線」に当たる概念である。長さやエネルギーの変分が停留する局所的な条件で定まり、経路全体の最短性とは区別される。
```

### Q4. 曲率と平行移動

曲率を直感的に理解する説明として、適切なものはどれか。

```quiz
- データ点の個数だけで決まる量である
  R: 曲率は空間の幾何学的な性質であり、その空間に含まれるデータ点の個数とは無関係に定まる量である。
- 各空間で0になる量である
  R: 曲率は空間ごとに異なる値を取る。ユークリッド空間では0だが、球面では正、双曲空間では負になる。
- 座標の名前を変えると自由に変更できる量である
  R: 曲率は空間そのものに内在する幾何学的な量であり、座標の取り方（名前の付け方）を変えても変化しない。
- [x]方向や測地線の振る舞いの変化を表す量である
  R: 曲率は空間の曲がり具合を定量化する量であり、平行移動でベクトルの向きがずれたり、測地線が近づいたり離れたりする振る舞いとして現れる。
S: /series/00#曲率とは何か
A: 曲率は空間の曲がり具合を定量化する。平坦なユークリッド空間、正の曲率を持つ球面、負の曲率を持つ双曲空間では、測地線や平行移動の振る舞いが異なる。
```

## 計量と情報をつなぐ

### Q5. リーマン計量の役割

リーマン計量は、表現空間で何を定めるために導入されるか。

```quiz
- [x]距離・角度を定める計量である
  R: リーマン計量は各点の接空間に内積を定めることで、どの方向にどれだけ進んだか、どの経路が自然かという距離・角度の測り方を与える。
- 局所座標だけで距離や角度まで定める
  R: 局所座標そのものは単なる番地であり、距離や角度を定めるのは座標ではなく計量である。座標を決めただけでは距離は定まらない。
- 接空間の方向を決め、距離は別の構造で扱う
  R: 接空間の方向（微分可能性）を扱うのは可微分構造の役割であり、距離をそこから切り離すのではなく、計量こそが接空間に内積を与えて距離を定める。
- 確率分布の形を決め、測地線は定めない
  R: 確率分布の形を決めるのはモデルの設計であり計量の役割ではない。むしろ計量が定まれば、それに基づいて測地線も定まる。
S: /series/00#リーマン計量とは何か
A: 多様体だけでは距離や角度は定まらない。リーマン計量を入れることで、どの方向をどれだけ進んだか、どの経路が自然かを測れるようになる。
```

### Q6. 自然勾配の考え方

自然勾配が通常の勾配降下と異なる点はどれか。

```quiz
- [x]計量を考慮し、分布の変化を基準に更新する
  R: 自然勾配はフィッシャー情報行列という計量を使って勾配を補正し、パラメータ上の距離ではなく分布空間での変化量を基準に更新方向を決める。
- ユークリッド距離をそのまま無視して、ランダムな方向へ進む
  R: 自然勾配はユークリッド距離を無視するのではなく、フィッシャー情報行列という別の計量に基づいて更新方向を体系的に補正するものであり、ランダムな方向に進むわけではない。
- 学習率を使わずに更新できる
  R: 自然勾配は勾配の向きと大きさを計量で補正する手法であり、更新のステップ幅を決める学習率は依然として必要である。
- 各パラメータを同じ値に固定する
  R: 自然勾配はパラメータを固定する手法ではなく、計量に基づいて各パラメータの更新量を調整しながら学習を進める手法である。
S: /series/00#自然勾配と学習の効率
A: 自然勾配は、パラメータの座標上の距離ではなく、計量が表す分布の変化を基準に更新方向を調整する。座標の取り方に依存しにくい学習を目指す考え方である。
```

### Q7. 多様体仮説の適用条件

多様体仮説を実データへ適用するとき、最も適切な判断はどれか。

```quiz
- 実データは厳密な多様体なので、前提の確認は不要である
  R: 実データはノイズや離散性、局所次元の違い、クラス境界付近の自己交差などにより厳密な多様体になっているとは限らず、前提を確認せずに適用するのは危険である。
- 画像や表現学習は、多様体仮説の適用対象外である
  R: 画像や表現学習はむしろ多様体仮説がよく参照される代表的な領域であり、適用対象外とする根拠はない。
- [x]厳密な多様体を仮定せず、ノイズ・局所次元・自己交差などをデータごとに確認する
  R: 多様体仮説は有力な見方だが、実データにはノイズや離散性、場所による局所次元の違い、自己交差などが起こりうるため、「低次元構造っぽさ」として捉えつつデータごとに前提を確認するのが安全である。
- データが多様体上にあるかどうかは、ラベルの正しさを判定すれば分かる
  R: ラベルの正しさは教師信号の品質に関する問題であり、データが多様体構造を持つかどうかという幾何学的な性質とは別の問題である。
S: /series/00#多様体とは何か
A: 多様体仮説は、データが見かけの次元より低い自由度の構造に集中するという有力な見方である。一方、ノイズや離散性、場所による局所次元の違い、クラス境界付近の自己交差などが起きうるため、「低次元構造っぽさ」として捉え、前提をデータごとに確認するのが安全である。
```

### Q8. 五つの道具の使い分け

同じデータを座標変換しただけで近傍関係と予測性能が変わった。最初の診断として、最も適切なものはどれか。

```quiz
- [x]空間の形・計量・実装の座標変換への整合を確認する
  R: 座標変換で結果が変わるのは、空間の形、計量、実装のどこかが座標の取り方に依存してしまっている兆候であり、まずその整合性を切り分けて確認するのが妥当な診断である。
- モデルの層数を増やして、座標依存性を学習で吸収する
  R: 層数を増やすことは座標依存性という原因を特定せずに対処しようとする方法であり、根本的な診断を経ないまま複雑さを増すだけで問題を覆い隠しかねない。
- 距離の値だけを比較し、空間の形や分布の仮定は固定する
  R: 距離の値だけを比較しても、その距離がどの空間の形や計量のもとで測られているかを固定してしまえば、座標変換によって結果が変わった原因は見えてこない。
- 正解ラベルを見直さず、予測精度の変化だけをノイズとみなす
  R: 座標変換という明確な操作に対して結果が変化しているのに、その変化をノイズとして片付けてしまうと、空間の形や計量に起因する本質的な問題を見逃す。
S: /series/00#まとめ-五つの道具
A: 座標変換で結果が変わるなら、空間の形、経路、曲率、計量、分布のどこを測っているかを分けて確認する。幾何学的な整合性と予測の正しさは別の評価である。
```
