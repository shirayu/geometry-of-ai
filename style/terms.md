## 数学記法

### ベクトル・行列

| 対象 | 記法 | 例 |
| --- | --- | --- |
| ラテン文字ベクトル | `\mathbf{}` | $\mathbf{x}, \mathbf{z}, \mathbf{W}, \mathbf{u}$ |
| ギリシャ文字ベクトル | `\boldsymbol{}` | $\boldsymbol{\mu}, \boldsymbol{\theta}$ |
| 行列（ラテン大文字） | `\mathbf{}` | $\mathbf{W}, \mathbf{F}$ |
| スカラー | 素のイタリック | $\kappa, d, \tau, n$ |

検証: `grep -rn 'boldsymbol{[a-z]' site/series/*.md` でラテン文字への誤用を確認（ヒットゼロが正常）。

### 予約記号

詳細は `style/symbols.md` を参照。同一記号の二重使用が避けられない場合は、使用箇所で明示的に断ること。

| 記号 | 意味 |
| --- | --- |
| $d$ | 埋め込み次元 |
| $n$ | データ数 |
| $K$ | カテゴリ数 |
| $\kappa$ | 集中度（vMF 分布のパラメータ） |
| $\tau$ | 温度（Softmax のパラメータ） |
| $m$ | マージン（ArcFace） |
| $\mathbb{S}^{d-1}$ | 単位球面（`$S^{d-1}$` は使用禁止） |
| $\Delta^{K-1}$ | 確率単体 |
| $D_{\text{KL}}$ | KL ダイバージェンス |
| $\mathbb{E}$ | 期待値 |

### インライン数式

前後に半角スペースを入れる（` $x$ ` 形式）。Web レンダリング崩れ防止。

### 表示数式

本文 1 段落につき原則 1 本まで。連続する導出は TIP コールアウトか実装ノートへ。

## 初出英語併記ルール

各章は独立に読まれる Web 連載のため、章ごとに初出での英語・カタカナ併記を行う。同一章内で 2 回以上併記している箇所は 2 回目以降を削除する。
