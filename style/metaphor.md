# メタファー台帳

## この文書について

本講義シリーズ（第0〜15回＋Appendix 1〜6）で使われるメタファー（比喩）の全登録簿である。
本シリーズは抽象的な幾何学を直感的に伝えるためメタファーを多用する。メタファーが章をまたいで一貫し、同じ語が無自覚に別の対象を指して読者を混乱させないよう、すべての比喩をここで一元管理する。

**何のために使うか：**

- 新しい章を書くとき、新規メタファーを導入する前に既存の用法（特に「星」のような多義語）を確認する。
- 既存メタファーを別の章で再利用するとき、初出章・指す対象・限界の明示箇所を参照する。
- 通読監査で、メタファーの初出導入・混線・限界明示が適切かを照合する。

**規約との関係：** 基幹メタファーの**正規定義（執筆時に従うべきルール）** は `STYLE_GUIDE.md` の「メタファー運用」表が正本である。本ファイルはそれを補完し、局所メタファーや混線一覧を含む**実態の全登録と監査記録**を担う。両者が食い違う場合は STYLE_GUIDE を正とし、本ファイルの監査所見（§3）に基づいて STYLE_GUIDE 側を更新する。

**用語：**

- **基幹メタファー**：シリーズ全体を貫き、複数章で繰り返し参照される比喩。
- **局所メタファー**：その章限りの説明補助。シリーズの骨格には関与しない。
- **賞味期限（限界の明示）**：「この比喩はここまで」を CAUTION 等で示した箇所。STYLE_GUIDE はすべての基幹メタファーに賞味期限を書くことを義務づける。
- **混線**：同じ語（例「星」）が章によって別の数学的対象を指す状態。章内初出での対象の再宣言で緩和する。

## 基幹メタファーの進化（全体像）

本シリーズの空間メタファーは、扱う幾何構造の高度化に合わせて段階的に進化する。

```txt
地図／地球儀（第0回）         平坦な世界観・多様体の局所近似
   ↓
プラネタリウム（第3回）        単位球面・球面埋め込み
   ↓
測量士／天体観測（第6回）       Attentionによる動的な計量・観測
   ↓
望遠鏡・霧（第7回で不確実性へ）  分布埋め込み・κの有限性
   ↓
旅／軌跡（第8回以降で主役化）    時間軸・拡散・推論過程
   ↓
顕微鏡（第14回）              トポロジー・局所の穴とループ
   ↓
地図を閉じる（第15回）         円環を閉じ、未踏領域を展望
```

「霧」と「旅」は第0回で芽が蒔かれ、後の章で主役化する伏線型のメタファーである。

### 「星」の本質的意図（流用判断の基準）

「星」は章により6つの対象（単語／データ点／トークン／概念／生成データ／事実）を指すが、**通底する本質は一つ**である。

> **星＝広大な空間に離散的に配置される「意味の所在」。第3回のプラネタリウム文脈では、その本質は "どこにあるか（方向・配置）" にあり、"どれだけ明るいか（大きさ・ノルム）" は捨てられる。**

この狙いは第3回プラネタリウム対応表に集約される。そこでは星の「明るさ」だけが「この比喩では使わない——ノルムを捨てた」と明記される。つまり**星メタファーは、本シリーズの核心思想「ノルムを捨て、方向（配置）だけが意味を担う」を視覚化する装置**である。

| 星が含意するもの | シリーズの主張 |
| --- | --- |
| 夜空に点として輝く | 表現は空間内の一点（離散的な所在） |
| 半径方向の距離ではなく、相互の角度（配置）を見る | コサイン類似度＝方向中心。第3回ではノルムを固定する |
| 集まると星座になる | 個々の点でなく相対配置がクラスター／意味を作る |
| 本来は燃えるガスの広がりで、点に見えるのは解像度の限界 | 第7回：点埋め込みは κ=∞ の特殊ケース。拡大すれば「霧」 |

> **章による含意の違いに注意：** 上記は第3回（球面制約）の文脈での本質である。第6回の天体観測メタファーでは「星の輝き・色」を Key、「星の質量・組成」を Value の説明に使う。ここでの「輝き」は**ノルム（大きさ）ではなく、トークンの内容的特性**を指す比喩であり、第3回で捨てた「明るさ＝ノルム」とは別物である。星を別章で使うときは、輝き・明るさが何を指すかを章内で再宣言すること。

6つの対象（単語・データ点・トークン・概念・生成データ・事実）はレイヤーは違うが、すべて「**離散的な意味の単位を、連続空間の一点として配置したもの**」という共通構造を持つ。だから同じ「星」で貫ける。さらに「離散的な星空（第1回）→連続的な夜空の点（第3回）→拡大すると霧（第7回）」という星の変遷そのものが、シリーズの論旨（点から方向へ、点から分布へ）を運ぶ。

**流用の判断基準：** 新規章で「星」を使ってよいのは、**離散的な意味の所在を連続空間に配置する**文脈に限る。配置・方向以外の含意（選択・移動・大小など）が主役になる場合は、別のメタファーを選ぶか、対象を章内で明示的に再宣言する。

### 3.2 「星」「星座」の多義（混線）一覧

「星」は本シリーズで最も多義なメタファーであり、6つの異なる対象を指す。新規章でさらに別の対象に流用しないよう、本一覧で既存の用法を必ず確認すること。

| 章 | 「星」が指すもの | 「星座」が指すもの | 章内での再宣言 |
| --- | --- | --- | --- |
| 第1回 | 単語 | トピック（政治・スポーツ等） | あり（§離散的な星空で明示。NOTE で「以降は連続空間の点を指す」と予告） |
| 第3回 | データ点（埋め込みベクトル） | 意味的クラスター | あり（プラネタリウム対応表） |
| 第6回 | トークン | Attentionで選ばれたトークン群 | あり（§星空としてのトークン列） |
| 第7回 | 概念／埋め込み（＋霧をまとう） | ハルシネーションで強制結合される群 | 部分的（プラネタリウム文脈の継続） |
| 第9回 | 凝縮先のデータ点 | （明示的な星座なし） | あり（§導入 NOTE で第7回との役割差を明示） |
| Appendix 2 | 学習された概念／偽の事実 | 空白地帯で無理に結ぶ群 | あり（第7回との対比表） |

各章で対象の再宣言は概ね行われており、「章内初出で対象を再宣言する」方針は守られている。
ただし同一語が6種の対象を指す負荷は読者に大きく、混線リスクは残る。新規メタファー導入時は、別の語を選べないかをまず検討すること。
